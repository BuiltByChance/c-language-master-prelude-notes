# 190 · 解谜奖励怎么写回玩家状态，又怎样按等级查提示？

程序用两个整数保存玩家状态：初始等级 1、经验 0。两次“解谜”由代码直接发放 50 和 75 点，没有输入谜底的流程。检查升级时已有 125 点，门槛是 100，最高等级是 10。实跑显示升到 2 级并提示“寻找被遗忘的失落之剑”；按代码扣除 100 后还剩 25 点，录屏未单独打印余量。

| 函数 | 参数与结果 | 为什么采用这个接口 |
| --- | --- | --- |
| `increase_exp(&exp, amount)` | `*exp += amount`，返回 `void` | 奖励额只需读，经验要写回玩家 |
| `check_level_up(&exp, &level)` | 满足 `*exp >= 100 && *level < 10` 时扣 100、加一级并返回 `true`，否则返回 `false` | 同一次升级同时改变经验与等级，调用者用布尔结果决定是否显示提示 |
| `get_treasure_hint(level)` | 用 `level - 1` 作下标，返回 `const char *` | 只需读当前等级，结果是供显示的固定字符串 |

**一次升级还是连续升级？** 课堂在 `while` 循环体里立即 `return true`，所以调用一次最多升一级。若奖励规则允许一次结算跨多级，可以反复调用，每次返回 `true` 就为新等级显示一次提示。等级已到 10 时，即使还存有 100 点经验也不能再升级。

**十个位置不等于十条提示。** 录屏声明 `hints[10]`，实际只填了两条字符串。第 3 至 10 级能通过数字范围检查，但对应表项是空指针，不能交给 `%s`。整理者版本按实际有文字的项数检查，把其余情况映射到兜底文字。[WG14 C11 草案 §6.7.9](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=159)

```c
#include <inttypes.h>
#include <stdbool.h>
#include <stdio.h>

static void increase_exp(int32_t *exp, int32_t amount)
{
    *exp += amount;
}

static bool check_level_up(int32_t *exp, int32_t *level)
{
    if (*exp < 100 || *level >= 10)
        return false;
    *exp -= 100;
    ++*level;
    return true;
}

static const char *get_treasure_hint(int32_t level)
{
    static const char *const hints[] = {"Waterfall", "Lost sword"};
    size_t count = sizeof hints / sizeof hints[0];
    if (level > 0 && (size_t)level <= count)
        return hints[level - 1];
    return "No hint for this level";
}

int main(void)
{
    int32_t exp = 0, level = 1;
    increase_exp(&exp, 50);
    increase_exp(&exp, 75);
    if (check_level_up(&exp, &level))
        printf("level=%" PRId32 ", exp=%" PRId32 ", hint=%s\n",
               level, exp, get_treasure_hint(level));
    return 0;
}
```

复测输出 `level=2, exp=25, hint=Lost sword`。这里用英文短语代替原课提示，并额外打印剩余经验，便于核对扣减。
