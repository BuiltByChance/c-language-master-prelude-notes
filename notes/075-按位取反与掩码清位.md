# 075 · 怎样让一个字节逐位取反，或只清除指定的位？

`~` 把整数的每个 `0` 变为 `1`、每个 `1` 变为 `0`。`!` 则判断整个值是否为零。用课堂的初值 `12` 对照，`!12` 得 `0`，把 `~12` 写回课堂的八位无符号变量则得到 `243`。

## 翻转并读出八位状态

录屏把 `status` 初始化为 `0b00001100`。`0b` 是 C23 的二进制整数常量前缀，下面的复现代码改用 C17 也能识别的 `0x0C`，数值同为 `12`。[C23 草案 §6.4.4.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf#page=78)

```c
#include <stdint.h>
#include <stdio.h>

static void print_binary(uint8_t num) {
    for (int index = 7; index >= 0; index--) {
        printf("%d", (num >> index) & 1);
    }
}

int main(void) {
    uint8_t status = 0x0C;
    printf("Initial status: 0b");
    print_binary(status);
    printf("\t(Binary)\n");

    status = ~status;
    printf("FINAL: 0b");
    print_binary(status);
    printf("\t(Binary)\n");
    return 0;
}
```

`num >> index` 把第 `index` 位移到最低位，`& 1` 只取这一位。从第 7 位打印到第 0 位，开头的零也会显示。课堂控制台的两行分别是 `0b00001100` 和 `0b11110011`。

`~status` 先把 `uint8_t` 提升为 `int` 再取反。在录屏使用的补码环境中，中间值是 `-13`。赋值给 `uint8_t` 时按模 256 转换，才得到打印的 `243`（`0xF3`）。[C11 草案 §6.5.3.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=107) · [§6.3.1.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=69)

## 只清除选定的位

讲师口述了 `status &= ~mask;` 的做法。先把要清的位置在 `mask` 中标为 `1`。`~mask` 把这些位置变为 `0`，其余位置变为 `1`。再与原状态做 `&`，目标位归零，其余位保持原值。

下面是整理者复测的例子。从最低位按 0 编号，初值的第 3、2 位都为 `1`，只清第 2 位后，第 3 位应仍为 `1`。

```c
uint8_t status = 0x0C;          // 00001100，重新从初值开始
unsigned int mask = 1u << 2;   // 00000100，选中第 2 位
status &= ~mask;               // 00001000，结果为 8
```
