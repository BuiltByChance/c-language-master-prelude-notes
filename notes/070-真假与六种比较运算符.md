# 070 · 两个整数怎样比较，为什么输出总是 0 或 1？

C 用 `<`、`>`、`<=`、`>=` 判断大小关系，用 `==`、`!=` 判断是否相等。这六种比较都产生 `int` 值，关系成立为 `1`，不成立为 `0`。[微软 C 关系和相等运算符](https://learn.microsoft.com/zh-cn/cpp/c-language/c-relational-and-equality-operators?view=msvc-170)

| 表达式 | 判断什么 | `a = 10`、`b = 20`（课堂运行） | `a = 5`、`b = 5`（整理者复测） |
|---|---|---:|---:|
| `a > b` | 大于 | 0 | 0 |
| `a < b` | 小于 | 1 | 0 |
| `a == b` | 相等 | 0 | 1 |
| `a != b` | 不相等 | 1 | 0 |
| `a >= b` | 大于或等于 | 0 | 1 |
| `a <= b` | 小于或等于 | 1 | 1 |

## 把比较结果存下来

单独取出课堂的相等比较，可以这样运行。

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    int a = 10, b = 20;
    bool equal = a == b;
    printf("a == b: %d\n", equal);  // a == b: 0
    return 0;
}
```

`bool equal = a == b;` 中，右边的 `==` 比较两个数，声明里的单个 `=` 用比较结果初始化 `equal`，`a` 和 `b` 的值都保留。若单独写成 `a = b;`，就是把 `20` 写进 `a`。

C17 中，`<stdbool.h>` 提供 `bool`，`<stdio.h>` 声明 `printf`。把 `equal` 作为 `printf` 的可变参数传入时，它会提升为 `int`，所以 `%d` 可以打印出 `0` 或 `1`。[C17 草案 §6.5.2.2](https://teaching.csse.uwa.edu.au/units/CITS2002/resources/n2176.pdf#page=78)

**为什么 `if (-2)` 也会进入分支？** 把一个整数直接用作条件时，C 只检查它是否为零。任何非零值都为真，包括负数（整理者补充）。[C17 草案 §6.8.4.1](https://teaching.csse.uwa.edu.au/units/CITS2002/resources/n2176.pdf#page=127)
