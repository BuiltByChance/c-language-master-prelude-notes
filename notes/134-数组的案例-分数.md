# 134 · 怎样一次遍历算出五名学生的平均分、最高分和最低分？

每读到一个成绩就做三件事：把它加进总分，和目前的最高分比较，和目前的最低分比较。总分从 0 开始，两个极值从第一项开始。若最低分也从 0 开始，这组正分无论怎么比都得不到真正的最低分。用第一项作初值的前提是至少有一个成绩。

下面是整理者按录屏改写的可运行例子。

```c
#include <stdio.h>

int main(void)
{
    const unsigned grades[] = {85, 92, 88, 96, 79};
    const size_t count = sizeof grades / sizeof grades[0];
    unsigned total = 0, highest = grades[0], lowest = grades[0];

    for (size_t i = 0; i < count; ++i) {
        unsigned grade = grades[i];
        total += grade;
        if (grade > highest) highest = grade;
        if (grade < lowest) lowest = grade;
    }
    printf("总分 %u，平均 %.2f，最高 %u，最低 %u\n",
           total, (double)total / count, highest, lowest);
    return 0;
}
```

读到 `92` 时，最高分从 85 升为 92。下一个 `88` 落在现有范围内，两个极值都保留。`96` 再次刷新最高分，最后的 `79` 刷新最低分。统计从头到尾只读一次，原来每名学生和分数的对应关系也保留下来。

录屏第一版只算平均分，显示 `88.00`，最高分和最低分还停在初值 `85`。补上比较再运行，显示总分 `440`、平均 `88.00`、最高 `96`、最低 `79`，退出码为 0。`(double)total / count` 在除法前转换为浮点，`%.2f` 才负责显示两位小数。这组数据恰好整除，若把最后一个分数从 79 改为 80，正确平均分应为 `88.20`。
