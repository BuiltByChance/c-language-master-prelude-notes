# 173 · 指针保存的地址，和指针变量自己的地址，怎样区分？

在 `int *ptr_floor_103 = &building_floors[2];` 中，变量名是 `ptr_floor_103`，类型是 `int *`，表示“指向 `int` 的指针”。`&` 取得数组第三个元素的位置，把这个指针值存入变量。数组元素保留自己的整数 **103**，赋值给指针并没有复制这个整数。

| 要观察什么 | 表达式 | 类型 |
|---|---|---|
| 第三个元素里存的门牌号 | `building_floors[2]` | `int` |
| 第三个元素的位置 | `&building_floors[2]` | `int *` |
| 指针里记住的位置 | `ptr_floor_103` | `int *` |
| 存放这个指针的变量自身的位置 | `&ptr_floor_103` | `int **` |

整理者复习示例用不同标签打印三项，避免把指针变量所在地误读成它所指向的位置：

```c
#include <stdio.h>

int main(void)
{
    int building_floors[] = {101, 102, 103, 104, 105};
    int *ptr_floor_103 = &building_floors[2];

    printf("element: %p\n", (void *)&building_floors[2]);
    printf("stored:  %p\n", (void *)ptr_floor_103);
    printf("pointer variable: %p\n", (void *)&ptr_floor_103);
    printf("same target: %d\n", ptr_floor_103 == &building_floors[2]);
    return 0;
}
```

**验证关系，不背地址数字**。同一次运行中，前两行显示同一元素的位置，最后一行打印 **1**。录屏一次实跑中，元素地址和指针保存的地址都以 `FCA0` 结尾；另一次打印时，前两项末尾都是 `F850`，`&ptr_floor_103` 的末尾却是 `F898`。原控制台后两项提示文字相同，还挤在同一行，要看传给 `printf` 的表达式才能区分。课堂 `%p` 调用省略了转换，复习版按标准传入 `void *`。[WG14 C11 草案 §7.21.6.1](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=333)

结尾又声明 `int *ptr_floor_102 = &building_floors[1];`，使第二个指针指向值为 102 的元素，片中没有运行它的输出或通过它改写数组。
