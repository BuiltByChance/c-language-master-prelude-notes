# 036 · 定宽整数：什么时候用 int32_t，怎样查出数值变错的原因

## 按字段要求选类型

| 需求 | 写法与判断依据 |
| --- | --- |
| 只做普通计数，例如从 0 数到 100 | 用 `int` 就能覆盖整个范围，无须指定内存宽度。 |
| 接口约定一个**恰好 32 位**的整数，同一份 C 源码要在多个平台编译 | 包含 `<stdint.h>`，有符号字段用 `int32_t`，无符号字段用 `uint32_t`。同理有 8、16、64 位的名称。C99 规定了这些名称；目标实现具备相应的精确位宽和表示时才提供对应类型。[C99 定宽整数定义](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1256.pdf#page=268) |
| 维护已经采用微软扩展的代码 | 在 MSVC 中可直接声明 `__int8`、`__int16`、`__int32`、`__int64`，前面是两个下划线，数字是**位数**。移植这段代码时，要确认目标编译器支持该扩展，或改用对应的标准定宽类型。[微软 C 定宽整数说明](https://learn.microsoft.com/en-us/cpp/c-language/c-sized-integer-types?view=msvc-170) |

## 打印时先核对格式，再检查赋值

课堂在 Visual Studio 的 `Debug x64` 项目中，用同一个变量 `sun_flower` 演示了两种故障。

- **没有打印出数。** 变量类型是 `__int16`，值是 `100`。写 `%h` 时，编辑器报告有多余的参数：`h` 只是长度修饰符，后面还缺转换字符。改为 `%hd` 就打印出 `100`。这里用 `%d` 也可以，因为 `short` 传给 `printf` 时会提升为 `int`。[微软 printf 格式说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170#argument-size-specification)
- **打印出了另一个数。** 同一个变量改存 `1009900000`，仍用 `%hd`，控制台显示 `-9760`，退出码为 0。有符号 16 位整数只能表示 −32768 到 32767；这次 MSVC 赋值时只保留了低 16 位。此时再换输出格式也找不回原值，应在赋值前检查范围，或用能容纳原值的类型。[微软有符号整数转换规则](https://learn.microsoft.com/en-us/cpp/c-language/conversions-from-signed-integral-types?view=msvc-170)

打印十进制 `long`、`unsigned long`、`long long`、`unsigned long long`，依次用 `%ld`、`%lu`、`%lld`、`%llu`（小写字母 l）。课堂最后的 `%lu` 仍传入了有符号的 `number`；按声明应写 `printf("%lu", number_3);`。这四行只在编辑器中展示。[微软 printf 长度修饰符表](https://learn.microsoft.com/en-us/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170#argument-size-specification)

## 复习示例：在写入 16 位字段之前检查范围

下面是整理者补充的标准 C 写法。课堂只板书介绍了 `<stdint.h>`。`INT16_MIN` 和 `INT16_MAX` 给出字段允许的上下限。`<inttypes.h>` 的 `PRId32`、`PRId16` 会展开为适合目标平台的有符号十进制格式，前面要写 `"%"`。[C99 整数格式宏](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1256.pdf#page=210)

```c
#include <stdint.h>
#include <inttypes.h>
#include <stdio.h>

int main(void)
{
    int32_t input = 1009900000;
    if (input < INT16_MIN || input > INT16_MAX) {
        printf("%" PRId32 " out of range\n", input);
        return 0;
    }

    int16_t stored = (int16_t)input;
    printf("%" PRId16 "\n", stored);
    return 0;
}
```

将代码放进 C 控制台项目的 `.c` 文件，在 Visual Studio 选择“调试 → 开始执行（不调试）”（Ctrl+F5）。第一次应看到 `1009900000 out of range`，说明程序在窄化前保住了原值。把 `input` 改为 `100` 再运行，应看到 `100`，这条路径才会写入 16 位变量。
