# 180 · 为什么退出花括号后，指针变量还在，目标却失效了？

录屏里有三个对象。外层的整数 `floor_number` 保存 103，外层的指针 `ptr_to_floor` 最初指向它。内层另有一个普通局部整数 `temp_floor`，值为 104。讲师在内层改变了**外层指针**的目标；退出内层时，C 会结束 `temp_floor` 的生命周期，却不会撤销之前的赋值，把指针重新指回 103。

- **名字的作用域**决定源码中的名字在哪些位置可用。在右花括号外写 `temp_floor++`，编辑器标红，因为这个位置看不到该名字。
- **对象的生命周期**决定什么时候还能访问该对象。退出内块后，外层仍能写出 `ptr_to_floor` 这个名字，但它此前指向的对象已经消失，指针的值变得不确定。此时不能通过它读取 104，也不能靠打印地址或者与 `NULL` 比较来确认目标是否存活。[WG14 C11 草案 §6.2.4 第 2、6 段](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=56)

**课堂结果。** 调试控制台先显示楼层 103，随后那次失效访问碰巧显示 104，退出码为 0。第二行属于未定义行为。它既不能证明原对象仍存活，也不能证明那块存储已经分配给了别的对象。讲师没有现场修复。

**整理者修正版。** 若只需在内层暂时查看另一层，给内层单独的指针，让外层的选择保持有效；若退出后要保留的只是数字，则在对象存活时把数值复制出来。

```c
#include <stdio.h>

int main(void)
{
    int floor_number = 103;
    const int *current = &floor_number;
    int last_seen;

    {
        int temp_floor = 104;
        const int *temporary = &temp_floor;
        last_seen = *temporary;
    }

    printf("current=%d, last_seen=%d\n", *current, last_seen);
    return 0;
}
```

这一版的 `current=103, last_seen=104` 来自外层仍存活的两个整数。
