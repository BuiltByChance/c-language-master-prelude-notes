# 145 · 怎样让农场里的作物逐轮成熟，同时保留空地和石头？

把农场存成 `int farm[10][10]`，每格只存状态。绘图时用 `.` 表示空地（0），`*` 表示已种未熟（1），`#` 表示成熟（2）。每次走访 100 格，只有值为 1 的格子有机会变成 2。这样空地不会长出作物，成熟的作物也不会退回幼苗。

1. **播种只做一次。** 录屏以 `srand((unsigned)time(NULL))` 设置伪随机数种子，再对各格执行 `rand() % 2 == 0 ? EMPTY : PLANTED`。约一半是幼苗，单次开局的株数会浮动。同一运行库用相同种子可以复现相同序列，调试时可改用固定种子。[Microsoft 的 rand 文档](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/rand?view=msvc-170)
2. **先打印初始地图，再更新五轮。** 外层循环数轮次，内两层分别遍历行、列。若某格是幼苗且 `rand() % 10 < 3`，就把它改成成熟。余数 0、1、2 命中，课程把它近似为每轮 30%。按独立的 30% 机会估算，一株幼苗五轮后还没熟的概率为 `0.7⁵ ≈ 16.8%`。收尾时看见几个星号是正常结果。
3. **画面与数据分别处理。** `print_farm(farm)` 逐行把状态转换成字符，每输出完一行才换行。初始地图和每轮更新后都调用它。Windows 版先用 `system("cls")` 清控制台，重画后用 `Sleep(1000)` 等待约一秒；清屏不会清除数组。录屏生成成功但有 C4013 警告，称 `Sleep` 未声明，按 Windows SDK 加入 `#include <windows.h>` 即可取得声明。[Windows 的 Sleep 文档](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-sleep)

以下是整理者的可运行练习。保留各帧以便直接比对，将时间种子换成固定种子。每帧应有 10 行；同一位置只可能从 `*` 变成 `#`，不会发生其他变化。

```c
#include <stdio.h>
#include <stdlib.h>

enum { ROWS = 10, COLS = 10 };
enum { EMPTY, PLANTED, MATURED };
static void print_farm(int farm[][COLS])
{
    for (int row = 0; row < ROWS; ++row) {
        for (int col = 0; col < COLS; ++col) {
            int state = farm[row][col];
            putchar(state == EMPTY ? '.' : state == PLANTED ? '*' : '#');
        }
        putchar('\n');
    }
}

int main(void)
{
    int farm[ROWS][COLS];
    srand(1);
    for (int row = 0; row < ROWS; ++row)
        for (int col = 0; col < COLS; ++col)
            farm[row][col] = rand() % 2 == 0 ? EMPTY : PLANTED;

    print_farm(farm);
    for (int round = 1; round <= 5; ++round) {
        for (int row = 0; row < ROWS; ++row)
            for (int col = 0; col < COLS; ++col)
                if (farm[row][col] == PLANTED && rand() % 10 < 3)
                    farm[row][col] = MATURED;
        printf("Round %d\n", round);
        print_farm(farm);
    }
    return 0;
}
```

**给地图加固定障碍。** 讲师还给状态 3（石头）配了字符 `!`，演示 `int farm[ROWS][COLS] = {[3][3] = STONE, [6][6] = STONE};`，其余格自动为 0。这次演示先注释了随机播种，控制台能看见两枚 `!`。讲师口头说刷新后石头会消失，但清屏只改显示，成长循环也只改幼苗。若接下来对所有格子随机播种，这两格也会被覆盖。要在随机农场保留石头，可以先随机播种，再写入这两个固定坐标。此后只更新幼苗，两块石头就会一直留在原地。
