# 150 · 怎样让面积函数既能打印，也能供后续计算？

每种图形只接收决定面积的尺寸。正方形用一条边长，长方形用同一单位的长和宽，圆用半径。若题目给的是直径，应先除以 2；把直径当半径会使面积变为正确值的四倍。长度用厘米时，面积的单位是平方厘米。

把公式写进返回 `double` 的函数。调用方只看结果时直接打印；还要比较或累加面积时，把返回值保存到变量中。下面是整理者的复习版，沿用录屏的近似值 `PI = 3.14` 和尺寸，补上了圆面积的输出。

```c
#include <stdio.h>

#define PI 3.14

double square_area(double side)
{
    return side * side;
}

double rectangle_area(double length, double width)
{
    return length * width;
}

double circle_area(double radius)
{
    return PI * radius * radius;
}

int main(void)
{
    printf("%.0f\n", square_area(6.0));
    printf("%.0f\n", rectangle_area(542.0, 123.0));
    double area = circle_area(5.6);
    printf("%.4f\n", area);
    return 0;
}
```

课堂最终控制台依次显示 `36.000000`、`186624.000000`、`293764.000000`、`66666.000000`，分别对应边长 6、432、542 的正方形和 542 × 123 的长方形。

上面复习版的输出是 `36`、`66666`、`98.4704`。最后一个数按课程给定的 π 近似值计算，打印更多小数位不会提高这个常量的精度。录屏把圆面积存入临时变量后草拟了一个条件判断，比较条件未写完，随后整段删除。
