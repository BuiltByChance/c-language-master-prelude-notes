# 136 · 三个账户各自改了余额，怎样核对总额也更新了？

数组中每项保存一个模拟账户的余额，单位为整元。账户 1 对应下标 0，账户 2 对应下标 1。显示时用 `index + 1` 给人看账户号，取余额则用 `account_balances[index]`。只给 `printf` 传数组名，传过去的是首元素地址，无法用整数格式输出指定账户的余额。

| 账户 | 初始余额（元） | 操作 | 操作后（元） |
| ---: | ---: | --- | ---: |
| 1 | 10000 | 存入 5000 | 15000 |
| 2 | 15000 | 取出 2500 | 12500 |
| 3 | 20000 | 无 | 20000 |

下面是整理者按录屏改写的核对程序。先完成两次余额变动，再从零开始对最终余额求和。

```c
#include <inttypes.h>
#include <stdio.h>

int main(void)
{
    int64_t balances[] = {10000, 15000, 20000};
    balances[0] += 5000;
    balances[1] -= 2500;

    int64_t total = 0;
    for (int i = 0; i < 3; ++i) {
        printf("账户 %d：%" PRId64 " 元\n", i + 1, balances[i]);
        total += balances[i];
    }
    printf("总额：%" PRId64 " 元\n", total);
    return 0;
}
```

录屏首次运行，三笔余额都正确，合计却显示 0，因为第二个循环只打印余额，没有更新累加器。补上 `total_assets += account_balances[index];` 后，第二次运行显示总额 47500 元，退出码为 0。逐项相加得到 `15000 + 12500 + 20000 = 47500` 元。也可从初始总额独立核对，`45000 + 5000 - 2500 = 47500`。本例的存入与取出是两笔独立操作，所以合计比原来多 2500 元。
