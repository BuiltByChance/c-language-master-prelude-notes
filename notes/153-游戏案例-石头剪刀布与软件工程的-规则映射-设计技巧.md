# 153 · 怎样把石头剪刀布的三条胜利规则写成一张表？

先定双方共同使用的编码：1 石头、2 布、3 剪刀。玩家输一个数，电脑用 `rand() % 3 + 1` 取得同一范围的数。讲师把说明、获取玩家出招、生成电脑出招、显示招式、判定胜负分成五个函数。取招函数返回编号；显示函数接收编号，用 `switch` 输出名称；判定函数接收双方编号。

**表的下标是玩家出的招，表里的值是这招能打败的对手。** 先处理双方相同的平局。其余情况下，只需比较电脑编号与 `winning_moves[player]` 是否相等。比如玩家出布（2），查到 `winning_moves[2] == 1`，电脑出石头（1）才是玩家获胜。下标 0 留空，使招式编号可以直接作下标。

| 玩家编号 | 1 石头 | 2 布 | 3 剪刀 |
| --- | --- | --- | --- |
| 能赢的电脑编号 | 3 剪刀 | 1 石头 | 2 布 |

整理者把判定写成可独立验证的函数。用两层循环测完九种组合，比靠随机对局等到某一组合更直接。

```c
#include <stdio.h>

enum { ROCK = 1, PAPER, SCISSORS };

static const char *outcome(int player, int computer)
{
    static const int winning_moves[] = {0, SCISSORS, ROCK, PAPER};
    if (player < ROCK || player > SCISSORS ||
        computer < ROCK || computer > SCISSORS)
        return "invalid";
    if (player == computer) return "draw";
    return computer == winning_moves[player] ? "win" : "lose";
}

int main(void)
{
    for (int player = ROCK; player <= SCISSORS; ++player) {
        for (int computer = ROCK; computer <= SCISSORS; ++computer)
            printf("%s ", outcome(player, computer));
        putchar('\n');
    }
    return 0;
}
```

三行分别应为 `draw lose win`、`win draw lose`、`lose win draw`。对角线三格都是平局。原片先实际运行逐项列举三个胜利条件的版本，再在编辑器改写为查表；片末停在查表源码，未再运行一局或比较耗时。讲师提到 `switch` 的常量限制：确切地说，`case` 标签需要整数常量表达式，`switch` 本身可以按运行时的整型表达式分支。

**查表前先验证输入。** 课堂实际输入 22、212321 均被要求重试，再输 2 被接受。原程序用 `%d` 配 `uint32_t *`，没有检查读取是否成功，不能据这些数字测试推断字母也能处理。若保留 `uint32_t`，可从 `<inttypes.h>` 取 `SCNu32`，检查 `scanf("%" SCNu32, &move) == 1` 后再检查 1～3。转换失败时先丢弃本行剩余字符，遇到文件尾则结束输入，避免重复遇到同一个无效字符。[Microsoft 的 scanf_s 说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/scanf-s-scanf-s-l-wscanf-s-wscanf-s-l?view=msvc-170)

**在 VS 中统一改名。** 录屏用 Ctrl+F 展开替换栏，将 `get_player_choice` 换成 `get_player_move`，再同样更换电脑取招函数和对应变量。点“全部替换”前看清搜索范围和匹配内容，否则相似名字可能一起被改。改名后重新生成、运行，检查提示和判定是否仍对应同一组编号。
