# 137 · 找到最高票数后，怎样知道是哪位候选人？

票数数组 `votes` 中，下标对应候选人，元素值对应得票数。讲师把四个位置初始化为 0，再用 `+=` 分别记入 `150、200、180、190` 票。这些是写在程序里的模拟数据。

遍历数组时，总票数要在每一轮累加。只有当前票数超过已有最高票时，才同时更新 `max_votes` 和 `winner`。前者保存票数，后者保存该票数出现的位置。屏幕上的候选人从 1 开始编号，打印时用 `winner + 1`。

```c
#include <stdio.h>

int main(void)
{
    const unsigned votes[4] = {150, 200, 180, 190};
    unsigned total = 0, max_votes = 0;
    int winner = 0;

    for (int i = 0; i < 4; ++i) {
        total += votes[i];
        if (votes[i] > max_votes) {
            max_votes = votes[i];
            winner = i;
        }
    }
    printf("总票数 %u，候选人 %d 获得 %u 票\n", total, winner + 1, max_votes);
    return 0;
}
```

上面是整理者的精简版。录屏先列四人的得票，再显示总票数 `720`、获胜候选人 `2`、得票 `200`，退出码为 0。

若出现并列最高票，严格比较 `>` 会保留最早达到最高票的位置。整理者举例，把第四人的 190 改成 200，第 2 和第 4 人同为 200 票，这段代码仍只打印第 2 人。若要报告全部并列者，先求最高票，再列出所有 `votes[i] == max_votes` 的候选人。
