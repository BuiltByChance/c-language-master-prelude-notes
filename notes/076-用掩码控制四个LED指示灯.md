# 076 · 怎样用掩码只关低电量灯，再把四盏 LED 切到正常状态？

课堂用 `uint8_t status` 模拟四盏指示灯。看屏幕上最右边的四位，从左往右依次是第 3 位错误、第 2 位低电量、第 1 位 Wi-Fi 和第 0 位电源。`1` 表示亮，`0` 表示灭。

| 题设 | 课堂控制台的八位输出 | 亮着的灯 |
| --- | --- | --- |
| 初始 | `00001100`（12） | 错误、低电量 |
| 换好电池 | `00001000`（8） | 错误 |
| 修好电路并连上 Wi-Fi | `00000011`（3） | Wi-Fi、电源 |

## 两次更新各用什么掩码

1. **只关低电量灯**。将 `status` 与 `11111011` 做按位与 `&`。掩码只有第 2 位是 `0`，这一位被清除，其他七位原样保留。即使低电量灯本来就灭着，同一操作也能重复执行。
2. **从 `00001000` 切到 `00000011`**。第 3 位要从 `1` 变 `0`，第 1、0 位要从 `0` 变 `1`。将这三位在掩码中标为 `1`，得到 `00001011`，再与当前值做异或 `^`。自己推掩码时，可用 `当前值 ^ 目标值` 找到所有需要翻转的位。

课堂把按位或 `|` 留作思考。整理者复测发现，如果“恢复正常”命令可能执行两次，第二次异或同一掩码会把 `00000011` 翻回 `00001000`。要从任意初态设置低四位为 `0011`，同时保留高四位，可写 `status = (status & 0xF0u) | 0x03u;`。前半清除低四位，后半只点亮电源和 Wi-Fi，重复执行结果相同。

## 运行并核对八位输出

下面是整理者复测的 C17 程序，沿用课堂的两次运算。录屏中的 `0b00001100`、`0b11111011`、`0b00001011` 在这里写成等值的十六进制。

```c
#include <stdint.h>
#include <stdio.h>

static void print_binary(uint8_t num) {
    printf("0b");
    for (int index = 7; index >= 0; index--) {
        printf("%d", (num >> index) & 1);
    }
    putchar('\n');
}

int main(void) {
    uint8_t status = 0x0C;
    print_binary(status);

    status = status & 0xFB;
    print_binary(status);

    status = status ^ 0x0B;
    print_binary(status);
    return 0;
}
```

运行后应依次看到 `0b00001100`、`0b00001000`、`0b00000011`，每个值各占一行。`num >> index` 把要读的位移到最右边，`& 1` 取出该位。从第 7 位数到第 0 位，前导零也会打印。换行放在循环结束后，放在循环里会让每一位各占一行。

源码的 `0b` 前缀决定整数常量怎样读，`printf` 的格式决定同一个值怎样显示。C17 的标准 `printf` 没有二进制转换符。C23 支持 `0b` 常量和 `%b` 输出。在实现该格式的运行库上，`printf("0b%08b\n", (unsigned)status);` 可直接输出八位。2026-11-22 核对时，微软 CRT 的格式表未列 `%b`，录屏验证的是上面的逐位打印方法。[C23 整数常量](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf#page=78) · [C23 格式化输出](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf#page=349) · [微软 CRT 格式表](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170)
