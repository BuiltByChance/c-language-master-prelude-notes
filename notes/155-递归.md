# 155 · 递归算阶乘时，乘法究竟在哪一层发生？

`factorial(n)` 要回答两个问题。能直接给出结果时，停止调用自己：`0! = 1`。其余非负整数都可缩小成同样的问题：先求 `(n - 1)!`，再乘以这一层的 `n`。每次实参减 1，保证能到达 0。

以 `5!` 为例，调用依次进入 `f(5) → f(4) → f(3) → f(2) → f(1) → f(0)`。总共六次函数调用，其中五次是函数体发起的自调用。返回方向与进入方向相反：

| 返回到哪一层 | 在这一层算出的返回值 |
| --- | --- |
| `f(0)` | 基例直接返回 1 |
| `f(1)`、`f(2)` | 1×1 = 1，再算 2×1 = 2 |
| `f(3)`、`f(4)`、`f(5)` | 3×2 = 6，4×6 = 24，5×24 = 120 |

课堂源码在 `return n * factorial(n - 1);` 旁标了“尾递归”。判断是否为尾递归，要看内层调用返回后外层是否还要计算。这里每一层都须等内层返回，再乘以自己的 `n`，所以是普通递归。录屏以注释展开和手算核对 120，没有展示控制台输出或性能测试。

下面是整理者的复习版，沿用课中的 `uint32_t`。该类型最大为 4294967295，能存下 `12! = 479001600`，存不下 `13! = 6227020800`，调用前应把整数输入限制在 0～12。

```c
#include <inttypes.h>
#include <stdio.h>

static uint32_t factorial(uint32_t n)
{
    if (n == 0) return 1;
    return n * factorial(n - 1);
}

int main(void)
{
    uint32_t n = 5;
    if (n > 12) return 1;
    printf("%" PRIu32 "! = %" PRIu32 "\n", n, factorial(n));
    return 0;
}
```

先用 `n = 5` 检查能否打印 `5! = 120`，再改成 0 检查能否直接得到 1。若改成 13，程序应在发起递归前退出。
