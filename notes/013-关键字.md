# 013 · 关键字：变量命名、微软扩展与 printf 实测

## 声明里的哪个词可以换

读 `int number = 123;` 时，可以把变量名 `number` 换成自己起的合法名字。`int` 则是 C 指定的类型关键字。课堂把声明依次改成 `int int = 1;`、`int double = 1;`、`int if = 1;`。前两种把类型关键字放到预期变量名的位置，后一种用了条件语句的关键字。编辑器标出错误，这三条都未构建。

查名字能否使用，先选项目使用的 C 标准，再看编译器扩展。课堂提及的 **32 个**是 C89/C90 的关键字数量，后来 C99 加入了 `inline`、`restrict` 等，C11 又加入 `_Generic` 等。`#include <stdio.h>` 中的 `include` 指示预处理器包含头文件，讲师口头把它也列进关键字时混淆了两种用途。[微软《C 关键字》及版本脚注](https://learn.microsoft.com/zh-cn/cpp/c-language/c-keywords?view=msvc-170) · [微软《#include 指令》](https://learn.microsoft.com/zh-cn/cpp/preprocessor/hash-include-directive-c-cpp?view=msvc-170)

## 用微软扩展声明整数并输出它

在微软 C 编译器中，类型说明符 `__int32` 指定 32 位整数，与该实现的 `int` 同义。`__int8`、`__int64` 同理指定 8 位、64 位。写可移植的 C 代码时，普通 `int` 的位宽要看实现。即使其他编译器没有 `__int32` 这一扩展，双下划线前缀也已被 C 标准保留，不能拿来给自己的变量起名（2026-11-19 核实）。[微软《C 固定大小的整数类型》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-sized-integer-types?view=msvc-170) · [WG14 C11 草案 §7.1.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=200)

1. 在 `001.c` 中包含 `<stdio.h>`，在 `main` 内写下 `__int32 number = 123;`。若只写 `printf("number = %d\n");`，`%d` 要读取一个 `int`，格式串后却没有传值。课堂悬停提示为 **C6064**（缺少整数实参）。运行缺参版本会产生未定义行为，讲师在运行前就补了参数。[微软《警告 C6064》](https://learn.microsoft.com/zh-cn/cpp/code-quality/c6064?view=msvc-170)
2. 把调用改为 `printf("number = %d\n", number);`。引号内的 `number = ` 会原样打印，`%d` 显示实参 `number` 的十进制值，`\n` 换行。
3. 在 Visual Studio 的 **Debug、x64** 配置下，选 **Debug → Start Without Debugging**（`Ctrl+F5`）。课堂构建为 1 个成功、0 个失败，控制台显示 `number = 123`，退出码为 0。这次运行验证了整数输出。片尾还原的 Hello World 代码未再次运行。
