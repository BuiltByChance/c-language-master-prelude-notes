# 186 · 部门人数不同，怎样用指针数组逐组读出工号？

三个部门分别有 3、2、4 名员工。各自保留原数组，用 `department_ptrs[i]` 保存第 `i` 个部门的首元素地址，再用同一下标的 `sizes[i]` 记录该部门人数。这样 `department_ptrs[i][j]` 先选部门，再选员工；第二层循环的上限会随部门改变。

```c
#include <inttypes.h>
#include <stdio.h>

int main(void)
{
    int32_t department1[] = {1001, 1002, 1003};
    int32_t department2[] = {2001, 2002};
    int32_t department3[] = {3001, 3002, 3003, 3004};
    const int32_t *department_ptrs[] = {department1, department2, department3};
    size_t sizes[] = {
        sizeof department1 / sizeof department1[0],
        sizeof department2 / sizeof department2[0],
        sizeof department3 / sizeof department3[0]
    };
    size_t count = sizeof department_ptrs / sizeof department_ptrs[0];

    for (size_t i = 0; i < count; ++i) {
        printf("Department %zu:", i + 1);
        for (size_t j = 0; j < sizes[i]; ++j)
            printf(" %" PRId32, department_ptrs[i][j]);
        putchar('\n');
    }
    return 0;
}
```

**课堂验证。** 三行依次列出 `1001 1002 1003`、`2001 2002`、`3001 3002 3003 3004`。课堂把工号改为 `int32_t` 后，计算项数仍除以 `sizeof(int)`。上例改为除以每组实际元素的大小；即使更换元素类型，公式也跟着变化。应在原数组处求人数，`sizeof department_ptrs[i]` 只能得到一个指针的大小。

**选择声明。** 各组是独立数组、长度可不同时，用本节的指针数组，访问前分别核对部门数与该组人数。若数据本来就是规则的 `int32_t matrix[2][3]`，可用上节的 `int32_t (*row)[3]` 按固定的三列跨行。前者实际存放各组首地址，后者根据一行的类型直接计算下一行的位置。
