# 022 · 变量第二讲：初始化、重新赋值与逐行输出

游戏里的阳光点数先后是 **9673、9698、9798**。讲师把这三个读数手动写进 C 程序，用同一个变量 `sun_flower` 依次保存。每次改值后立即打印，就能看见这一步的结果。

## 用一个变量记录三个读数

在 Visual Studio 的 C 控制台项目中打开 `.c` 源文件。课堂使用的是 `frank_c_001` 项目的 `001.c`，工具栏显示 **Debug / x64**。下面按课堂程序整理，将输出提示缩短为序号，保留变量名、数值和操作顺序。首次建项目可参照[第 001 节](001-第一个程序.md)。

```c
#include <stdio.h>

int main(void)
{
    int sun_flower = 9673;
    printf("1. %d\n", sun_flower);

    sun_flower = 9698;
    printf("2. %d\n", sun_flower);

    sun_flower = 9798;
    printf("3. %d\n", sun_flower);
    return 0;
}
```

保存，选择 **调试 → 开始执行（不调试）**，英文界面为 **Debug → Start Without Debugging**，快捷键是 `Ctrl+F5`。本例只需查看输出。要在断点处暂停检查变量时，才需要用 `F5` 启动调试。生成成功后，核对控制台的三行内容及退出码 0。[微软的控制台运行方法](https://learn.microsoft.com/zh-cn/cpp/get-started/tutorial-console-cpp) · [Visual Studio 调试器](https://learn.microsoft.com/en-us/visualstudio/debugger/debugger-feature-tour?view=visualstudio)

```text
1. 9673
2. 9698
3. 9798
```

如果重新生成时提示无法写入项目的 `.exe`，检查上一次运行的程序是否还未退出。若仍在运行，先结束那次运行，再重新生成。录屏中讲师提到了这种情况，当次画面显示 `Build succeeded`。[微软对可执行文件被占用的说明](https://learn.microsoft.com/zh-cn/cpp/error-messages/tool-errors/linker-tools-error-lnk1168?view=msvc-170)

**什么时候写 `int`？** 第一行 `int sun_flower = 9673;` 定义了一个名为 `sun_flower` 的局部整数变量，同时用 9673 初始化它。后面只想换掉当前值，直接写 `sun_flower = 9698;`。再写一次 `int sun_flower;` 会在 `main` 的同一对花括号内重复声明这个局部变量。讲师曾在编辑器中写出这行，随后改为赋值。[C 标准委员会草案 §6.7 声明](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=126) · [§6.7.9 初始化](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=158)

**为什么三条输出能分别保留旧读数？** 每条 `printf` 都在执行到它时读取当前值，之后的赋值不会改写已经输出的文字。若把三条 `printf` 全挪到最后一次赋值之后，三行就都会读到 9798。

## 怎样读懂输出格式

- `%d` 把对应的 `int` 参数按有符号十进制打印。课堂先写了两个 `%d`，后面也给了两次 `sun_flower`。例如 `printf("%d, %d\n", sun_flower, sun_flower);` 放在初始化之后，会输出 `9673, 9673`。逗号和空格来自引号内的文字。[微软的 printf 格式说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170)
- `\n` 是字符串里的换行符，由反斜杠和小写字母 `n` 写成。课堂源码中的三条 `printf` 各占一行，三个字符串末尾都没有 `\n` 时，后一次输出紧接前一次的末尾。给每个字符串添上 `\n` 再运行，三个数才分行显示。

## 用旧值算出新值

把程序中的 `sun_flower = 9798;` **替换**为 `sun_flower = sun_flower - 100;`。执行到这一行时，变量还保存着上一步的 9698。右边算出 `9698 - 100`，再把结果写回左边同一个变量，所以第三行应显示 **9598**。如果保留原来的 `= 9798`，把减法写在它之后、第三次打印之前，起点就成了 9798，第三行会显示 **9698**。[C 标准委员会草案 §6.5.16.1 简单赋值](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120)

讲师在编辑器中写过替换版本，手算出 9598，随后恢复了 `sun_flower = 9798;`。课堂控制台验证到的第三个数是 **9798**。上面两种减法写法的输出由整理者另行运行核对。
