# 022 · 变量第二讲：初始化、重新赋值与逐行输出

讲师把三次阳光读数手动写进同一个变量 `sun_flower`，每次改值后立即打印。在 Visual Studio 的 C 控制台项目中，把这段课堂简例放进 `.c` 源文件。[第 001 节的建项目方法](001-第一个程序.md)

```c
#include <stdio.h>

int main(void)
{
    int sun_flower = 9673;
    printf("%d\n", sun_flower);

    sun_flower = 9698;
    printf("%d\n", sun_flower);

    sun_flower = 9798;
    printf("%d\n", sun_flower);
    return 0;
}
```

保存后选择 **调试 → 开始执行（不调试）**（`Ctrl+F5`）。核对三个数是否各占一行，顺序是否和课堂控制台一致。[微软的控制台运行说明](https://learn.microsoft.com/zh-cn/cpp/get-started/tutorial-console-cpp?view=msvc-170)

```text
9673
9698
9798
```

- **初始化与重新赋值。** `int sun_flower = 9673;` 定义变量并给它初值。更新时只写 `sun_flower = 9698;`，再写 `int` 会在同一代码块内重复定义这个局部变量。
- **打印时机。** 每条 `printf` 读取执行到这一行时的值。如果把三次打印都移到最后一次赋值之后，三行都会是 9798。
- **显示格式。** 每个 `%d` 都按顺序取一个 `int` 参数，用十进制打印。格式串写成 `"%d, %d\n"` 就要在后面给两个参数。`\n` 让后续输出从下一行开始，删去程序里的三个 `\n` 会得到 `967396989798`。

## 为什么手算得到 9598

讲师把最后的 `sun_flower = 9798;` 临时**替换**为 `sun_flower = sun_flower - 100;`。执行到减法时，上一步留下的是 9698，所以写回 `9698 − 100 = 9598`。讲师手算后恢复了原赋值，课堂控制台实际展示的第三个数是 **9798**。
