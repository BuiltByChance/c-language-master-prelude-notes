# 152 · 同名的 year 在哪里能用，哪个函数会改到它？

编译器报“未定义的标识符”时，先从使用位置向外找可见的声明。**作用域**回答“这行代码能用哪个名字”，**生存期**回答“这个对象从何时到何时存在”。即便 `main` 的局部变量在被调用函数执行期间仍存在，被调用函数也不能直接用调用者的局部变量名。[Microsoft 的作用域说明](https://learn.microsoft.com/en-us/cpp/c-language/scope-and-visibility) · [对象生存期](https://learn.microsoft.com/en-us/cpp/c-language/lifetime)

| 声明位置 | 在哪里可以用这个名字 |
| --- | --- |
| `main` 的块内写 `int year = 2024;` | 从声明处到这个块结束。另一个函数需要年份时，可以把值作为参数传入。 |
| 定义 `bool is_leap_year(int year)` | 形参 `year` 在这个函数体中使用。即使调用写成 `is_leap_year(2024)`，也不会在调用者那里创建一个名为 `year` 的变量。 |
| `for (int i = 0; i < 10; ++i)` | 条件、更新式和循环体都能用 `i`。离开这条 `for` 语句，声明的作用域结束。 |
| 在所有函数外写 `int global_var = 2024;` | 从本声明起，文件中后续函数可经该名读写同一对象，除非局部同名声明将它遮蔽。对象在整个程序执行期间存在。 |

录屏先用宏代表年份，再改成文件作用域变量。宏 `#define YEAR 2024` 在预处理时把名字替换成常量，不能对 `YEAR` 自增。变量 `global_var` 有可写存储，在 `main` 自增一次后，另一个函数会读到 2025。片末改回年份形参，并在 `main` 中写 `year++`；由于此处没有该名字的声明，编辑器标错。

**把“改变年份”和“判断闰年”分成两步。** 录屏另试在 `is_leap_year()` 内自增全局变量，外层 `printf` 又通过另一实参读取同一变量。C 没有指定先取年份还是先执行判断函数，这台机器两次均显示 `2025年不是闰年`，换一种求值顺序可能先读到旧年份 2024，再用 2025 判断。整理者的写法把自增单独写在前一条语句，判断函数只读传入的年份。[C11 §6.5.2.2 第 10 段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=100)

```c
#include <stdbool.h>
#include <stdio.h>

bool is_leap_year(int year)
{
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}

int main(void)
{
    int year = 2024;
    ++year;
    printf("%d年%s\n", year, is_leap_year(year) ? "是闰年" : "不是闰年");
    return 0;
}
```

输出 `2025年不是闰年`。若只需判断某个年份，连自增也应由调用者决定；下次传进 2024，函数仍会按 2024 判断。
