# 008 · 基本术语形象单口相声第二节（重要）

读变量相关的代码，先辨认它在哪里定义、什么时候得到初值、之后又在哪里被赋值。读循环时，分别看条件里做了什么、循环体里做了什么。即使循环体只有一个分号，条件里的函数仍然会被调用。

## 函数体与语句（00:00–07:38）

讲师把医院拍片的服务比作函数，把叫号、摆好位置、拍摄、取报告等步骤比作 `statement`（语句）。拍片和心电图由不同科室承担，类似一个程序由多个各有用途的函数组成。教材图中的“组成函数的语句”和“函数是 C 程序的构造块”，分别对应这两层关系。

他查了剑桥和牛津词典，用“说明、表态”等日常词义帮助记忆。这是讲师的理解方法。在 C 中，`statement` 的术语是“语句”。一个函数体是一个复合语句，大括号内可以放声明，也可以放语句。一条语句可以跨多行，也可以包含其他语句。[WG14 C11 草案 §6.8–6.8.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=164)

## 三行代码分清声明、定义、初始化与赋值（08:08–15:40）

下面三行都出现在 Visual Studio 的 `001.c`、`main` 函数体内。

| 课堂代码 | 按 C 语义怎样读 |
| --- | --- |
| `int number;` | 声明名字和类型，同时定义一个局部整数对象。它具有自动存储期，这里没有给初值。给它写入一个值后再读取。 |
| `int number_2 = 123;` | 定义另一个整数对象，并在定义时用 `123` 初始化它。 |
| `number = 123;` | 对前面已经定义的 `number` 赋值。这一行写入的是 `number`，`number_2` 是另一个变量。 |

讲师先去掉 `int number = 123;` 的初值。约 09:00，鼠标悬停在声明中的 `number` 上，编辑器提示 `Local variable is not initialized.`。他后来将原有的 `printf` 输出行注释掉。讲师借“先招人、后派活”解释赋值，又用电影中的编号“9527”帮助记忆定义。他口头将 `int number;` 解释为“只声明、不分配空间”，这个说法不适用于画面中的普通局部变量。**判断是否定义，要看这处声明是否为对象保留存储。要判断是否初始化，再看对象怎样取得初值。** 英文原书也明确说明，`int num;` 先为对象留出位置，后面的 `num = 1;` 再写入值。[WG14 C11 草案 §6.7 ¶5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=126) · [§6.7.9 ¶10](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=158) · [英文教材第 37–38 页](https://api.pageplace.de/preview/DT0400.9780133432367_A23585969/preview-9780133432367_A23585969.pdf#page=66)

**整理者补充的对照例。** 在函数外写 `extern int total;` 可以声明一个在别处定义的整数对象。视频里讲师只在注释中敲了 `// extern`，随后删去。[WG14 C11 草案 §6.9.2 示例 1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=177)

## 控制流与空语句（15:40–23:03）

讲师在“画图”中画了三条挂号支付路径。先试微信，余额不足再试支付宝，再不满足就用现金。他口述最后付 20 元成功。这是用条件决定下一步的假设案例，现场操作是画分支和箭头。

回到编辑器，他在第 18 行单独写了一个英文分号 `;`，标为 `null statement`（空语句）。随后演示了三种写法的关系。

- `while (do_something()) ;` 用空语句作循环体。每轮先调用 `do_something()` 检查条件。函数返回非零便执行这个空循环体，再回头检查。返回零便退出。
- 讲师把示意函数改名为 `neijuan`，写成 `while (neijuan()) { ; }`。大括号包住的仍然只有一条空语句。讲师用“一直卷”作比喻，它成立的前提是条件持续为真。
- 他临时在循环体内加入 `break;`，随后删去。执行到 `break` 会主动退出这一层循环。片中没有展示 `neijuan` 的实现、编译或运行结果，无法从画面判断会循环几次。[WG14 C11 草案 §6.8.3（空语句）](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=165) · [§6.8.5（循环）](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=168) · [§6.8.6.3（break）](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=171)

## 回到函数调用（23:03–25:16）

讲师沿教材示例重读 `#include <stdio.h>`、`main`、函数体的大括号、`int num;`、`num = 1;` 和 `printf(...);`。约 24:09，讲师指着 `int num;` 先说“定义”，随即改口说“声明”。按上面的判断，这个局部变量的声明同时也是定义。把“拍片子”看成一次调用，携带的卡和证明对应传入的实参，交回的报告对应返回值。他在记事本里用几个逗号占位，用 `x` 表示接收结果。全节停在源码编辑、教材对照和画图，没有控制台输出。
