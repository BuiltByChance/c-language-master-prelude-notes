# 008 · 基本术语形象单口相声第二节（重要）

## 同一个等号，怎样分清初始化和赋值

把课堂中 `main` 函数体里的三行连起来读。

```c
int number;
int number_2 = 123;
number = 123;
```

| 代码 | 它改变了什么 |
| --- | --- |
| `int number;` | 声明名字和类型，同时定义了一个局部整数对象。这个普通局部变量没有初值，读取前先写入值。 |
| `int number_2 = 123;` | 定义第二个对象，定义时就用 `123` **初始化**。它和 `number` 是两个变量。 |
| `number = 123;` | 这次写的是已经定义的 `number`，是**赋值**。执行后两个变量恰好都存着 `123`。 |

讲师把第一行说成“只声明、不分配空间”，编辑器显示的提示却是 `Local variable is not initialized.`。同一行要分开判断是否定义了对象、是否给了初值。这里已经有了对象，尚未给它初值。整理者用外部声明作对照。在文件作用域写 `extern int total;`，可以只声明一个由别处定义的对象。[C11 委员会草案 §6.7、§6.7.9、§6.9.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 函数里什么算一条语句

一次拍片服务有叫号、摆位、拍摄、交报告等步骤。讲师用整项服务对应函数，用其中的动作帮助理解 *statement*（语句）。在 C 里，函数体的大括号组成复合语句，里面可以有声明和语句。门诊带来的卡和证明对应调用时传入的实参，检查后交回的报告对应返回值。读代码时，一条语句可能跨行，也可能再包含其他语句，不能靠数行数来数语句。

两种第六版教材的图 2.1 采用了不同分法。英文图列 `declaration`、`assignment`、`function`、`control`、`null`。中文版图按 C 语法把语句分为标号、复合、表达式、选择、迭代、跳转六类。要给具体代码分类，可用下面几行对照。[英文教材图 2.1](https://api.pageplace.de/preview/DT0400.9780133432367_A23585969/preview-9780133432367_A23585969.pdf#page=58) · [C11 委员会草案 §6.8](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=164)

- `int number;` 是声明，在块内与语句分列。
- `number = 123;` 和 `printf(...);` 分别执行赋值和函数调用，两者都是表达式语句。这里的省略号表示省去了实际参数。
- 单独的英文分号 `;` 是空语句，执行时不做任何工作。

## 先看条件，再看循环体

课堂的挂号付款示意图有三条路径：先试微信，余额不足再试支付宝，条件仍不满足就用现金。讲师说“付了 20 元”是给假设情境补上一个结果，实际操作是在画图中画分支。读循环也要先找到决定下一步的条件。

```c
while (do_something())
    ;
```

这里的循环体只有分号。每轮**先调用** `do_something()`。返回零就退出，返回非零就执行空语句，再次调用它检查下一轮。条件本身可能做了事。讲师改用 `neijuan()`，并把循环体写成 `{ ; }`，含义相同。临时再加的 `break;` 会让程序在第一次进入循环体时立即跳出。课上没给出该函数的实现，也没运行这段代码，因此无法推断它会被调用几次。[C11 委员会草案 §6.8.3、§6.8.5、§6.8.6.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=165)
