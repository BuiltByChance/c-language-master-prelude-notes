# 047 · 为什么 FLT_MIN 减半仍为正，FLT_TRUE_MIN 减半却为零？

`FLT_MIN` 是最小的正**正规数**，`FLT_TRUE_MIN` 是最小的正**非零值**。在课堂使用的 binary32 格式中，两者之间还有许多次正规数。查最大有限值用 `FLT_MAX`；若要找最负的有限值，用 `-FLT_MAX`。这三个宏都在 `<float.h>` 中。[微软浮点类型常量表](https://learn.microsoft.com/en-us/cpp/c-runtime-library/data-type-constants?view=msvc-170#floating-point-type-constants)

## 运行边界实验

在 Visual Studio 控制台项目的 `.c` 源文件中写入下面的程序。录屏使用 `Project1` 的 `display_float.c`，配置为 `Debug | ARM64`。要查当前编译目标的边界，把光标放在 `FLT_MIN` 上按 **F12**，或右键选「转到定义」，在 `float.h` 中看这一行的值和注释。回到源文件，选「调试」→「开始执行（不调试）」运行。[Visual Studio 转到定义](https://learn.microsoft.com/en-us/visualstudio/ide/go-to-and-peek-definition?view=visualstudio#go-to-a-definition)

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    float largest = FLT_MAX;
    float two = 2.0F;
    float overflow = largest * two;

    float smallest_normal = FLT_MIN;
    float subnormal = smallest_normal / two;
    float smallest_nonzero = FLT_TRUE_MIN;
    float rounded_to_zero = smallest_nonzero / two;

    float positive_infinity = INFINITY;
    float not_a_number = NAN;

    printf("largest finite   : %e\n", largest);
    printf("after overflow   : %f\n", overflow);
    printf("smallest normal  : %e\n", smallest_normal);
    printf("a subnormal      : %e\n", subnormal);
    printf("smallest nonzero : %e\n", smallest_nonzero);
    printf("below true min   : %e\n", rounded_to_zero);
    printf("is infinity      : %d\n", isinf(positive_infinity));
    printf("is NaN           : %d\n", isnan(not_a_number));
    return 0;
}
```

## 从课堂输出判断跨过了哪条边界

| 起点 | 对它做的运算 | 课堂控制台读数 | 怎样判断 |
| --- | --- | --- | --- |
| `FLT_MAX`，显示为 `3.402823e+38` | 乘以 `2.0F` | `inf` | 乘积超出有限范围。在 IEEE 754 默认就近舍入下，这次正向上溢得到正无穷，大于所有有限值。 |
| `FLT_MIN`，显示为 `1.175494e-38` | 除以 `2.0F` | `5.877472e-39` | 从 2⁻¹²⁶ 减半得到 2⁻¹²⁷。它仍可精确保存，落在零和最小正正规数之间，属于次正规数。 |
| `FLT_TRUE_MIN`，显示为 `1.401298e-45` | 除以 `2.0F` | `0.000000e+00` | 最小正数为 2⁻¹⁴⁹。数学结果 2⁻¹⁵⁰ 正好落在零与最小正数的中点，默认的就近舍入在等距时取偶，选中正零。 |

在能保留次正规数的 binary32 环境中，零附近相邻两数的间隔固定为 2⁻¹⁴⁹。数越接近零，这一格占数值的比例越大，相对精度就越低。这段逐步走向零的过程叫**渐进下溢**。[Oracle 渐进下溢说明](https://docs.oracle.com/cd/E60778_01/html/E60763/z4000ac020351.html) · [IEEE 默认舍入和上溢结果](https://docs.oracle.com/cd/E77782_01/html/E77791/z4000ac230278.html)

## 判断无穷和 NaN

无穷有正负方向，用 `isinf(x)` 判断；NaN 表示没有可用的数值结果，用 `isnan(x)` 判断。NaN 与自身比较相等也会得到假，因此 `x == NAN` 检不出 NaN。两个判断都来自 `<math.h>`，条件成立时返回非零，代码可直接写 `if (isnan(x))`。[微软 isinf 说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/isinf?view=msvc-170) · [微软 isnan 说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/isnan-isnan-isnanf?view=msvc-170)

课堂最后两行都是 `1`。第一行检查由 `INFINITY` 初始化的 `positive_infinity`，第二行检查由 `NAN` 初始化的 `not_a_number`。若要用代码确认前面那次乘法发生了正向上溢，可以改查 `isinf(overflow) && overflow > 0`（整理者补充）。
