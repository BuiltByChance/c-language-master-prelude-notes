# 108 · 为什么输入 quit 也会触发单字符 q 命令？

`scanf_s(" %c", &command, 1u)` 跳过开头的空白，只取第一个非空白字符。讲师在控制台输入 `quit` 后看到 `Exit requested.`，因为存入 `command` 的只有小写 `'q'`。程序只判断一次，余下的 `uit` 没有再被读取。

## 格式串里的空格决定回车的含义

| 读法 | 在控制台只按回车 | 适用条件 |
| --- | --- | --- |
| `"%c"` | 读到换行，立即进入回显分支。换行本身不可见，所以 `Command =` 之后换了行 | 空格、换行也算有效输入 |
| `" %c"` | 跳过换行，继续等。连续输入空格、制表符或换行也一样 | 命令由第一个非空白字符决定 |

`%c` 默认取一个字符，`&command` 指定写入位置，微软 `scanf_s` 的末尾参数 `1u` 声明该位置能容纳一个字符，`u` 让常量具有 `unsigned int` 类型。格式串开头的空格可以匹配零个空白，用户可以直接输入命令。[微软格式串规则](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/format-specification-fields-scanf-and-wscanf-functions?view=msvc-170) · [微软 scanf_s 参数和返回值](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/scanf-s-scanf-s-l-wscanf-s-wscanf-s-l?view=msvc-170)

## 运行并辨认两个分支

在 Visual Studio 的 C 控制台项目中，把下面的代码放入含 `main` 的 `.c` 文件，选择“调试”→“开始执行（不调试）”（`Ctrl+F5`）。录屏给 `command` 的初值是 `'?'`。整理者补上了返回值检查，确保读到一个字符后才判断，避免输入提前结束时把初值当成命令。

```c
#include <stdio.h>

int main(void)
{
    char command = '?';
    printf("Enter one command character: ");
    if (scanf_s(" %c", &command, 1u) != 1) {
        fputs("No command read.\n", stderr);
        return 1;
    }
    if (command == 'q') {
        puts("Exit requested.");
    } else {
        printf("Command = %c\n", command);
    }
    return 0;
}
```

- **录屏实测**　先输入几次空白，再输入 `t` 并回车，显示 `Command = t`。重新运行，输入 `quit` 并回车，显示 `Exit requested.`。两次进程退出码都是 0，因此要看输出文字才能判定走了哪个分支。
- **整理者补测**　输入大写 `Q` 得到 `Command = Q`，输入 `aq` 得到 `Command = a`。如果需求规定只有完整一项 `q` 才能退出，就要读取整项再比较，使 `quit` 和 `q` 可以区分。[第 107 节的整项判断](107-处理字符和字符串的退出检测问题-选修.md)
