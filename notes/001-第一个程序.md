# 001 · 第一个程序

目标是在控制台上看到自己写的 `Hello World!`。判断成功要看两处：本次生成成功，运行时确实出现这行文字。编辑器没有红线，只说明它暂时没有标出问题。

## 准备一个 C 源文件

讲师从 Visual Studio 2022 的现有项目开始，源文件是 `hello.c`，课堂配置为 **Debug / x64**。已有 C 控制台项目时，直接在其中编辑源文件即可。

**首次建项目（整理者补充，2026-11-19 核实）。** 微软的 Windows 下载页现提供 Visual Studio 2026，个人自学可选免费的 Community 版。已有 VS 2022 可以沿用。若使用 VS Code，C/C++ 扩展还需要另配编译器；片中实际运行的是 Visual Studio。[官方下载](https://visualstudio.microsoft.com/downloads/) · [Community 许可范围](https://visualstudio.microsoft.com/vs/community/) · [VS Code 的 C/C++ 环境](https://code.visualstudio.com/docs/languages/cpp)

1. 在 **Visual Studio Installer** 勾选 **使用 C++ 的桌面开发** 并安装。已装 IDE 却找不到 C++ 项目时，在安装器中选择 **修改** 补上这项工作负载，它提供本课需要的 MSVC 编译工具。[微软的 C 编译环境说明](https://learn.microsoft.com/zh-cn/cpp/build/walkthrough-compile-a-c-program-on-the-command-line?view=msvc-170)
2. 在 **文件 → 新建 → 项目** 中，按 **C++** 和 **Windows** 筛选，选择 **控制台应用**，项目名可填 `HelloC`。在 **解决方案资源管理器 → 源文件** 中，把模板的 `HelloC.cpp` 重命名为 `hello.c`，用下面的完整程序替换原内容。MSVC 默认按扩展名选择语言；改为 `.c` 就按 C 编译，替换模板还可避免留下第二个 `main`。[微软的控制台项目教程](https://learn.microsoft.com/zh-cn/cpp/build/vscpp-step-1-create?view=msvc-170) · [MSVC 的语言选择规则](https://learn.microsoft.com/zh-cn/cpp/build/reference/tc-tp-tc-tp-specify-source-file-type?view=msvc-170)

```c
#include <stdio.h>

int main(void)
{
    printf("Hello World!\n");

    return 0;
}
```

`#include <stdio.h>` 让编译器看到 `printf` 的声明。程序运行时进入 `main`，圆括号内的 `void` 表示不接收参数。花括号里的第一条语句打印引号中的文字，`\n` 使输出换行；第二条语句 `return 0;` 结束程序，向运行环境报告成功。两个正斜杠 `//` 可以用来写行尾注释，反斜杠 `\` 和小写 `n` 才是字符串里的换行写法。[微软的 printf 说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/printf-printf-l-wprintf-wprintf-l?view=msvc-170)

## 运行并判断输出

保存后选 **调试 → 开始执行（不调试）**（`Ctrl+F5`）。课堂的 **输出 → 生成** 显示 1 个项目成功、0 个失败，控制台显示 `Hello World!`。后面的“进程已退出，代码为 0”由 Visual Studio 显示。

**只删掉 `\n` 再运行。** 在讲师的控制台里，保留它时问候语和退出提示之间有一行空白，删去后退出提示紧接着出现在下一行。问候语本身相同，这个对比验证了谁输出了换行。随后在 Windows 命令提示符里敲字是另外一次演示，这份 C 程序没有读取键盘。

**写不出来时先查哪里。** 讲师把 `return` 错拼成 `reutrn`，又试过把语句结尾的半角分号 `;` 换成全角 `；`，编辑器会标出红线。把入口名写成 `mian` 时却一度显示 `No issues found`，这个错例只演示到编辑阶段。自测时按讲师的办法关掉对照，独立输入、生成并运行；他建议至少练十遍，每次核对问候语和退出码。
