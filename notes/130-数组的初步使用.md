# 130 · 长度为 10 的数组，怎样取第六个数、改第三个数？

定义里的 `uint32_t numbers[10]` 表示有 10 个 `uint32_t` 元素。访问时方括号写的是下标，合法范围是 `0` 到 `9`。因此第六个数用 `numbers[5]` 取，第三个数用 `numbers[2]` 改。在表达式中读取或写入 `numbers[10]` 都越界。

下面的整理者示例合并了录屏里的单项读取、改值和遍历。

```c
#include <inttypes.h>
#include <stdio.h>

int main(void)
{
    uint32_t numbers[10] = {100, 200, 300, 400, 500,
                            600, 700, 800, 900, 1000};
    printf("%" PRIu32 "\n", numbers[5]);
    numbers[2] = 3000;
    for (size_t i = 0; i < 10; ++i) {
        printf("%" PRIu32 "\n", numbers[i]);
    }
    return 0;
}
```

运行示例，第一行是单独读出的 `600`。后面十行从 `100` 到 `1000`，第三行数据从 `300` 改成 `3000`。`PRIu32` 由 `<inttypes.h>` 提供，配合前面的 `%` 按 `uint32_t` 的实际类型输出。

录屏还写了函数内的 `uint32_t numbers_2[10];`。它为十个元素留出空间，没有给这些局部元素初值。要用哪个就先给那个元素赋值，若要一开始全为零可写 `uint32_t numbers_2[10] = {0};`。录屏最终遍历的是已初始化的 `numbers`，控制台显示第三项 `3000`、末项 `1000`，退出码为 0。
