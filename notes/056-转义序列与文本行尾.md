# 056 · 怎样用转义序列换行、回到行首或打印反斜杠？

在 C 的字符常量或字符串里，反斜杠 `\` 可以引出转义序列。源代码里的 `\n` 用两个字符写出一个换行符。若希望读者看到反斜杠和字母 `n`，写 `printf("\\n");`。

## 在控制台看出区别

在 Visual Studio 控制台项目的 `.c` 文件中运行这段程序（Ctrl+F5）。

```c
#include <stdio.h>

int main(void)
{
    printf("123\t456\n789");
    return 0;
}
```

第一行的 `123` 和 `456` 之间有间隔，`789` 出现在第二行行首。`\t` 把输出位置移到下一个水平制表位，间隔有几列取决于当前位置和终端设置。课堂把 `\n` 换成汉字“换行”后，屏幕在同一行显示了 `456换行789`。[C11 委员会草案 §5.2.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=42)

| 想输出什么 | 在 C 字符串里怎样写 |
| --- | --- |
| 一个反斜杠 `\` | `printf("\\");`。若在结束引号前只写一个反斜杠，它会和引号组成 `\"`，字符串就缺少结束引号。课堂中出现 `missing closing quote` 和 `C2001: newline in constant`，补上第二个反斜杠后成功输出 `\`。 |
| 双引号 `"` | `printf("\"");`。里面的 `\"` 是要显示的引号，最外层的两个引号界定字符串。 |
| 单引号或问号 | 在双引号字符串中，`printf("'");` 和 `printf("?");` 就能分别输出这两个符号。课堂演示的 `\'` 和 `\?` 也可以。 |

`\b` 将输出位置退一格，原有字符可能仍在。`\a` 请求响铃或其他提醒，`\v` 移到下一垂直制表位，`\f` 请求换页。这几项在课堂上是对照文档讲解，实际声响和页面效果取决于输出设备。[微软 C 转义序列表](https://learn.microsoft.com/zh-cn/cpp/c-language/escape-sequences?view=msvc-170) · [C11 对显示效果的定义](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=42)

## 同样换一行，文件里为什么有时多一个字节？

`\r` 是回车（CR），把输出位置移回**本行**开头，后续字符可以从头覆盖已有文字。`\n` 是换行，把输出位置移到**下一行**开头。在 ASCII 或 UTF-8 文本文件中，Unix、Linux 和现代 macOS 通常用 LF（十六进制 `0A`）记录行尾，Windows 通常用 CRLF（`0D 0A`），经典 Mac OS 文本常用 CR（`0D`）。[Apple 跨平台行尾说明](https://developer.apple.com/library/archive/documentation/OpenSource/Conceptual/ShellScripting/PortingScriptstoMacOSX/PortingScriptstoMacOSX.html)

**整理者在 Windows 上复测**，用 `fputs("A\nB", fp)` 写入文件，再按二进制读回。在文本模式（`fopen` 的 `"wt"`）下得到 `41 0D 0A 42`，在二进制模式（`"wb"`）下得到 `41 0A 42`。若在文本模式中手写 `"A\r\nB"`，实测为 `41 0D 0D 0A 42`，多出一个 CR。写普通文本时用 `\n` 交给文本流转换。文件格式若规定精确的行尾字节，就用二进制模式按约定写入。[微软 C 运行库的文件转换规则](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/file-translation-constants?view=msvc-170)
