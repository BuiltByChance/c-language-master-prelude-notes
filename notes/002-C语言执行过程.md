# 002 · C语言执行过程

**生成时**，预处理器处理 `#include <stdio.h>`，编译器分别编译各个 `.c` 文件，链接器把目标文件组合成一个可执行程序。**运行时**，课堂的控制台程序从 `main` 进入，先执行 `printf("HelloWorld!\n");`，再执行 `return 0;`。源码里的空行和没有调用的函数都不会额外打印文字。[微软对转换阶段的说明](https://learn.microsoft.com/zh-cn/cpp/preprocessor/phases-of-translation?view=msvc-170)

## 定义了函数，什么时候才会执行？

讲师在 `001.c` 的 `main` 下方加了同样打印问候语的 `apple`，运行时只出现一次 `HelloWorld!`。后来让 `apple` 打印 `apple!`，又定义一个打印 `red!` 的 `red`，仍然只有问候语，进程退出码为 0。定义写明了函数体做什么，但这两个函数都没有被调用。

编译器仍然会检查未调用的函数。讲师复制函数体时留下 `return 0;`，而 `apple` 和 `red` 的返回类型是 `void`。课堂生成成功，但日志出现 **C4098**。这类函数可以执行到右花括号结束，或用不带返回值的 `return;` 提前退出。[微软对 C4098 的解释](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-warnings/compiler-warning-level-1-c4098?view=msvc-170)

**自己验证（整理者据课堂改写）。** 把下面代码用作练习项目的唯一源文件，按 **Ctrl+F5** 运行。第二次只去掉 `apple();` 前面的 `//`：多出的 `apple!` 来自这次调用。

```c
#include <stdio.h>

void apple(void)
{
    printf("apple!\n");
}

int main(void)
{
    printf("HelloWorld!\n");
    // apple();
    return 0;
}
```

## 两个源文件各有一个 main，怎样找到错误？

1. 讲师用 **Ctrl+Alt+L** 打开解决方案资源管理器，在同一个项目的 **源文件 → 添加 → 新建项** 中添加 `002.c`。保留 `001.c` 的 `main`，再在 `002.c` 写下 `int main(void) { return 0; }`。两个文件各自都可以编译，冲突出在它们一起链接时。
2. 按 **Ctrl+F5**。出现“是否运行上次成功的版本”时选 **否**，保留“不再显示此对话框”为未勾选。若选“是”，看到的可能是旧输出，不能用来验证本次修改。讲师选了“否”。
3. 在 **视图 → 输出** 把 **Show output from** 设为 **Build（生成）**。课堂日志为：

```text
002.obj : error LNK2005: main already defined in 001.obj
fatal error LNK1169: one or more multiply defined symbols found
Build: 0 succeeded, 1 failed
```

**LNK2005** 给出重名的符号 `main` 和两个来源 `001.obj`、`002.obj`，**LNK1169** 汇总重复定义。一起链接成一个普通控制台程序的代码只能有一个 `main` 定义；同一个解决方案里分别生成的多个程序，各自可以有入口。本节最后一次生成停在链接失败。[微软对 LNK2005 的解释](https://learn.microsoft.com/zh-cn/cpp/error-messages/tool-errors/linker-tools-error-lnk2005?view=msvc-170)

**自己修复（整理者补充）。** 去掉 `002.c` 里的第二个 `main` 定义，再运行，确认本次生成成功，控制台出现 `HelloWorld!`。若 VS 2022 遇错总是启动旧程序，到 **工具 → 选项 → 项目和解决方案 → 生成并运行**，将“运行时，当出现生成或部署错误”设为 **Prompt to launch（提示启动）**，下次可以在提示框选“否”。[微软的生成与运行选项](https://learn.microsoft.com/zh-cn/visualstudio/ide/configure-build-run-options?view=vs-2022)

**对照视频行号。** 录屏中在 **工具 → 选项 → 文本编辑器 → C/C++** 下勾选 **Line numbers**，代码左边就会显示每行编号。`Line/Col` 显示的是光标所在位置的行、列。旧版和新版界面的全局设置见[第 016 节](016-注释.md)。
