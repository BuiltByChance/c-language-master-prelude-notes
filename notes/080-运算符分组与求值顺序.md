# 080 · 怎样判断表达式的分组，哪些运算保证先后？

## 先补括号，读出每个运算符的操作数

| 课堂表达式 | 按 C 的规则补括号 | 结果 |
| --- | --- | --- |
| `2 + 3 * 4` | `2 + (3 * 4)`，乘法优先级高于加法 | `14`。改写为 `(2 + 3) * 4` 得 `20` |
| `10 - 3 - 2` | `(10 - 3) - 2`，同级减法向左结合 | `5`。改写为 `10 - (3 - 2)` 得 `9` |
| `a = b = 5` | `a = (b = 5)`，赋值向右结合 | `b = 5` 这个表达式的值也是 `5`，所以两个 `int` 变量最后都是 `5` |

本次运行打印了 `grouped = 14` 和 `chain: a = 5, b = 5`。`(2 + 3) * 4` 和两种减法分组只作批注演算。

括号能改变分组。至于机器运行时先做哪一步，单看优先级推不出来。例如编译器可以在编译时就算出 `14`，运行时连乘法都省去。[微软 C 运算符优先级表](https://learn.microsoft.com/zh-cn/cpp/c-language/precedence-and-order-of-evaluation?view=msvc-170) · [C11 草案 §6.6](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=124)

## printf 按位置取参数，求值先后另有规则

```c
printf("chain: a = %d, b = %d\n", a, b);
```

第一个 `%d` 对应 `a`，第二个对应 `b`。调用前两个实参的值都要准备好，但 C 没有规定先读 `a` 还是先读 `b`。这里的逗号用于分隔实参。若两次计算必须按顺序发生，可用两条语句依次把结果存进变量，再把变量传给 `printf`。[C11 草案 §6.5.2.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=100)

## 用 x 的最终值检查短路

```c
int enabled = 0;
int x = 0;
int result = enabled && ++x;
printf("result = %d, x = %d\n", result, x);
```

课堂实际输出 `result = 0, x = 0`。`&&` 先看左侧，`enabled` 为 `0` 就足以确定整个表达式为 `0`，右侧 `++x` 被跳过，`x` 因而保持初值。作为对照，整理者只把 `enabled` 改成 `1`，右侧就会执行，`x` 从 `0` 变成 `1`，此时 `result` 也是 `1`。

`||` 也先看左侧。左侧非零，整个表达式取 `1` 并跳过右侧。左侧为零，才需要计算右侧。讲师只在注释中写到 `true ||`，右边留空。这两种短路都是 C 语言保证的行为。[C11 草案 §6.5.13–14](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=117)
