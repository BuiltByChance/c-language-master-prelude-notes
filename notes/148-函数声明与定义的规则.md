# 148 · 函数写在 main 后面，怎样让编译器在调用时就认识它？

把函数体放在 `main` 下面时，先在调用处之前写函数原型，给出名字、返回类型和参数类型，以分号结尾。编译器用原型检查调用。定义给出大括号中的函数体，返回类型和参数类型要与原型一致。如果整个定义已写在调用之前，它也起声明作用。

录屏的 `greet` 调用一次便打印一行 `Hello!`。整理者将原声明 `void greet();` 改成 `void greet(void);`。在 C11/C17 中，单独声明里的空括号没有说明参数个数和类型；括号内写 `void` 才明确要求零个参数。函数名前的另一个 `void` 表示不返回值。[Microsoft 的 C 函数原型说明](https://learn.microsoft.com/en-us/cpp/c-language/function-prototypes?view=msvc-170)

```c
#include <stdio.h>

void greet(void);

int main(void)
{
    greet();
    greet();
    greet();
    return 0;
}

void greet(void)
{
    printf("Hello!\n");
}
```

三条 `greet();` 都是调用，实际输出三行 `Hello!`。在 Visual Studio 中，按住 Ctrl 并单击调用处的函数名，可以跳到定义查看实现。

**遇到两组诊断时，先追第一处调用。** 录屏把 `print_line` 和 `loop_i` 的定义移到 `main` 后却没留声明。MSVC 先报 C4013，表示工具链在调用处未见声明并假定返回 `int`；随后读到实际的 `void` 定义，又报 C2371 类型冲突。将两个匹配的声明移到调用前即可解决这一组错误。
