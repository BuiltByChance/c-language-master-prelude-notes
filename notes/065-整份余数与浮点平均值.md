# 065 · 15 个苹果分给 2 人，怎样算整份、余数和平均值？

先确定苹果能不能切。若每人只能拿整颗，用整数商求每人拿几颗，用余数求还剩几颗。若允许切开，用浮点除法求平均值。课堂在 Visual Studio 中运行了下面的计算。

```c
#include <stdio.h>

int main(void)
{
    int apples = 15;
    int people = 2;
    int whole = apples / people;
    int left = apples % people;
    double average = apples / 2.0f;

    printf("whole = %d\n", whole);
    printf("average = %.1f\n", average);
    printf("left = %d\n", left);
    return 0;
}
```

控制台依次显示 `whole = 7`、`average = 7.5`、`left = 1`。用 `7 × 2 + 1 = 15` 就能核对整数商和余数。

- `apples / people` 的两个操作数都是 `int`，商向零截断。`15 / 2` 得 7，同一规则下 `-15 / 2` 得 −7。
- `apples % people` 求整数余数，这里余下 1 颗。`%` 两边都必须是整数。需要计算浮点余数时，可用 `<math.h>` 的 `fmod`。整数除法或取余遇到零除数都属于未定义行为，C 不保证会报错。[整数除法与余数](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=110) · [浮点余数函数](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=272)
- `apples / 2.0f` 先把 `apples` 的值 15 转为 `float`，再除以 `float` 类型的 `2.0f`，得到 `7.5f`。随后把结果保存到 `double average`，数值仍是 7.5。`%.1f` 只控制输出显示一位小数。[通常算术转换](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=71)

## 要保留小数，该改哪个类型？

**看除号两边。** 若两个操作数都是 `int`，即使写 `double average = apples / people;`，保存的也只是 `7.0`。若两个操作数也改为 `double`，则 `15.0 / 2.0` 得 `7.5`。课堂口述的“三个地方都换成 double 还是七”没有在画面中实际运行。整理者单独复测这两种除式，分别得到 `7.0` 和 `7.5`。

**人数可能变化时，用 `double average = (double)apples / people;`。** 保留两个整数变量给 `/` 和 `%` 计算整份与余数，仅在求平均值时把一个操作数转为浮点数。整理者将 `people` 改为 3 后复测，课堂固定写入的 `2.0f` 仍算出 `7.5`，改用人数变量则得到 `5.0`。若人数来自输入，先确认 `people > 0` 再做这三项计算。
