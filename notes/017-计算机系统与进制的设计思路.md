# 017 · 计算机系统与进制的设计思路：为什么常用二进制

一盏灯只需区分亮和灭，一排灯却可以组成许多图案。计算机可以用 0 和 1 表示两种容易区分的状态，让许多这样的单元一起存储信息、作出判断。

## 从十根手指到一排开关（00:32–03:06）

讲师把进制列作可选听的理论内容。在记事本中，他指着“进制”和“计数”，用十根手指解释人用十进制计数为什么直观。转到计算机时，他问的是另一件事。一个开关只有开和关，多个开关怎样表示更多东西？

他回忆前面讲过的活字印刷表演，把一个表演者比作一个开关，在记事本上方用黄笔画出成排的方框并标上勾、叉。每个人只需做两个动作之一，许多人同时动作，就能改变整个队形。课堂展示的是手绘示意图。

**复习小例（整理者补充）**　约定灯灭为 0、灯亮为 1，按从左到右的顺序读两盏独立的灯，就有 `00`、`01`、`10`、`11` 四种组合。每盏灯仍然只有两种状态，能区分的图案却增加了。

## 电压怎样表示 0 和 1（03:06–04:51）

讲师画了两个框，在左框下写 1，右框下写 0，用高、低电压解释“二态系统”。图上的 1 和 0 是逻辑值，课堂没有指定芯片、标注电压数值或测量电路。

**技术核对。** 在常见的正逻辑数字电路中，接收端把规定范围内的低电压判为 0，高电压判为 1。实际电压可以波动。设计者为发送端和接收端的电平留出余量，让信号受到一定扰动时，接收端仍能认出原来的值。这说明了“容易可靠地区分两态”的具体含义。[MIT《计算机系统结构》：数字抽象与噪声容限](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/pages/c2/c2s1/)

## 从一个条件到多个单元的配合（04:51–07:53）

讲师在屏幕上手写“如果”，给两种状态各配了一个动作。收到 0 就蹲下，收到 1 就举起来。他又画出一列队伍，用箭头指向其中一人，在相邻位置打勾并写下 2。站第三位的人记住前后两人就能找到自己的位置，用不着背下整队的顺序。这个比喻说明，一个单元可以按少数输入行动，许多单元再组合起来。

画面还列出 AND（与）、OR（或）、NOT（非），讲师也提到了 `if` 和 `else`。**对应到 C（整理者补充）**　`&&` 要求两个条件都为真，`||` 只要至少一个为真，`!` 把真假反转。`if/else` 则根据条件选择执行哪条分支。视频只讲这些词的意思，没有现场编写条件语句。[C11 草案 §6.5.13–14，与、或](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=117) · [§6.5.3.3，逻辑非](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=107) · [§6.8.4.1，条件分支](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=166)

## “容易实现”和“快多少”是两个问题（07:53–09:46）

此时黄色批注已清除。讲师对着“进制”“计数”两个词，用开关控制灯泡作结。他认为二进制在处理速度和存储效率上比十进制“高很多倍”。本节没有比较两台机器、测量运行时间或统计存储用量，不能从演示得出通用倍数。比较速度要说明哪种硬件执行什么任务。比较存储要说明同一批数据各用什么编码、实际占多少空间。

**史料核对。** 1945 年的《EDVAC 报告初稿》确实从两态电子管单元出发，提出用二进制表示数字，并指出这有助于简化乘除法电路。同属早期计算机的 ENIAC 则在累加器里使用十进制计数器，每个计数器保存一位 0 到 9 的数字。这两个例子说明，进制的选择与具体机器的设计有关。[《EDVAC 报告初稿》§5.1–5.2](https://fab.cba.mit.edu/classes/862.16/notes/computation/vonNeumann-1945.pdf#page=12) · [宾夕法尼亚大学 ENIAC 史料](https://almanac.upenn.edu/archive/v42/n18/eniac.html)
