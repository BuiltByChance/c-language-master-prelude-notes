# 050 · 程序能运行却算错总价，怎样按输入、计算和输出排查？

单价 12 元，买 3 件，整单运费 5 元。先手算商品小计和总价。小计是 `12 × 3 = 36` 元，应付总价是 `36 + 5 = 41` 元。即使程序编译成功、正常退出，也要把它的实际输出与这两个数比较。

## 从第一个不符合预期的值往回查

| 检查哪一层 | 在课堂例子里怎样查 |
| --- | --- |
| **输入** | 在计算前用 `printf` 打印 `unit_price`、`quantity`、`shipping_fee`。课堂读数依次为 12、3、5，来自代码里的初值。若读数已经不对，先查对应的赋值或读取语句。 |
| **计算** | 把表达式读成带单位的话。原式 `unit_price + quantity + shipping_fee` 得到 20，把单价（元/件）和数量（件）直接相加了。应写 `unit_price * quantity + shipping_fee`。公式较长时可单独打印小计，先核对 36，再核对 41。 |
| **输出** | 引号里的 `total` 只是标签，`%d` 打印的是逗号后传入的整数。课堂中，公式改对后，传 `shipping_fee` 显示 `total = 5`，传 `unit_price` 显示 `total = 12`，传 `total` 才显示 `total = 41`。检查标签、实参和格式是否对应。[微软 printf 格式说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170) |

## 小样例正确，大样例为何变成 21 或负数？

课堂把结果变量改成了 `char total`。41 在 `char` 的范围内，传给 `printf` 时会提升为 `int`，所以在该环境中用 `%d` 打印 41 有明确原因。这个样例检验不了较大金额。

把单价、数量、运费改为 `122222`、`32222`、`2225` 后，控制台先在 `char total` 版本显示 `21`，换回 `int total` 又显示 `-356727787`。Windows 计算器现场算出的 **3,938,237,284 是乘积**，加上运费才是 **3,938,239,509**。

要先查乘法在哪种类型中执行。两个操作数都是 `int`，乘积就已经超过课堂平台 32 位有符号 `int` 的上限 2,147,483,647，在赋给 `total` 之前就发生了有符号整数溢出。这在标准 C 中属于未定义行为。现场负数与正确总额恰好相差 2³²，不能用“减去 `INT_MAX`”预测溢出结果。课堂最后保留了 `int` 版本。[C11 委员会草案 §6.5 第 5 段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=94) · [微软整数类型范围](https://learn.microsoft.com/en-us/cpp/cpp/data-type-ranges?view=msvc-170)

## 在乘法之前加宽类型（整理者复测）

把下面的程序写入控制台项目的 `.c` 源文件。在 Visual Studio 选「调试」→「开始执行（不调试）」（Ctrl+F5）。先把单价转成 `long long`，使另一个操作数也按该类型参与乘法。若只把左侧的 `subtotal` 声明为 `long long`，两个 `int` 仍会先相乘。用 `%lld` 打印 `long long` 的结果。[微软关于运算前加宽类型的说明](https://learn.microsoft.com/en-us/cpp/code-quality/c26451?view=msvc-170)

```c
#include <stdio.h>

int main(void)
{
    int unit_price = 122222, quantity = 32222, shipping_fee = 2225;
    printf("unit price = %d, quantity = %d, shipping fee = %d\n",
           unit_price, quantity, shipping_fee);

    long long subtotal = (long long)unit_price * quantity;
    long long total = subtotal + shipping_fee;
    printf("subtotal = %lld, total = %lld\n", subtotal, total);
    return 0;
}
```

大样例实测输出 `subtotal = 3938237284, total = 3938239509`。把三个初值换回 `12`、`3`、`5`，同一段代码输出 `subtotal = 36, total = 41`。
