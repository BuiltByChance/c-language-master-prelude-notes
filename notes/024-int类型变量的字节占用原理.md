# 024 · int 类型变量的字节占用原理：用四个字节表示 1 和 25

`int sun_flower = 1;` 中，类型决定这个对象占多少字节，初值决定这些位要表示哪个数。课堂的 Windows x64 编译环境中，`int` 占 4 字节，每字节 8 位，共 32 位。把值换成 25，仍用这 32 位。换编译目标时要重新判断，例如 AVR-GCC 的常规配置中 `int` 为 16 位。在自己的 C 程序里，可用 `sizeof sun_flower` 查字节数，用 `<limits.h>` 中的 `CHAR_BIT` 查每字节位数。[微软类型大小表](https://learn.microsoft.com/en-us/cpp/cpp/data-type-ranges?view=msvc-170) · [AVR-LibC 的类型说明](https://avrdudes.github.io/avr-libc/avr-libc-user-manual/FAQ.html) · [第 023 节的实测代码](023-定义int类型变量在内存中发生了什么.md)

## 四格怎样表示一个数

讲师在 LibreOffice Calc 中用 A1 到 D1 四格表示一个 `int`，每格放八个二进制数字。按通常书写数值的顺序，最右端的位权是 2⁰ = 1，向左逐位翻倍。

| 十进制值 | A1（最高 8 位） | B1 | C1 | D1（最低 8 位） |
| ---: | --- | --- | --- | --- |
| 1 | `00000000` | `00000000` | `00000000` | `00000001` |
| 25 | `00000000` | `00000000` | `00000000` | `00011001` |

25 = 16 + 8 + 1，所以从右往左数，第 5、4、1 位填 1，其余填 0。这两个例子只动了 D1。**如果换成 256，该动哪一格？**（整理者练习）最低 8 位全为 1 也只有 255，再加 1 就进位。此时 C1 为 `00000001`，D1 为 `00000000`，A1、B1 都为零。

**复现课堂的换算。** 在 Windows **计算器 → 菜单 → 程序员** 中选 **DEC**，输入十进制数，再读 **BIN** 一栏。输入 25 应看到 `0001 1001`，同屏 **HEX** 为 `19`。去掉组间空格即可填入 D1。录屏中的计算器字长显示为 **QWORD**，它是计算器的设置，程序中 `int` 的宽度由编译目标决定。若在 Calc 输入后前导零消失，可先将四格设为 **设置单元格格式 → 数字 → 文本** 再输入（整理者补充）。[微软的计算器模式说明](https://support.microsoft.com/en-us/windows/apps/use-the-calculator-in-windows) · [LibreOffice 的文本数字说明](https://help.libreoffice.org/latest/en-US/text/scalc/guide/text_numbers.html)

**四格按位权排列。** 改 D1 时，贴在表格上方的源码截图仍是 `int sun_flower = 1;`。任务管理器展示的是整机内存统计，讲师没有在那里测出四字节的增量，也没有读取变量地址。整理者在 Windows x64 上用 TinyCC 另行验证，按地址从低到高读取整数 25 的四个字节，得到十六进制 `19 00 00 00`。这就是小端序，最低有效字节在最低地址。[微软的字节序说明](https://learn.microsoft.com/en-us/cpp/standard-library/bit-enum?view=msvc-170)

## 32 位能表示多少个整数

在本例的 32 位有符号补码表示中，每一位都有 0、1 两种状态，32 位共有 **2³² 种组合**。最高位是符号位，讲师在 A1 最左端标出它，写下 `32 − 1 = 31`，最后给出范围 **−2³¹ 到 2³¹−1**。他刚提出“为什么要减一”，视频就结束了。[微软的 INT_MIN 与 INT_MAX](https://learn.microsoft.com/en-us/cpp/c-language/cpp-integer-limits?view=msvc-170)

**整理者补充推导。** 最高位为 0 时，余下 31 位有 2³¹ 种组合，其中全零已经用来表示 0。从 0 开始数，第 2³¹ 个值就是 **2³¹−1 = 2,147,483,647**。在补码中，最高位为 1 时贡献 **−2³¹**，其余位全零就得到最小值 **−2,147,483,648**。判断题目问的是“多少个”还是“最大是多少”，就能分清 **2³²** 和 **2³¹−1**。[C 标准委员会工作草案 §6.2.6.2 整数表示](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf#page=56)
