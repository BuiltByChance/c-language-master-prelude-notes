# 086 · 多个 else if 怎样排序，才能让每个温度分支都能触发？

`if / else if / else` 适合从多个动作中只选一个。程序从上往下检查条件，遇到第一个真条件就执行对应的分支，跳过这条链的其余部分。最后的 `else` 没有条件，只有前面全部为假才会进入。[C11 草案 §6.8.4.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=166)

## 为什么课堂代码不会打印严寒提示？

录屏最后的温度是 `35.0f`，条件依次为 `> 30.0`（制冷）、`< -1.0`（制暖）、`< -15.0`（严寒提示），最后 `else` 提示不需要开空调。讲师在编辑器里逐项讲解，画面没有展示运行结果。

以 `-16°C` 为例，`-16 > 30` 为假，`-16 < -1` 为真，于是执行制暖分支。走到第三项的前提是 `t < -1` 已经为假，而任何满足 `t < -15` 的温度都必然满足 `t < -1`。给每个分支找一个能命中它的值，就能查出这种被前项挡住的条件。

## 怎样让两档低温各有用途？

若要求低于 `-15°C` 时单独给出严寒提示，就把范围较小的 `< -15` 放在 `< -1` 前。下面是整理者的复核程序，沿用课堂阈值，将输出简写为动作名。修改初值后重新运行即可测试。

```c
#include <stdio.h>

int main(void) {
    float current_temperature = -16.0f;

    if (current_temperature > 30.0f) {
        puts("制冷");
    } else if (current_temperature < -15.0f) {
        puts("严寒提示");
    } else if (current_temperature < -1.0f) {
        puts("制暖");
    } else {
        puts("不需要开空调");
    }
    return 0;
}
```

整理者在本地分别运行了两种顺序。表中每个温度单独测试，输出按动作归纳。

| 初值（°C） | 录屏顺序 | 调整后 |
| --- | --- | --- |
| `35` | 制冷 | 制冷 |
| `30`、`-1` | 不需要开空调 | 不需要开空调 |
| `-2`、`-15` | 制暖 | 制暖 |
| `-16` | 制暖 | 严寒提示 |

`-15` 恰好等于分界值，严格小于的条件不成立，因此落入制暖分支。检查相邻档位时，既要试阈值本身，也要试阈值另一侧能触发新分支的值。
