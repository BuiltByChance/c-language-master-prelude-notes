# 064 · 连续赋值时，外层拿到的是哪个值？

## 一行里有三个名字，先看声明了几个变量

课堂先写 `int x = y = z = 0;`。这行只声明 `x`，它的初值来自右边的赋值表达式 `y = z = 0`。当时 `y` 和 `z` 都还没有声明，Visual Studio 在两个名字下方标了红色波浪线。要一次定义三个 `int` 并分别初始化为零，写 `int x = 0, y = 0, z = 0;`。逗号分隔三个声明符，每个名字各有一个初值。[C 的声明语法](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=126)

变量都已定义后，`x = y = z = 10;` 按 `x = (y = (z = 10));` 分组，这叫**右结合**。在中间两层 `y = (z = 10);` 中，内层把 10 存入 `z`，并把存入后的值提供给 `y`。同理，外层 `x` 得到 `y` 存入后的值。三个 `int` 最终都是 10。`(z = 10)` 本身不能作为下一次赋值的写入位置。右结合说明各层如何分组，单凭它无法推断机器写入三个对象的先后顺序。[C 的赋值表达式规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=119)

## 小数先赋给整数，再传给 double，还能保留吗？

课堂没有输出三个变量。下面的第一组打印用来核对课堂推演，第二组是整理者补充的混合类型对照。

```c
#include <stdio.h>

int main(void)
{
    int x = 0, y = 0, z = 0;
    x = y = z = 10;
    printf("%d %d %d\n", x, y, z);

    double weight;
    int whole_kg;
    weight = whole_kg = 10.75;
    printf("%.2f %d\n", weight, whole_kg);
    return 0;
}
```

第一行实测为 `10 10 10`。第二行之所以是 `10.00 10`，是因为 `whole_kg` 接收 `10.75` 时，浮点数隐式转为 `int`，小数部分被舍去。外层的 `weight` 只能接收到整数 10，再以 `double` 保存。这里的转换不需要写强制类型转换符。[简单赋值](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120) · [浮点转整数](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=69)

如果要同时保留原始重量和整千克数，拆成 `weight = 10.75;` 和 `whole_kg = weight;` 两句。这样 `weight` 保留 10.75，只有 `whole_kg` 舍去小数。
