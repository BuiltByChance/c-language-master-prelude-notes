# 074 · 怎样用按位异或翻转选定的位、找出状态不符的开关？

按位异或 `^`（XOR）逐位比较两个整数，对应位不同得 `1`，相同得 `0`。它和按位或 `|` 的区别在于两位都为 `1` 时，`1 ^ 1` 得 `0`，`1 | 1` 得 `1`。[C11 草案 §6.5.11](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=116)

## 用掩码翻转选中的位

```text
  0010    原值 2
^ 1010    掩码 10
------
  1000    结果 8
```

从右往左以第 0 位起算，掩码 `1010` 选中第 3 位和第 1 位。掩码为 `1` 的列翻转，所以第 3 位从 `0` 变 `1`，第 1 位从 `1` 变 `0`。掩码为 `0` 的列保留原值。要把目标位设为 `1`，用按位或。要切换目标位的状态，用异或。

课堂在 Visual Studio 中取 `int a = 2;`、`int b = 10;`，运行 `printf("%d\n", a ^ b);`，控制台输出 `8`。整理者复测时用 `a ^= b;` 把结果写回 `a`，再执行一次便回到 `2`，因为被选中的位翻转了两次。

## 交换两个整数时怎样选

讲师以两个独立变量 `int a = 1, b = 2;` 为例，在板书上比较三种写法。表中每一行都从这组初值开始，各自执行后都是 `a == 2`、`b == 1`，整理者已分别运行核对。

| 方法 | 依次执行 | 原理与适用条件 |
| --- | --- | --- |
| 临时变量 | `int temp = a;` `a = b;` `b = temp;` | 先保存原来的 `a`，再覆盖它。通常选这种写法，既能看出旧值去了哪里，也无需判断两数之和是否越界。 |
| 加减 | `a = a + b;` `b = a - b;` `a = a - b;` | 先保存总和，再依次减出原来的 `a` 和 `b`。对 `int`，第一步的和必须能用 `int` 表示，例如最大值 `INT_MAX` 加 `1` 就会产生未定义行为。[C11 草案 §6.5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=94) |
| 异或 | `a = a ^ b;` `b = a ^ b;` `a = a ^ b;` | 同一个值异或两次会抵消。第二步消去原 `b`，得到原 `a`，第三步消去原 `a`，得到原 `b`。两处必须是不同的存储位置。如果都指向同一变量，第一步就会把它清零。 |

讲师倾向于临时变量。录屏所用的微软 x64 环境中，`int` 占 4 字节，但优化器可以把临时值放在寄存器中或消去变量。课堂没有比较生成的指令或测量耗时，不能从三行源码判断哪种交换更快。[微软 x64 类型布局](https://learn.microsoft.com/zh-cn/cpp/build/x64-software-conventions?view=msvc-170#scalar-types) · [微软编译器优化说明](https://learn.microsoft.com/zh-cn/windows-hardware/drivers/debugger/debugging-optimized-code-and-inline-functions-external)

## 用差异位判断哪个开关要开、哪个要关

板书假设五个开关中 `1` 表示开、`0` 表示关。前两行是讲师给出的状态，第三行是整理者按位核算的结果。

```text
  01010    图纸要求
^ 10111    假设读数
-------
  11101    不同的位置
```

先读差异行，`0` 表示该开关已经符合要求。遇到 `1` 再看图纸的同一列，目标为 `1` 就开，为 `0` 就关。从左数，第 1、3、5 个要关，第 2 个要开，第 4 个保持开启。调整后，用新读数再与图纸异或，得到 `00000` 才表示五个开关全部相符。
