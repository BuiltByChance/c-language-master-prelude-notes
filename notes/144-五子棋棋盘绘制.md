# 144 · 怎样保存一张 15×15 棋盘，让无效落子可以重试？

`board[x][y]` 的第一维表示行，第二维表示列，两者都取 0～14。录屏在 Windows 控制台项目的 `game.c` 中使用 `wchar_t board[15][15]`。空位 `·` 是 U+00B7，黑子 `●` 是 U+25CF，白子 `○` 是 U+25CB。黑方先走。[Unicode 几何图形码表](https://www.unicode.org/charts/PDF/U25A0.pdf)

1. **开局只初始化一次。** 用两层循环把 225 个位置填成空位。此后绘制只读取每个位置，行内打印各格，行末换行。把初始化放进重画循环会清除已落的棋子。
2. **先判断输入，再查看棋盘。** 录屏用 `scanf_s("%" SCNu8 " %" SCNu8, &x, &y)` 的返回值检查是否成功读到两个数。只有在两个坐标都小于 15 时才查看 `board[x][y]`，并检查它是空位。整理者建议先按有符号的整数读入，再检查每项在 0～14。`%u` 类转换允许可选的正负号，返回 2 只说明完成两次赋值。[Microsoft 的 scanf_s 文档](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/scanf-s-scanf-s-l-wscanf-s-wscanf-s-l?view=msvc-170)
3. **合法落子才换人。** 将当前玩家写进空格，切换黑白，跳出本轮输入循环，重画并询问 `y/n`。输入格式错误、越界或重复占位时，保留棋盘和当前玩家，提示重输。开始下一局才清空棋盘。

下面是整理者从录屏提取的落子逻辑，可独立验证棋盘状态。`play` 收到的是已经解析好的坐标。先检查行、列上下界，再读对应格。示例将 Windows 控制台输出设为 UTF-8，源码和窄字符串也用 UTF-8；绘制只使用窄输出。

```c
#include <stdbool.h>
#include <stdio.h>
#include <wchar.h>
#include <windows.h>

enum { BOARD_SIDE = 15, EMPTY_CELL = 0x00B7, BLACK_STONE = 0x25CF, WHITE_STONE = 0x25CB };

static bool play(wchar_t board[][BOARD_SIDE], int row, int col, wchar_t *player)
{
    if (row < 0 || row >= BOARD_SIDE || col < 0 || col >= BOARD_SIDE) return false;
    if (board[row][col] != EMPTY_CELL) return false;
    board[row][col] = *player;
    *player = (*player == BLACK_STONE) ? WHITE_STONE : BLACK_STONE;
    return true;
}

int main(void)
{
    SetConsoleOutputCP(65001);
    wchar_t board[BOARD_SIDE][BOARD_SIDE], player = BLACK_STONE;
    for (int row = 0; row < BOARD_SIDE; ++row) {
        for (int col = 0; col < BOARD_SIDE; ++col) board[row][col] = EMPTY_CELL;
    }
    int moves[][2] = {{6, 7}, {6, 7}, {6, 8}};
    for (int i = 0; i < 3; ++i) {
        puts(play(board, moves[i][0], moves[i][1], &player) ? "OK" : "Retry");
    }
    printf("%04X %04X\n", (unsigned)board[6][7], (unsigned)board[6][8]);
    for (int row = 0; row < BOARD_SIDE; ++row) {
        for (int col = 0; col < BOARD_SIDE; ++col) {
            wchar_t cell = board[row][col];
            const char *symbol = cell == BLACK_STONE ? "●" : cell == WHITE_STONE ? "○" : "·";
            printf("%s ", symbol);
        }
        putchar('\n');
    }
    return 0;
}
```

核对输出 `OK`、`Retry`、`OK`，紧接着是 `25CF 25CB` 和 15 行棋盘。第七行的第八格为黑子，第九格为白子。第二次下在已有的黑子上被拒绝，白方仍可在相邻空位落子。

在 Visual Studio 中打开项目属性 → C/C++ → 命令行，在“其他选项”填 `/utf-8`，让 MSVC 以 UTF-8 解释源文件并生成窄字符串。录屏用 `SetConsoleOutputCP(65001)` 设置控制台输出代码页，`setlocale(LC_ALL, "")` 请求系统环境的区域设置。最初棋盘可见，部分提示未显示。讲师改了部分提示的打印方式，又修正重复落子后无法重试的问题。后续实测 `15 15`、`-1 -1` 均得到“无效的移动”，标点输入则得到“输入无效”。录屏中的宽、窄输出混用不能作为可移植写法。输入失败时原程序以 `while (getchar() != '\n')` 丢弃本行，遇到文件尾会一直循环。自写交互版时应同时判断 `EOF`，结束输入。完成的是落子、轮换和重画，尚无五子连线判胜。[Windows 控制台输出代码页](https://learn.microsoft.com/en-us/windows/console/setconsoleoutputcp)
