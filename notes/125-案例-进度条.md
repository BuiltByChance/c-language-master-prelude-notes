# 125 · 怎样让控制台进度条在同一行从 0% 走到 100%？

把一行留给进度条，每次先用 `\r` 把光标移回行首，再重画整条。设总步数为 50，已完成 `i` 步就写 `i` 个 `#`、`50 - i` 个空格。回车只移动光标，补足空格才能覆盖原来的内容。终端一行要容得下整条进度条和右边的百分比。[Microsoft 的 C 转义序列](https://learn.microsoft.com/zh-cn/cpp/c-language/escape-sequences?view=msvc-170)

下面是整理者按录屏改写的 Windows 示例，可放进控制台项目的 `.c` 文件编译运行。

```c
#include <stdio.h>
#include <windows.h>

int main(void)
{
    const unsigned total_steps = 50;
    for (unsigned i = 0; i <= total_steps; ++i) {
        printf("\r[");
        for (unsigned j = 0; j < i; ++j) putchar('#');
        for (unsigned j = i; j < total_steps; ++j) putchar(' ');
        printf("] %3u%%", i * 100 / total_steps);
        fflush(stdout);
        if (i < total_steps) Sleep(10);
    }
    puts("\n处理完成!");
    return 0;
}
```

- `i = 0` 画空条，`i = 25` 画半条，`i = 50` 画满条。外层条件包含终点，最后一次才有 `100%`。`%3u` 给数字留三列，`%%` 写出一个百分号。
- 50 步每步增加 2 个百分点，100 步每步增加 1 个百分点。`fflush(stdout)` 在等待前送出当前这一行的缓冲内容，使没有换行的更新也能及时显示。`Sleep(10)` 的单位为毫秒，只调节演示速度。录屏最后一次完整运行显示满条、`100%`、另起一行的“处理完成!”和退出码 0。[Microsoft 的 fflush 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fflush?view=msvc-170) · [Windows Sleep 文档](https://learn.microsoft.com/zh-cn/windows/win32/api/synchapi/nf-synchapi-sleep)

讲师只用下载文件举例。若接入真实传输，整理者建议每收到一块数据就累计已传字节，已知总字节且大于零时用 `100.0 * 已传字节 / 总字节` 计算百分比。先做整数除法会丢掉小数，例如整型的 `25 / 50 * 100` 得到 0。总大小未知时可直接显示已传字节。
