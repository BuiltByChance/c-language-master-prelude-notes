# 026 · int 的初始化与赋值：同一个变量的值怎样改变

## 从两次输出区分初始化和赋值

```c
#include <stdio.h>

int main(void) {
    int sun_flower = 100;
    printf("1-> sun_flower = %d\n", sun_flower);
    sun_flower = 99;
    printf("2-> sun_flower = %d\n", sun_flower);
    return 0;
}
```

`int sun_flower = 100;` 定义变量并给它初值，这叫**初始化**。`sun_flower = 99;` 把新值写回同一个变量，这叫**赋值**。每次 `printf` 都用 `%d` 打印执行到那一行时的整数值，所以课堂控制台先显示 `1-> sun_flower = 100`，再显示 `2-> sun_flower = 99`。[C 标准委员会草案 §6.5.16.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120)

若输出来自别的练习，先检查当前项目中哪个文件定义了 `main`。课堂第一次运行的是 `game.c`。讲师把 `001.c` 的 `main_1` 改回 `main`，把 `game.c` 的 `main` 改名为 `main_2`，再选 **Debug → Start Without Debugging（Ctrl+F5）**，才看到上面两行。[微软对 C 程序入口的说明](https://learn.microsoft.com/zh-cn/cpp/c-language/main-function-and-program-execution?view=msvc-170)

## 把第二次赋值改成 90，哪一格会变

讲师随后把 `99` 改成 `90`，在 LibreOffice Calc 里手填同一个变量赋值前后的表示。课堂环境的 `int` 占 4 字节，每格 8 位，表中从左到右按位权从高到低排列。[微软类型大小表](https://learn.microsoft.com/zh-cn/cpp/cpp/data-type-ranges?view=msvc-170)

| 执行完的语句 | A2 | B2 | C2 | D2（最低字节） |
| --- | --- | --- | --- | --- |
| `int sun_flower = 100;` | `00000000` | `00000000` | `00000000` | `01100100` |
| `sun_flower = 90;` | `00000000` | `00000000` | `00000000` | `01011010` |

读 D2 中为 1 的位，`64 + 32 + 4 = 100`，`64 + 16 + 8 + 2 = 90`。两次只有最低字节的值不同，三个全零的高字节也属于这个 `int`。单凭字节为零不能判定内存空闲，表格也无法说明 CPU 实际执行了几次写入。

**区分数值大小和变量大小。** 讲师短暂把初值改成 `1000000`，随即恢复为 `100`。整理者验算，两个 8 位字节最多能表示的无符号数是 65,535，装不下 1,000,000。后者按高位在前写成 `00 0F 42 40`，三个字节非零，`int` 在课堂环境仍占四字节。换编译目标时，用 `sizeof sun_flower` 查该变量占几字节。

讲师对 90 的演示停在表格。整理者用 TinyCC 运行上面的程序，再把 `99` 改为 `90` 重跑，第二行随之从 `99` 变为 `90`，第一行两次都是 `100`。
