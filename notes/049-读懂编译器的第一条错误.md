# 049 · 编译报错指向 printf，为什么要回看上一条语句？

## 找到这一次生成的第一条错误

1. 保存源文件，在 Visual Studio 选「生成」→「生成解决方案」。打开「视图」→「输出」（Ctrl+Alt+O），在「显示输出来源」选「生成」，从本轮生成开始处向下找第一条 `error`。普通 `warning` 提醒有可疑之处，默认可以继续生成。遇到 `error` 则须先修复。若生成失败后提示运行上次成功的版本，选「否」，旧程序的输出验证不了刚改的源码。[微软输出窗口说明](https://learn.microsoft.com/en-us/visualstudio/ide/output-window?view=visualstudio)
2. 从诊断里读出**文件、行和列、严重程度、消息正文**。从正文提取动作和对象，例如“在谁前面缺什么”“哪个名字未声明”“哪两个类型不匹配”。编译器读到某处才发现语法接不上，根因可能在前一条语句。一个漏掉的分号、括号或引号也能引出多条后续诊断。[微软编译错误排查说明](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-errors-1/c-cpp-build-errors?view=msvc-170)
3. 要跳到源码，打开「视图」→「错误列表」，双击对应记录。列表若选「生成 + IntelliSense」，会同时显示编译器诊断和编辑器的实时提示。要单看编译器，来源选「生成」。列表可以按列排序，要确定谁先报错，回到本次生成输出看顺序。[微软错误列表说明](https://learn.microsoft.com/en-us/visualstudio/ide/error-list-window?view=visualstudio)

## 从第 19 行找到第 17 行

课堂文件 `display_float.c` 的第 17 至 19 行如下，中间有一空行。

```c
int score = 95

printf("score = %d\n", score);
```

`display_float.c(19,5): error C2146` 表示编译器在第 19 行第 5 列报告语法错误。正文指明在标识符 `printf` 前缺 `;`。编辑器还给出了 `E0065`（应输入分号）。双击两条记录都落在 `printf` 上。编译器读到这个名字时，第 17 行的声明还没结束。把那行改成 `int score = 95;` 即可。[微软 C2146 说明](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-errors-1/compiler-error-c2146?view=msvc-170)

**每次只修一处，再生成。** 用最新一轮输出确认原来的首条错误是否消失。如果仍有错误，就从新的第一条查起。若生成成功，再运行核对结果。课堂中只定义一次 `score` 的版本生成成功，控制台打印 `score = 95`，退出代码为 `0`。

**片尾的三条声明还有另一个错误。** 讲师在同一个 `main` 函数体中给三条 `int score = 95` 依次补上分号，编辑器的分号提示消失了，但「输出」仍是添加后两条声明之前的成功记录。整理者用 TinyCC 复测，编译器在第二个定义处报 `redeclaration of 'score'`。若三处用的是同一个变量，只保留第一次定义，后面确需改值时写赋值语句（如 `score = 95;`）。[C11 委员会草案 §6.7 第 3 段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=126)

## 提示文字太小时改哪一项

- 若**鼠标悬停的提示太小**，在「工具」→「选项」搜索「字体和颜色」。录屏进入「环境」→「字体和颜色」，在「显示其设置」选「编辑器工具提示」，将字体改为 Consolas、字号改为 16。若小的是构建日志，选「输出窗口」。误改「环境」会连菜单一起放大，讲师最后把环境字体恢复为「自动」。
- 据微软文档，Visual Studio 2026 从 18.11 起将「字体和颜色」并入统一设置页，仍可从「工具」→「选项」搜索进入（2026-11-21 核实）。[微软字体和颜色设置](https://learn.microsoft.com/en-us/visualstudio/ide/fonts-and-colors-environment-options-dialog-box?view=visualstudio)
- 录屏另行浏览了 Fira Code 和更纱黑体，均未安装。Consolas 随适用的微软产品提供。需要前两种字体可从各自项目的发布页获取。入口及 Consolas 的提供方式核实于 2026-11-21。[微软 Consolas 说明](https://learn.microsoft.com/en-us/typography/font-list/consolas) · [Fira Code 发布页](https://github.com/tonsky/FiraCode/releases) · [更纱黑体发布页](https://github.com/be5invis/Sarasa-Gothic/releases)
