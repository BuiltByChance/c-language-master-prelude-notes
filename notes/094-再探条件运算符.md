# 094 · 怎样用条件运算符按分数选等级？

`条件 ? 值一 : 值二` 会产生一个值。先计算条件。条件非零时只计算问号和冒号之间的表达式，条件为零时只计算冒号后的表达式。要从多个等级中选一个字符，可以把下一次判断写在冒号后面。[Microsoft Learn：C 的条件运算符](https://learn.microsoft.com/zh-cn/cpp/c-language/conditional-expression-operator?view=msvc-170)

```c
#include <inttypes.h>
#include <stdio.h>

int main(void) {
    uint32_t score = 85;
    char grade = (score >= 90) ? 'A' :
                 (score >= 80) ? 'B' :
                 (score >= 70) ? 'C' : 'D';

    printf("得分：%" PRIu32 "，等级：%c\n", score, grade);
    return 0;
}
```

**为什么先检查 90 分？** 85 同时满足 `>= 80` 和 `>= 70`。按门槛从高到低判断，85 先跳过 A，再选中 B，到这里就结束了。如果先写 `>= 70 ? 'C'`，85 会被提前归为 C。最后的 `'D'` 接收所有低于 70 的分数。

**怎样看出嵌套关系？** 每行冒号后面的剩余部分，都是这一层条件为假时要计算的表达式。把后两档单独加上括号，就能看清一对问号和冒号管到哪里。

```c
(score >= 80) ? 'B' : ((score >= 70) ? 'C' : 'D')
```

换行只方便对齐阅读。如果用括号标出一整层，要包住完整的 `条件 ? 真值 : 假值`。录屏里一度在 `'B'` 后、冒号前就闭合括号，编辑器标红，随后讲师撤掉了这对括号。展开成 `if / else` 时，每次只在 `else` 里检查下一档，命中后给 `grade` 赋值一次。

**验证分界。** 修改 `score` 的初值，重新编译并运行。讲师现场得到 85 → B、45 → D。整理者用上面的程序逐对检查门槛两侧，得到 69 → D、70 → C，79 → C、80 → B，89 → B、90 → A。

录屏用 `%u` 打印分数、`%c` 打印等级。上面的复习代码用 `<inttypes.h>` 的 `PRIu32` 匹配 `uint32_t`，这样在底层整数类型不同的平台上也能按无符号十进制输出。[IBM：定宽整数的格式宏](https://www.ibm.com/docs/en/zos/3.2.0?topic=files-inttypesh-io-format-integer-types)
