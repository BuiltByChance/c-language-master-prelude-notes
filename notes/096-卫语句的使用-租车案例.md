# 096 · 租车资格检查中，什么时候把 && 拆成卫语句？

课堂的租车规则要求年满 21 岁，并且有至少 1 年驾驶经验。只需回答“能租吗”，可直接写 `age >= 21 && driving_exp_years >= 1`。要告诉申请人哪一项不合格，可以给每个拒绝原因写一条**卫语句**，在发现资格不符时说明原因并立即返回。能走到最后的才执行通过逻辑。[Martin Fowler：用卫语句处理特殊情况](https://refactoring.com/catalog/replaceNestedConditionalWithGuardClauses.html)

```c
#include <stdint.h>
#include <stdio.h>

int main(void) {
    uint8_t age = 23;
    uint8_t driving_exp_years = 2;

    if (age < 21) {
        puts("不符合条件，年龄不足。");
        return 0;
    }
    if (driving_exp_years < 1) {
        puts("不符合条件，驾驶经验不足。");
        return 0;
    }
    puts("满足租车条件");
    return 0;
}
```

**门槛和顺序各决定什么？** 把放行条件 `>=` 反过来，拒绝条件应写 `<`。恰好 21 岁且驾龄恰好 1 年可以通过。若两项都不合格，先检查哪项就只提示哪项，因为第一条命中的 `return` 已经结束了 `main`。整理者修改上面两个初值并分别编译运行，得到下列结果。

| 年龄 | 驾龄（年） | 唯一输出 |
| --- | --- | --- |
| 20 | 0 | 不符合条件，年龄不足。 |
| 21 | 0 | 不符合条件，驾驶经验不足。 |
| 21 | 1 | 满足租车条件 |

**两种写法检查的次数相同。** C 的 `&&` 从左向右求值，左侧为假就跳过右侧。按本例的顺序，20 岁时两种写法都只检查年龄，年满 21 岁才检查驾龄。将判断拆开，能为每种失败给出不同提示，同时让通过路径保持在同一层。[Microsoft Learn：C 逻辑运算符的短路规则](https://learn.microsoft.com/zh-cn/cpp/c-language/c-logical-operators?view=msvc-170)

**把规则移入函数。** 片尾把两个 `if` 和最后的 `puts` 移进 `void check_car_rent(uint8_t age, uint8_t driving_exp_years)`，在 `main` 前声明它。两个拒绝分支改用不带值的 `return;` 返回调用处，通过时打印消息后走到函数末尾。`main` 用 `check_car_rent(22, 3);` 提供年龄和驾龄，再用自己的 `return 0;` 结束程序。讲师实际运行了合并条件版（23 岁、2 年）和函数版（22 岁、3 年），两次都显示通过。[Microsoft Learn：C 的 return 语句](https://learn.microsoft.com/zh-cn/cpp/c-language/return-statement-c?view=msvc-170)
