# 193 · 把数组交给函数时，除了起点还要给什么？

讲师用《C Primer Plus》第 6 版中文版第 10 章「使用指针形参」收束基础指针部分。翻到程序清单 `sum_arr2.c` 时，可以带着一个问题读它：函数收到首元素指针，怎样知道该在哪里停？

- **起点加元素数。** 若传入 `a` 和 `n`，有效下标从 `0` 到 `n - 1`，循环条件写 `i < n`。当 `n == 0` 时，一次也不读取。
- **起点加结束位置。** 对含五个元素的数组 `a`，可传 `a` 和 `a + 5`。从前一个指针向后移动，每次在读取前检查 `p != end`；两者相等时已经走过最后一个元素。这里的 `a + 5` 只标记边界。

以上两种写法是对书页例子的复习说明。录屏随后翻到字符串、字符串 I/O 和内存管理章节，最后回到只有 `main` 和 `return 0` 的编辑器。字符串、结构体、动态分配和多级指针属于后续话题，本节没有运行新程序。
