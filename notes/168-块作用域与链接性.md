# 168 · C 的四种作用域分别管哪些名字？

**作用域**决定源代码的某处能用哪个名字。判断前先认出要找的是变量、形参还是语句标签，再找它的声明位置。[WG14 C11 草案 §6.2.1](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=53)

| 作用域 | 在本课代码中怎样判定 |
|---|---|
| 文件作用域 | `int total = 100;` 写在函数外，后面的函数能使用它，直到本翻译单元末尾。进出内层块不改变它保存的 100。 |
| 块作用域 | `main` 内另开一对大括号，在其中声明 `int local = 7;`，只可从声明处到该块末尾使用这个名字。讲师在右大括号之后放开打印语句，编辑器提示 `local` 未定义。 |
| 函数作用域 | 适用于语句标签。同一函数的 `goto done;` 可以跳到后面才出现的 `done:`，执行标签后面的语句。另一个函数即使也有同名标签，跳转目标仍只能在当前函数内。 |
| 函数原型作用域 | 原型 `static int add(int left, int right);` 中，`left`、`right` 的作用域到这个函数声明符末尾。定义可写 `static int add(int a, int b)`，函数体用的是 `a`、`b`；需要匹配的是函数类型。 |

### 沿着代码走一遍

先打印文件变量 `total`，进入内层块打印 `local`，出块后再次打印 `total`。然后调用 `add(2, 3)`，遇到 `goto done;` 跳到 `done:` 下的 `printf`。按课中完整源码应依次得到 `file total=100`、`block local=7`、`after block total=100`、`add result=5`、`label reached`。录屏没有展示控制台，以上五行由整理者按课堂代码单独编译复核。

### 链接判断的是另一件事

两处声明能否指向同一实体，要看名字的**链接**。本例文件级 `total` 有外部链接，另一翻译单元可用匹配的 `extern int total;` 指向同一对象；文件级 `static` 函数 `add` 有内部链接，限于本翻译单元；普通块内 `local` 的名字无链接。讲师一度把“内部链接”和“无链接”并称，二者应区分。对象能否跨函数返回保值还要看存储期，例如块内静态对象的名字无链接，其值却可跨调用保留。[WG14 C11 草案 §6.2.2、§6.2.4](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=54)
