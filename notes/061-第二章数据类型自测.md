# 061 · 第二章结束时，怎样自测数据类型和混合运算？

## 用 10～15 分钟完成一次自测

1. 从空白 `.c` 文件开始，给本章学过的类型各写一个带初值的声明。先覆盖 `int`、`float`、`double`、`char`，再写 `<stdint.h>` 中的 `int32_t` 和 `uint32_t`。每个变量都要能说出它保存什么，以及数据是否可能为负、是否要保留小数或固定宽度。
2. 自选数值做加、减、乘、除，至少写一次整数和浮点数混合运算，并打印结果。整理者建议先写下预期值，尤其是除法的小数部分，再运行对照。遇到差异，先看运算符两边的类型，再看接收结果的变量。
3. 讲师建议做完后定时休息 5 分钟，再重写本章案例。遮住原代码，重写时解释每个类型、后缀和转换的用途。哪一步写不下去，就带着那个具体问题查 C 标准或编译器文档，再跑一次。

讲师把整数运算列为复习重点。若还说不清一次整数除法的结果，先把它写成能运行的小程序。IEEE 754 的编码细节记不全，可以回查[本章拆解 13.25 的例子](043-binary32的指数偏移与解码.md)。

## 同样是 7 除以 2，哪一步决定小数能否保留？

课堂在桌面上手写 `a / b`，口头设 `a` 为 `float`、`b` 为整数。下面是整理者补充的自测，可先预测三项输出。

```c
#include <stdio.h>

int main(void)
{
    int items = 7, boxes = 2;
    float weight = 7.0f;
    double average = items / boxes;
    printf("%.1f %.1f %.1f\n", average, (double)items / boxes, weight / boxes);
    return 0;
}
```

实测输出 `3.0 3.5 3.5`。第一项先做整数除法得到 `3`，赋给 `double` 时小数部分已丢失。第二项在除法前把 `items` 转成 `double`，因而得到 `3.5`。第三项的 `weight` 已经是 `float`，除法会把 `boxes` 转为浮点类型，无需再给 `weight` 加强制转换。[C11 的通常算术转换](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=71) · [整数除法规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=110)

## 在 MSVC 的 C 程序中需要复数时查什么？

标准头文件是 `<complex.h>`。在本课涉及的 C11/C17 中，`imaginary` 是实现支持纯虚数类型时才提供的宏，没有单独的标准头文件 `<imaginary.h>`。[C11 草案 §7.3.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=206)

按微软文档核实（2026-11-21），MSVC 的 C 编译器不支持原生 `_Complex` 类型，但 C 运行库提供复数运算。例如，可用 `_Dcomplex z = _Cbuild(3.0, 4.0);` 从实部和虚部构造复数，再用 `cabs(z)` 求模。课堂没有编译复数示例。[微软 C 复数数学支持](https://learn.microsoft.com/en-us/cpp/c-runtime-library/complex-math-support?view=msvc-170)
