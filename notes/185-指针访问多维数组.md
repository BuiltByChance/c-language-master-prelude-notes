# 185 · 二维数组的行指针怎么声明，怎样读出第 2 行第 2 列？

`int matrix[2][3]` 有两行，每行是一个含三个 `int` 的数组。要让一个指针按**整行**移动，写 `int (*ptr)[3] = matrix;`。右边的 `matrix` 在这里转换为首行地址 `&matrix[0]`，所以 `ptr + 1` 指向第二行。声明中的 3 决定每行宽度，行数 2 则用来限定遍历范围。[WG14 C11 草案 §6.5.2.1](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=98)

括号改变了所声明的对象。读 `int (*ptr)[3]` 时，先看到 `*ptr`，得到一个指针，所指对象是三个整数的数组；读 `int *ptr[3]` 时，先看到 `ptr[3]`，得到一个三项数组，每项各是一枚 `int *` 指针。后者适合保存三个独立指针，不能直接用来接收这里的矩阵首行地址。

```c
#include <stdio.h>

int main(void)
{
    int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int (*ptr)[3] = matrix;

    for (int i = 0; i < 2; ++i) {
        for (int j = 0; j < 3; ++j)
            printf("%d%c", ptr[i][j], j == 2 ? '\n' : ' ');
    }
    return 0;
}
```

课堂实跑输出 `1 2 3` 和 `4 5 6` 两行。要定位 5，两维都从零计数：`ptr[1]` 选中含 4、5、6 的行，`ptr[1][1]` 再选行内下标 1。下标已经包含解引用，整个表达式等价于 `*(*(ptr + 1) + 1)`。讲师用这个数解释定位，未再执行单独的搜索或改写。
