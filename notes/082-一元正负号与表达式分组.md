# 082 · 怎样判断负号作用于一个数还是整个和？

`3 - 2` 中，减号左右各有一个操作数，表示减法。`-3` 中，负号只有右侧一个操作数，表示取相反数。同理，`a + b` 做加法，`+b` 则保留 `b` 的值。

## 表达式的值会写回变量吗？

- 设 `int x = 3;`。单写 `-x;` 会得到 `-3`，这个结果随即被丢弃，`x` 仍为 `3`。改写为 `x = -x;`，才会把 `-3` 存回 `x`。
- 设 `int x = -3;`。`+x` 的值仍是 `-3`，即使写成 `x = +x;`，存回的也还是 `-3`。一元正号不能用来取绝对值。

课堂用的是 `int`。按 C 的整数提升规则，若换成 `signed char`，一元 `+` 会先把操作数提升为 `int`，所以表达式保留原来的数值，结果类型可以改变。[C11 草案 §6.5.3.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=107)

## 用括号标出负号的范围

C 规定一元正负号比乘法和二元加减法结合得紧。下表沿用课堂的 `a = 2`、`b = 3`。[微软 C 运算符优先级表](https://learn.microsoft.com/zh-cn/cpp/c-language/precedence-and-order-of-evaluation?view=msvc-170)

| 表达式 | 负号作用于谁 | 代入结果 |
| --- | --- | --- |
| `-a + b` | 只作用于 `a`，按 `(-a) + b` 分组 | `-2 + 3 = 1` |
| `-(a + b)` | 作用于括号里的整个和 | `-(2 + 3) = -5` |
| `-a * b` | 作用于左因子，按 `(-a) * b` 分组 | `(-2) * 3 = -6` |
| `a * -b` | 作用于右因子，按 `a * (-b)` 分组 | `2 * (-3) = -6` |

讲师在编辑器里用注释写出了加法两例的结果和乘法两例的分组。表中两个乘积由整理者代入同一组数，在本地运行核对。课堂全程没有显示控制台输出。
