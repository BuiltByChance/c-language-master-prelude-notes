# 016 · 注释：行注释、块注释与编译结果

注释可以写在难懂的代码旁，给以后读程序的人留一张“便签”。读代码时，先找注释的边界。课堂里同一句中文写在块内时，程序照常输出 `HelloWorld!`。复制到块外的那一句则被编辑器标上了红色波浪线。

## 在 Visual Studio 2022 显示行号（00:00–00:48）

讲师在项目 `Project1` 的 `run.c` 里写下 `// 注释 Comment`，用行号指出这行文字的位置。录屏中的设置入口如下。

1. 进入 **工具 → 选项**（Tools → Options）。录屏中，讲师在选项窗口的搜索框输入 `line`，中文界面可搜“行号”。
2. 进入 **文本编辑器 → 所有语言 → 常规**（Text Editor → All Languages → General），勾选 **行号**（Line numbers），点“确定”。
3. 回到源码，看左侧是否显示行号。讲师打开选项前就已有行号，复选框也已勾选，这一步展示的是入口。

以上路径按 Visual Studio 2022 文档核对，核实日期为 2026-11-19。[微软《在编辑器中显示行号》](https://learn.microsoft.com/zh-cn/visualstudio/ide/reference/how-to-display-line-numbers-in-the-editor?view=vs-2022)

## 两种注释分别管到哪里（00:48–03:58）

| 写法 | 作用范围 | 录屏中的操作 |
| --- | --- | --- |
| `// 说明` | 从 `//` 所在位置到本逻辑行末，前面已写的代码仍然有效。 | 把第 5 行补成 `// 注释 Comment 行注释`，另写 `// 便签`。随后在第 8、9、10 行各输入一组 `//`，演示多行分别注释。 |
| `/* 说明 */` | 从 `/*` 到遇到的第一个 `*/`，可以跨行，不能嵌套。 | 输入 `/*` 后，讲师的 Visual Studio 自动补出 `*/`。他插入多行，用笔标出两个边界之间的区域，把 `printf` 留在块外。 |

讲师按自己的键盘布局说明怎样输入正斜线。他的键盘在右侧 Shift 左边有一个同时标有 `/` 和 `?` 的键，连续输入两个 `/` 就得到 `//`。

判断时要看符号出现的位置。在字符串或字符常量中，形似注释的字符是字面内容。讲师按行号讲“这一行跑、那一行不跑”，用意是帮助定位。按 C 的翻译规则，每条注释在程序运行前就被替换成一个空格，换行符保留。像本课这样的托管 C 程序，启动时调用 `main`，第 1 行 `#include <stdio.h>` 在预处理阶段处理。[C11 草案 §6.4.9 注释边界](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=93) · [§5.1.1.2 翻译阶段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=29) · [§5.1.2.2.1 程序启动](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=31)

## 对照块内、块外的结果（03:58–04:49）

1. 讲师在块注释中输入一句中文。块结束后是 `printf("HelloWorld!\n");`，再往下是 `return 0;`。
2. 在 **Debug、x64** 配置下构建并运行，构建输出显示 **1 个成功、0 个失败**。控制台打印 `HelloWorld!` 并换行，注释里的文字没有出现在输出中。
3. 他把同一句话复制到第 8 行，也就是 `/*` 上方。块内的原文仍是注释，块外的文字被当作源码解析，在这个位置不能构成有效的 C 语句，编辑器标出了红色波浪线。这个版本停在编辑器诊断阶段，没有再次构建。

**复习示例（整理者改写）**　先找出每条注释在哪里结束，再看哪条输出语句会执行。下面的片段放在原程序的 `main` 中，预期只打印一行 `HelloWorld!`。

```c
/* 暂时停用下面的输出
   printf("A\n");
*/
printf("HelloWorld!\n");  // 从这两个斜杠起才是注释
```

## 分清两种斜线，把说明写在代码旁（04:49–06:53）

讲师在浏览器查看斜线和反斜线的词条。写块注释时，两端都用 **正斜线 `/`**，只是与星号的次序相反。`printf` 字符串中的 `\n` 用的是 **反斜线 `\`**，用来表示换行。[Unicode 基本拉丁字符表](https://www.unicode.org/charts/PDF/U0000.pdf)

回到源码后，讲师在原本的空行试写普通文字，编辑器再次出现红色波浪线，他随即删去。后来他在 `printf` 上方用 `//` 加上一串示意文字，比作提前记下“下面这行为什么这样写”。片尾，他把多行注释中的文字换成“块注释”，与上方的“行注释”对照。最后一次实际运行仍是前面打印 `HelloWorld!` 的版本。
