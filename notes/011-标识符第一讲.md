# 011 · 标识符第一讲：函数名、变量名与首字符规则

标识符是程序里用来指代某个对象、函数等的名字。读 `int number = 100;`，`int` 指定类型，`number` 给变量命名，`100` 是初值。读 `printf("Hello, World!\n");`，`printf` 是标准库函数的名字。`return 0;` 中的 `return` 则是 C 关键字。

## 检查一个新变量名

1. **看首字符。** 在本课使用的基本字符中，可以用英文字母 `A–Z`、`a–z` 或下划线 `_` 开头。文档语法里的 `nondigit` 指这组字符。
2. **从第二个字符查到末尾。** 每个位置都可以继续用字母、下划线或数字 `0–9`。`number_2` 合乎规则，`number-2` 会被拆成名字、减号和数字。`xxx` 与 `Xxx` 是两个名字，引用时须保持大小写一致。
3. **查名字是否已被保留。** `double`、`return` 等关键字不能用作变量名。自己取名时用字母开头、把下划线放在内部，容易避开保留前缀。[微软《C 标识符》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-identifiers?view=msvc-170) · [下一节的下划线规则](012-标识符第二讲.md)

## 在 Visual Studio 看诊断

课堂在 `001.c` 的 `main` 函数内改同一条声明，初值为 `123`。把鼠标停在波浪线或变量名上，可以比较两种提示。

| 课堂输入 | 编辑器显示了什么 | 怎样判断 |
| --- | --- | --- |
| `int 0xxx = 123;` | 红线提示 `invalid hexadecimal number`。 | `0x` 触发了十六进制数的识别。改变量名的首字符即可，右边的 `123` 合法。 |
| `!xxx`、`-xx` | 名字位置出现红线。 | `!` 和 `-` 都是运算符，无法作为变量名的一部分。 |
| `int xx0105876 = 123;` | 悬停显示 `(local variable) int xx0105876`。 | 两个字母后可连续接数字。提示中的 `local variable` 和 `int` 表明编辑器已识别这个局部整型变量。本节验证到编辑阶段。 |
