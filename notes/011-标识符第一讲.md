# 011 · 标识符第一讲：函数名、变量名与首字符规则

在 `int number = 100;` 中，`number` 是给变量起的名字；在 `printf("Hello, World!\n");` 中，`printf` 是被调用函数的名字。这两处名字都是标识符（identifier）。检查一个自己起的名字，先看首字符，再看后续字符，最后检查它是否与关键字或保留名称冲突。

## 从函数名和变量名认标识符（00:00–06:06）

讲师在 Visual Studio 的 `001.c` 中选中 `printf`，又在教材结构图上圈画 `function a()` 和 `function b()`。他把函数比作医院科室：只说“A 部门”很难知道去哪里拍片，说“放射科”就能找到相应的服务。程序中可以用函数名引用已有的功能。示例调用若执行，`printf` 会把指定文字写到标准输出；本节显示的是源代码。[WG14 C11 委员会草案 §7.21.6.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=342)

| 录屏里的代码 | 怎样读 |
| --- | --- |
| `int number = 100;` | `int` 说明类型，`number` 是变量的标识符，初始值是 100。 |
| `double number_2;` | `double` 说明类型，`number_2` 是另一个变量名。下划线和数字都出现在首字符之后。 |
| `return 0;` | `return` 是关键字。讲师口头把它也称作“名字”；按 C 的词法分类，`int`、`double`、`return` 都是关键字，不能拿来当变量名。[微软《C 关键字》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-keywords?view=msvc-170) |

讲师随后删掉两条变量声明，临时把调用处的 `printf` 换成一串 0 和 1。编辑器出现红色波浪线，他把函数名还原。这段和“叫张三比报身份证号容易”是同一个比喻：名字便于人识别。他没有查询或展示 `printf` 的机器码。

## 从词义读到 C 文档（06:06–10:22）

讲师在剑桥词典圈出 `identifier` 释义旁的 **IT** 标签，又查动词 `identify`，用“婴儿凭声音辨认母亲”的例句解释“识别”。词典还举了机场标识的例子。这里借词义理解名字的用途，具体能用哪些字符，要看 C 的规则。[剑桥词典 identifier](https://dictionary.cambridge.org/dictionary/english/identifier) · [剑桥词典 identify](https://dictionary.cambridge.org/dictionary/english/identify)

在 **Microsoft Learn → C 语言参考 → C 的元素 → C 标识符**，讲师指出标识符可以命名变量、类型、函数和标签。例如在 `int result;` 里，整数变量名是 `result`。留意两个地方的拼写：文档正文提到函数名 `main`、`printf`，下方示例调用写的是 `printf_s`。讲师在浏览器里读了示例，没有运行它。图中的局部变量 `result` 尚未初始化就出现在条件判断里，不能据此推断一条输出结果。[微软《C 标识符》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-identifiers?view=msvc-170)

## 怎样读首字符和后续字符的语法（10:22–14:59）

讲师以中文姓名中的姓和名打比方，再回到网页上的三行语法。把它读作一个可以反复追加字符的过程，就能看出数字为什么不能打头。

| 文档中的写法 | 在本课使用的基本字符范围内怎样读 |
| --- | --- |
| `nondigit` | 先写一个 `A–Z`、`a–z` 中的字母，或一个下划线 `_`。这里的词指表中列出的字符，不能把它理解为“除了数字随便写”。 |
| `identifier nondigit` | 已经有了一个名字，可以再接字母或下划线。 |
| `identifier digit` | 已经有了一个名字，也可以再接 `0–9`。可以接多个，数字也可以收尾。 |

录屏用常见英文键盘演示了两个容易混淆的字符：减号键输入 `-`，按住 **Shift** 再按同一键得到 `_`。下划线属于上表，短横线在 C 中另有运算符用途。讲师圈出的整张表都是首字符候选，并非每个名字都要以下划线起头。[微软的标识符语法表](https://learn.microsoft.com/zh-cn/cpp/c-language/c-identifiers?view=msvc-170)

## 在编辑器里逐个试名字（14:59–16:47）

讲师在 `main` 内反复改同一条局部变量声明，保留初始值 `123`，观察红色波浪线和鼠标悬停提示。

| 输入或改动 | 观察与结论 |
| --- | --- |
| `int 0xxx = 123;` | 名字位置出现红线。约 15:15，提示原文是 `invalid hexadecimal number`（无效的十六进制数）。这串字符以 `0x` 起头，触发了数值写法的诊断。一般命名规则是首位不能为数字，具体报错措辞取决于输入。 |
| `!xxx`、`-xx` | 都试出了红线。讲师口头还举了等号，`!`、`-`、`=` 都不在名字允许的字符表中。 |
| `xxx`、`Xxx`、`_xx` | 在这条局部声明里，这三种写法都能被识别。C 区分大小写，`xxx` 和 `Xxx` 是两个不同的名字。 |
| `int xx0105876 = 123;` | 最后一次编辑。约 16:34，悬停显示 `(local variable) int xx0105876`。两个字母打头后可以连续接数字，字幕把这一串泛写成了“00000”。 |

片尾切回微软语法表。全节没有构建日志、控制台输出或变量值的运行结果；现场验证到编辑器识别了变量名和类型。

**规则的适用范围（整理者补充）。** 上表适合检查用基本拉丁字母、数字和下划线拼写的名字。C11 还规定了部分扩展字符的使用条件。实际取名也要避开保留名称：双下划线开头、下划线紧跟大写字母的名字始终保留；在文件作用域，变量或函数名也应避开下划线开头。课堂中的 `_xx` 是函数内的局部变量。给自己的变量起名时，可以沿用同节的 `number_2`，把下划线放在名字内部。[WG14 C11 草案 §6.4.2.1 标识符](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=77) · [§7.1.3 保留标识符](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=200)
