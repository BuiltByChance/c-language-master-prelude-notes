# 178 · 空指针表示什么，怎样把它用作“还没有目标”？

`char *ptr = NULL;` 创建了一个有确定值的指针变量，用空指针值表示它目前不指向任何对象。可以给它赋值，也可以用 `ptr == NULL` 判断是否已有目标；只有指向仍然存活的字符对象后，才能通过 `*ptr` 访问那个字符。[WG14 C11 草案 §6.3.2.3、§6.5.3.2](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf)

若只在函数里写 `char *ptr;` 而未初始化，这个普通局部变量的值不确定，连读取它做判空都不可靠。若目标已释放，旧指针也不会自动变成 `NULL`。因此判空能识别的是程序约定的“无目标”状态；对象是否仍然存活，要从它的创建和销毁位置判断。

**录屏所见。** 讲师在 Windows 桌面右击，选“新建 → 快捷方式”，打开“浏览”，留空目标。“下一步”不可用，第一次取消后临时图标消失。第二次以相同界面说明“稍后再指定目标”，在记事本写下 `char *ptr = NULL;`，没有编译或触发异常。

**整理者复习示例。** 以下两行输出分别验证尚未选择字符和选择后的状态。

```c
#include <stdio.h>

int main(void)
{
    char letter = 'C';
    char *ptr = NULL;
    if (ptr == NULL)
        puts("no selection");

    ptr = &letter;
    printf("%c\n", *ptr);
    return 0;
}
```

输出依次是 `no selection` 和 `C`。
