# 121 · 怎样用一个循环打印某个数的十行乘法表？

输入的 `num` 在十行中保持不变，另一个因子 `index` 从 1 增加到 10。每一行直接计算 `num * index`，不需要保存前一行的结果。`index <= 10` 包含第十行，`index` 增加到 11 时退出。

**录屏中的编译错误。** `for` 第一栏声明的是 `index`，讲师却在 `printf` 中用了 `i`，Visual Studio 报 `C2065`，提示 `i` 未声明。他把两处都改成 `index`，三个输出参数按顺序成为 `num`、`index`、`num * index`，重新生成后才运行成功。

在 Visual Studio 的 C 控制台项目中，将下面的代码放进 `.c` 文件，按 `Ctrl+F5`，输入一个 `uint32_t` 范围内的十进制正整数。录屏输入 `5`，从 `5 * 1 = 5` 到 `5 * 10 = 50` 共十行，退出码为 0。

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void)
{
    uint32_t num;
    puts("请输入正整数：");
    if (scanf_s("%" SCNu32, &num) != 1 || num == 0) {
        return 1;
    }
    for (uint32_t index = 1; index <= 10; index++) {
        uint64_t product = (uint64_t)num * index;
        printf("%" PRIu32 " * %" PRIu32 " = %" PRIu64 "\n",
               num, index, product);
    }
    return 0;
}
```

整理者补了读取检查，并在乘法前把一个因子转换为 `uint64_t`。例如输入 `500000000`，第十行的积是 `5000000000`，已超过录屏中 32 位无符号乘积的范围。
