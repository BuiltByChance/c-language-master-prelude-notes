# 048 · 怎样在 float、double 和 long double 之间选择

## 先确定什么差别会影响结果

| 需求 | 选择依据 |
| --- | --- |
| 显示测量值 | 讲师假设室温只显示到 0.1 度，传感器误差已有 0.2 度。在室温量级，`float` 足以满足这项显示要求。多存小数位也消除不了传感器误差。 |
| 一般数值计算或反复累加 | 接口允许，内存和传输成本也未成为瓶颈时，可从 `double` 起步。先写出允许的绝对或相对误差，再用代表性输入核对最终结果。估算范围时要包括最大的中间值和最接近零的有意义数值。 |
| 文件、网络或设备约定了 32 位二进制浮点格式 | 按接口约定编解码。若目标的 `float` 对应该格式，可用它存储，内部计算仍可提升为 `double`。对大量同类型数据，用元素数乘以单个元素的字节数算存储成本。按课堂读数，100 万个元素用 `float` 占 400 万字节，用 `double` 占 800 万字节。 |
| `double` 的精度或范围不足 | 缺有效数字时比较 `LDBL_DIG` 与 `DBL_DIG`，中间值太大时比较 `LDBL_MAX` 与 `DBL_MAX`。若担心极小值变成零，还可查对应的 `*_TRUE_MIN`。改用 `long double` 前，在目标平台确认所需指标有提升，再用原计算验证。 |

**整理者复测累加误差。** 在 Windows x64 上用 binary32 的 `float` 和 binary64 的 `double` 各从零开始，分别加 `0.1f` 和 `0.1` 共 100 万次，每步存回原类型。数学结果是 100000，实测分别为 `100958.34375` 和约 `100000.00000133`。若允许的绝对误差是 0.01，这组输入用 `float` 超标，用 `double` 达标。

## 在目标平台读懂三列输出

把课堂程序放进 Visual Studio 控制台项目的 `.c` 文件，选「调试」→「开始执行（不调试）」（Ctrl+F5）。编译目标应与要部署的平台一致。录屏用的是 `Project1` 项目中的 `display_float.c`，配置为 `Debug | ARM64`。

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("float       : size=%zu, digits=%d, max=%e\n",
           sizeof(float), FLT_DIG, FLT_MAX);
    printf("double      : size=%zu, digits=%d, max=%e\n",
           sizeof(double), DBL_DIG, DBL_MAX);
    printf("long double : size=%zu, digits=%d, max=%Le\n",
           sizeof(long double), LDBL_DIG, LDBL_MAX);
    return 0;
}
```

| 课堂实测 | `size`（字节） | `digits`（十进制有效数字） | `max`（最大有限值的显示结果） |
| --- | ---: | ---: | ---: |
| `float` | 4 | 6 | `3.402823e+38` |
| `double` | 8 | 15 | `1.797693e+308` |
| `long double` | 8 | 15 | `1.797693e+308` |

`*_DIG` 给出十进制往返转换可保留的有效位数。在正规数范围内，把这么多位有效数字的十进制数转成该类型，再按同样位数转回十进制，能还原原数。`123.45` 和 `0.0012345` 都有五位有效数字。整段算法经过许多次舍入，最终误差要另测。[C11 委员会草案 §5.2.4.2.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=49)

`sizeof` 只给出占用字节数，结果类型为 `size_t`，用 `%zu` 打印。课堂中后两行的精度和上界也相同，符合微软 C 对 `long double` 与 `double` 采用相同表示的说明。两者仍是不同的类型，其他 C 实现可以让 `long double` 表示更多值。写普通的 `double` 常量可直接用 `1.234566`，无需后缀。用科学记数法打印时，`long double` 对应 `%Le`，`float` 在可变参数位置提升为 `double`，对应 `%e`。[微软 C 浮点常量与类型](https://learn.microsoft.com/en-us/cpp/c-language/c-floating-point-constants?view=msvc-170) · [printf 格式说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170)

## 金额要求精确到分时

有限位二进制小数写不尽十进制的 0.1 和 0.01。若金额只到分，3.69 元可直接存成整数 369 分，并按余额范围选择能装下它的整数类型。若利率或汇率计算会产生不足一分的结果，应明确在哪一步、按什么规则舍入。数据库可用十进制定点类型，例如 MySQL 的 `DECIMAL(p,s)`，`p` 是总位数，`s` 是小数位数。讲师说后续练习有时会简化为 `double`，本节没有执行账务计算。[MySQL 精确定点类型](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/fixed-point-types.html)
