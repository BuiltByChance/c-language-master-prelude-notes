# 151 · 怎样从任务要求推导函数的参数和返回类型？

写函数前依次回答五个问题：它完成什么任务？为此必须知道什么？调用者要拿到什么结果？哪些 C 类型能表达这些输入和结果？怎样命名才能在调用处看懂用途？例如，求两个整数的和需要两个数，调用者还要用这个和时就返回数值；只需打印一条提示的函数可以返回 `void`。

**把问题缩成一条原型。** 要判断“给定的公历年份是不是闰年”，只需输入一个年份，返回是或否。因此原型可写成 `bool is_leap_year(int year);`。月份、日期和最终显示哪一句话都不参与判断。调用处决定用这个真假值打印提示，或者据此计算二月天数。

```c
#include <stdbool.h>
#include <stdio.h>

bool is_leap_year(int year);

int main(void)
{
    int years[] = {2024, 2023, 1900, 2000};
    for (int i = 0; i < 4; ++i) {
        int year = years[i];
        printf("%d年%s\n", year, is_leap_year(year) ? "是闰年" : "不是闰年");
    }
    return 0;
}

bool is_leap_year(int year)
{
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}
```

公历的普通年份能被 4 整除就置闰；整百年份必须还能被 400 整除。判断表达式已经给出真假，函数可直接返回它。讲师建议用 `true`、`false` 表意；`bool` 函数返回整数 0 或 1 也合法，返回值会转换成对应布尔值。课堂验证了 2024 是闰年、2023 是平年。整理者在复习代码中加入 1900（平年）和 2000（闰年）；只写 `year % 4 == 0` 会误判 1900，只排除所有整百年则会误判 2000。[美国海军天文台的公历闰年规则](https://aa.usno.navy.mil/faq/leap_years)

**显示出错时，先分清判断和格式。** 片中合并两条输出语句时，格式串含 `%d` 和 `%s`，却只提供了三目表达式选出的字符串。要按顺序传入整数 `year` 和字符串；缺少实参会使行为未定义。修正后，判断函数本身无需改动。

课堂将 `return 0;` 用作 `main` 的成功退出状态。在标准的宿主环境中可写 `int main(void)`；从 C99 起，这种 `main` 执行到末尾也等价于返回 0。早期省略返回类型的代码和某些编译器接受的 `void main` 都不宜当成可移植的入口写法。[C99 §5.1.2.2](https://open-std.org/JTC1/SC22/wg14/www/docs/n1124.pdf)
