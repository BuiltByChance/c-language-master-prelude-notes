# 010 · C 的元素：标记、空白字符与 Tab 对齐

## 先给代码分词

标记（token）是编译器在词法上认作一项的单位。课堂把源码一段段选中，检查一个名字、一个数或一个符号在哪里结束。

| 课堂片段 | 划出的标记 | 读法 |
| --- | --- | --- |
| `int main(void)` | `int`、`main`、`(`、`void`、`)` | 关键字、函数名和每个括号各占一项。 |
| `int number = 1;` | `int`、`number`、`=`、`1`、`;` | 声明并初始化一个整数。 |
| `number = 456;` 与 `number == 456` | 第一处的 `=` 是一个标记，第二处的 `==` 也是一个标记，`456` 各是一个整数常量。 | 前者写入值，后者比较相等，不能把两个相邻的等号拆开读。 |

查术语可从 **Microsoft Learn → C 语言参考 → C 的元素 → C 标记** 进入。微软的教学页将关键字、标识符、常量、字符串字面量、运算符、标点分列。C11 语法将 `=`、`==` 等符号也列在 *punctuator* 中。[微软《C 的元素》](https://learn.microsoft.com/zh-cn/cpp/c-language/elements-of-c?view=msvc-170) · [微软《C 标记》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-tokens?view=msvc-170) · [C11 委员会草案 §6.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=75)

## 改空白前，比较改动前后读出了什么

空格、水平制表符、换行、回车、换页、垂直制表符都是空白字符。以下四种情形得到的结果不同。[微软《空白字符》](https://learn.microsoft.com/zh-cn/cpp/c-language/white-space-characters?view=msvc-170)

- **相邻的词。** `int number;` 有类型和变量名两个词，删掉中间的空白就成了一个标识符 `intnumber`。而在 `number=123;` 的等号两侧加空格，标记仍然相同，空格有助于读者辨认赋值。
- **头文件名。** `#include <stdio.h>` 的尖括号圈定要查找的头文件名。讲师临时在括号里面加空格写成 `< stdio.h >`，里面的字符随之改变。他恢复原样后才继续，课上没有生成这个改写版本。[C11 委员会草案 §6.10.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=182)
- **两条声明之间。** 课堂把代码挤成一行 `{int number;int number_2 = 123;`，分号仍然隔开两条声明。讲师在 **Debug / x64** 配置下选 **Debug → Start Without Debugging（Ctrl+F5）** 生成并运行。输出为 **1 个项目成功、0 个失败**。四条 **C4101** 提示有未使用的局部变量，控制台以退出码 **0** 结束，程序本身没有打印文字。按行拆开这些声明有助于分别读到每个变量。[微软对 C4101 的说明](https://learn.microsoft.com/zh-cn/cpp/error-messages/compiler-warnings/compiler-warning-level-3-c4101?view=msvc-170)
- **行注释末尾。** 恢复排版时，`int number_2 = 123;` 一度跟在 `// 定义 definition` 后面，整行变成注释色。把声明移到下一行，代码着色随即恢复。在这里删去换行会使后面的声明落入注释。

## 缩进、制表位与实际写入的字符

课堂先输入 `number=345` 再敲分号，编辑器把它排成 `number = 345;`。接着输入 `if (number == 456)` 以及一对花括号，在花括号之间回车，光标自动缩进到块内。格式化和缩进都发生在编辑器里。讲师又在两条长短不同的声明末尾添加 `//` 注释，用 Tab 让两个 `//` 对齐。录像结束时，块里还留着一行未写完的 `number`，状态栏有 1 个错误标记，最后这份编辑稿没有再次生成。

水平制表符使光标前进到下一个制表位。用整理者的例子来算，取从 0 开始的列号，制表位每 4 列一个，光标在第 1 列按 Tab 前进 3 列到第 4 列，在第 3 列按就只前进 1 列。因此画面上多出几列空白，单看宽度无法知道文件里存的是空格还是制表符。[水平制表符定义](https://datatracker.ietf.org/doc/html/rfc20#section-5.2)

**要复现项目的排版**，先看项目约定一层缩进几列、用空格还是制表符。Visual Studio 2022 从 **工具 → 选项 → 文本编辑器 → 所有语言 → 选项卡（Tabs）** 查看。只改一种语言时选相应语言的子项。以下字段按微软文档核实于 2026-11-19，课上没有改动这些设置。[Visual Studio 缩进与制表设置](https://learn.microsoft.com/zh-cn/visualstudio/ide/options-text-editor-all-languages-tabs?view=vs-2022)

| 字段 | 怎样选、改后看哪里 |
| --- | --- |
| 制表位大小（Tab size） | 控制两个制表位之间相隔几列。项目若按 4 列对齐，另一个人设成 8 列时，同一行里的制表符会显示为不同宽度。 |
| 缩进大小（Indent size） | 控制嵌套一层缩进几列。改它时看花括号内下一层代码从哪一列开始。 |
| 插入空格 / 保留制表符 | 约定只存空格时选前者，缩进写入普通空格。约定使用制表符时选后者，编辑器尽量写制表符，写不满的余数用空格补齐。 |

课上还口头比较了存储开销。以 UTF-8 文件为例（整理者补充），一个制表符占 1 字节，四个普通空格占 4 字节；显示时对齐到了同一列，文件实际占用仍可能不同。[UTF-8 编码规则 §3](https://datatracker.ietf.org/doc/html/rfc3629#section-3)
