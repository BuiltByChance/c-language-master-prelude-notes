# 123 · 怎样让三角形的每一行比上一行多一颗星？

外层仍用 `i < size` 决定画多少行。要让每行逐渐变长，把方阵程序的内层条件从 `j < size` 改成 `j <= i`。因为 `j` 从 0 开始，第 `i` 行按零起算会取到 `0, 1, …, i`，恰好打印 `i + 1` 颗星。每行结束后换行。

例如第一行 `i = 0` 时，`0 <= 0` 成立，能打印一颗星。`j` 增到 1 后条件失败，换行。第二行的 `i` 是 1，`j` 又从 0 起步，0 和 1 都能通过判断，因此打印两颗。若误写 `j < i`，第一行会是空行，最后一行也会少一颗。

## 运行五行样例

在 Visual Studio 的 C 控制台项目中，把下面的整理者复习代码放进 `.c` 文件，按 `Ctrl+F5`。输入 `5`，录屏中实测的图形如下。五行从同一列开始，每行的星数依次为 1、2、3、4、5。

```text
*
* *
* * *
* * * *
* * * * *
```

```c
#include <stdio.h>

int main(void)
{
    int size;
    puts("请输入三角形的行数：");
    if (scanf_s("%d", &size) != 1 || size < 1) {
        return 1;
    }
    for (int i = 0; i < size; i++) {
        for (int j = 0; j <= i; j++) {
            printf("* ");
        }
        putchar('\n');
    }
    return 0;
}
```
