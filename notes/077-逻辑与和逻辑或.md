# 077 · 判断两个条件，该用逻辑与还是逻辑或？

在 C 中，整数 `0` 为假，非零为真。要求两个条件都成立，用逻辑与 `&&`。只要至少一个成立就可以，用逻辑或 `||`，包括两个都成立的情况。两个运算符的结果都是 `int`，值为 `0` 或 `1`。[微软《C 逻辑运算符》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-logical-operators?view=msvc-170)

课堂把“账号正确”和“密码正确”看作两个判断结果。登录要求两项都通过，就用 `&&` 组合它们。讲师在 Visual Studio 中用下面两个整数代表一真一假。

```c
#include <stdio.h>

int main(void) {
    int condition_a = 1;
    int condition_b = 0;

    int res = condition_a && condition_b;
    printf("res = %d\n", res);

    res = condition_a || condition_b;
    printf("res = %d\n", res);
    return 0;
}
```

第一次只运行逻辑与，控制台输出 `res = 0`。追加逻辑或后再次运行，两行依次是 `res = 0` 和 `res = 1`。此时第二个条件为假，第一个条件为真就足以让逻辑或成立。

**怎样区分逻辑运算、数值相等和位运算？** 整理者把两个输入换成 `2` 和 `4`。它们数值不同，`2 == 4` 得 `0`。它们都非零，`2 && 4` 与 `2 || 4` 都得 `1`。换成单个符号就要比较二进制位。`0010` 和 `0100` 没有重合的 `1`，所以 `2 & 4` 得 `0`，`2 | 4` 得 `6`。

**右边的条件什么时候会执行？** 两个运算符都先算左边。`&&` 遇到左边为假、`||` 遇到左边为真时，结果已经确定，右边会被跳过，这叫短路。例如，整理者用 `count != 0 && total / count >= 60` 判断是否有人参加且平均分达到 60 分，`total` 是总分，`count` 是人数。`count` 为 `0` 时整个条件为假，除法不会执行。[C11 草案 §6.5.13–14](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=117)
