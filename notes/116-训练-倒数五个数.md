# 116 · 从用户输入的数倒数到 1，循环条件该怎么写？

“倒数五个数”是题目的由来。起点由用户输入，最后显示的数字固定为 1。`for (uint32_t index = start_number; index > 0; index--)` 把输入复制给计数器，每轮先输出当前值，再减 1。输出 1 后计数器变成 0，下一次判断失败，程序才打印“倒数结束”。

`index` 是无符号数，不能把条件写成 `index >= 0`。它减到 0 时条件仍为真，再减一次就回绕到 `UINT32_MAX`，会从头倒数一个极大的数。若需求确实要显示 0，可以保留 `index > 0`，在循环结束后单独打印一次 0。[C11 委员会草案 §6.2.5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=47)

## 在控制台运行

在 Visual Studio 的 C 控制台项目中，把以下代码放进 `.c` 文件，按 `Ctrl+F5`。`<inttypes.h>` 提供两组格式宏。读 `uint32_t` 用 `"%" SCNu32` 并传入变量地址，打印同一类型用 `"%" PRIu32` 并传入变量的值。[C11 委员会草案 §7.8.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=235)

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void)
{
    uint32_t start_number;
    puts("请输入倒数的起点：");
    if (scanf_s("%" SCNu32, &start_number) != 1) {
        puts("未读到整数。");
        return 1;
    }
    puts("倒数开始！");
    for (uint32_t index = start_number; index > 0; index--) {
        printf("%" PRIu32 "\n", index);
    }
    puts("倒数结束！");
    return 0;
}
```

录屏输入 `10`，控制台逐行显示 10 到 1，随后出现“倒数结束”，退出码为 0。整理者另测输入 `1` 只打印一个数字，输入 `0` 则两句提示之间没有数字。代码补上了读取失败检查。练习时输入只含十进制数字且能用 `uint32_t` 表示的值。无符号读入格式也允许前置负号，单看返回 1 不能判定用户输入了正数。
