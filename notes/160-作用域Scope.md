# 160 · 怎样判断一个变量名能在哪些地方使用？

在使用变量的那一行，从当前这一层大括号向外找已经出现的声明。最先找到的同名声明决定这个名字指向哪个对象。跳到另一个函数后，要从那个函数所在的块重新查找。**作用域**回答的是“这段代码能否用这个名字”，即使两个函数先后执行，它们各自的局部变量名也不会因调用而互相可见。

| 录屏中的声明位置 | 可使用的位置 |
|---|---|
| `main` 内的 `int number = 10;` | 从声明处起，到 `main` 对应的右大括号为止。 |
| `demoFunction` 内的 `int32_t local_var = 5;` | 只在这个块的声明之后可见。`main` 若需要其结果，可让函数返回该值。 |
| 两个函数之前的 `int32_t g_global_var = 10;` | 具有文件作用域，后面定义的两个函数都可以用这个名字读写同一对象。 |

**按运行顺序核对输出**。录屏先由 `main` 调用 `demoFunction()`，它依次打印局部值 **5**、全局值 **10**。函数返回后，`main` 再打印全局值 **10**，进程以 0 退出。讲师另推演在两个函数内各对全局值加 1 后得到 **12**，实际运行前已移除这两次自增。

课程把变量分成“函数内、文件内、整个程序内”来讲。C 标准把这里函数体内变量名的可见区域称为**块作用域**，还可以小到一对内层大括号。跨源文件共享同一对象还需要外部链接，以及使用处可见的声明，例如在头文件里写 `extern int32_t g_global_var;`，并只在一个源文件里给出定义。课堂只打开了一个源文件。[WG14 C11 草案 §6.2.1、§6.2.2](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=53)
