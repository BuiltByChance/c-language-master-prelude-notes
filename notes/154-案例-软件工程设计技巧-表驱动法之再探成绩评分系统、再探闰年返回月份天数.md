# 154 · 月份和成绩怎样换成能安全查表的下标？

当输入和输出之间有一组可以列全的对应关系，而且能由输入算出索引时，可以把规则写成表。改规则时改对应的表项即可。建表前先写下合法输入的最小值、最大值，分别算出它们对应的下标；越界输入要在取表项之前拦住。

| 问题 | 合法输入与索引 | 容易遗漏的表项 |
| --- | --- | --- |
| 公历一个月有几天 | 月份 `1..12` 对应 `month - 1`，范围 `0..11` | 2 月在下标 1，闰年取 29，其余取 28。月份越界返回 `-1`。 |
| 整数成绩属于哪一档 | 分数 `0..100` 对应整数商 `score / 10`，范围 `0..10` | 90～99 共用下标 9，100 单独用 10。整张表有 11 项，前六项给 0～59 分。越界返回自定标记 `"X"`。 |

录屏文件名为 `table.cpp`。下面是整理者按相同规则编写的 C 复习版。月份表在每次调用时按传入的年份初始化，`const` 防止随后改写它。成绩表直接存放字符串，满分可以使用两个字符的等级 `"A+"`。

```c
#include <stdio.h>

int days_in_month(int month, int year)
{
    if (month < 1 || month > 12) return -1;
    int leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
    const int days[] = {31, leap ? 29 : 28, 31, 30, 31, 30,
                        31, 31, 30, 31, 30, 31};
    return days[month - 1];
}

const char *grade(int score)
{
    static const char *const grades[] = {
        "F", "F", "F", "F", "F", "F", "D", "C", "B", "A", "A+"
    };
    if (score < 0 || score > 100) return "X";
    return grades[score / 10];
}

int main(void)
{
    printf("%d %d %d\n", days_in_month(2, 2024), days_in_month(2, 2025),
           days_in_month(13, 2024));
    printf("%s %s %s %s %s\n", grade(59), grade(60), grade(99), grade(100), grade(101));
    return 0;
}
```

复习版的两行结果为 `29 28 -1` 和 `F D A A+ X`，分别检查二月的两个分支、越界保护和分档端点。若让负分先除 10，例如 `-1 / 10` 得 0，就可能把无效分数判为 F。

**用打印结果定位错误。** 课堂的第一张等级表存单个 `char`，55 分查到 `'F'`。用 `%d` 输出时得到 70，是这台机器的字符编码值；改用 `%c` 显示 F。那一版 100 分为 A、78 分为 C。要让满分显示 A+，讲师将表项和返回值改成指向字符串的指针，把 `'X'` 改成 `"X"`，用 `%s` 打印，现场才得到 A+。
