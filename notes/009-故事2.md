# 009 · 故事2：读懂 C 标准、版本迁移和语言排行榜

## 看懂教材封面和标准编号

**K&R C** 指正式标准问世前，许多人参照《The C Programming Language》第一版（1978）使用的 C。K 和 R 是封面上的 **Brian W. Kernighan** 与 **Dennis M. Ritchie**。讲师口述时提到的 Ken Thompson 开发过 C 的前身 B。读这本旧书可以了解早期 C，读按 C11 编写的教材则能学习后来加入的特性。[里奇对语言和教材历史的回顾](https://www.nokia.com/bell-labs/about/dennis-m-ritchie/chist.html)

| 读到的名称 | 对学习或维护代码有什么影响 |
| --- | --- |
| ANSI C、C89、C90 | 在讨论第一版标准时，C89 是美国标准的称呼，C90 是对应的 ISO 国际标准，技术内容相同。 |
| C99 | 增加了变长数组等特性。教材的数组示例用到这类特性时，先查编译器及当前模式是否支持。 |
| C11 | 引入原子操作、线程支持等。讲师把“至少学到 C11”作为本课程选教材的尺度。 |
| C17 / C18 | 指 2018 年出版的同一版，主要修正 C11 的缺陷。 |
| C2x、C23 | C2x 是修订期间的名字。最终通称 C23，正式编号为 **ISO/IEC 9899:2024**。 |

看标准处于什么阶段，要看文件上的**动作和日期**。录屏中 WG14 的日程 N3132 把 2024-02-12 列为“提交文件供出版”，讲师据此预计二月发布。2026-11-19 核实，ISO 记录的第五版实际出版时间是 **2024 年 10 月**。“C24”仅是课上构造迁移情境时用的假设名。[WG14 当时的日程](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3132.pdf) · [ISO 出版记录](https://www.iso.org/standard/82075.html) · [GCC 对各版 C 标准的说明](https://gcc.gnu.org/onlinedocs/gcc/Standards.html) · [各版特性与 GCC 支持情况](https://gcc.gnu.org/projects/c-status.html)

## 项目只剩一个月交付，要不要切标准

课堂设定是团队已有大量 C11 源码，只剩一个月交付，新标准刚发布。按当前标准可以完成任务，而切换需要成员学规则、更改受影响的代码并重新验证。讲师据此倾向于先按原有标准交付。这是他画在 Hello World 示例旁的假设项目，现场没有改编译器模式。

**整理者的迁移示例。** 查清项目原来的语言模式和实际要用的新特性，再按编译器的迁移说明找可能坏掉的旧代码。例如 `int nullptr = 1;` 中的名字在 C11 可以用，到了 C23，`nullptr` 成为关键字，得改名。用 GCC 的团队可以显式选旧模式（如 `-std=c11`）维持现有构建，另用目标模式构建并跑原有测试。修复、验证的工作量能放进交付周期时，再决定切换。[GCC 的 C23 迁移说明](https://gcc.gnu.org/gcc-15/porting_to.html) · [GCC 方言选项](https://gcc.gnu.org/onlinedocs/gcc/Standards.html)

**考试环境另有依据。** 讲师回忆学校使用过 Visual C++ 6.0，提到等级考试使用 Visual C++ 2010。6.0 在 1998 年发布，此后还有服务包。备考应从教育部教育考试院的大纲目录选“二级 C 语言程序设计”，翻到“考试方式 → 考试环境”。录屏时期的 2023 年版写的是中文版 Windows 7 和 Visual C++ 2010 学习版。2026-11-19 核实，目录所列的 2025 年版仍这样规定。该要求限定于此考试，平时开发按项目的编译器与标准选环境。[微软 6.0 发布公告](https://news.microsoft.com/source/1998/09/02/microsoft-announces-worldwide-availability-of-visual-studio-6-0-at-dev-days-98/) · [微软服务记录](https://learn.microsoft.com/en-us/visualstudio/releases/2022/servicing-vs2022) · [2023 年二级 C 大纲](https://ncre.neea.edu.cn/res/Home/2306/6016844d02b8b7fb5d9ea3981f0a0eb9.pdf?download=%E4%BA%8C%E7%BA%A7C%E8%AF%AD%E8%A8%80.pdf) · [考试院大纲目录](https://ncre.neea.edu.cn/html1/report/2412/185-1.htm)

遇到“C 很靠近机器”这样的描述也可追问一个实例。讲师放大 Motorola 6800 的汇编清单，里面能把地址、机器码、指令助记符和注释逐列对照。他用它解释 C 与汇编的关系，课堂停在看清单，没有编译两种语言比较结果。

## 月榜第一、年度语言、岗位需求，分别看什么

课上打开的是 **2024 年 1 月**的 TIOBE 月榜。表头的 `Ratings` 是当月指数评分，`Change` 是和上年同期相比的变化，看“涨得最多”要读后者。

| 录屏数据 | 当月排名与评分 | 同比变化 |
| --- | --- | ---: |
| Python | 第 1，13.97% | −2.39 个百分点 |
| C | 第 2，11.44% | −4.81 个百分点 |
| C# | 第 5，7.16% | +1.43 个百分点 |

讲师指着 Python 称其为“2023 年年度语言”。Python 的确在这个月排第一。TIOBE 把年度奖授予过去一年评分涨幅最大的语言，2023 年得主是 **C#**。指数依据多家搜索引擎的查询命中数计算。若想判断一个地区需要多少 C 或 Python 程序员，得另看当地岗位及其职责，无法从这张表的百分比换算。[TIOBE 年度奖规则和历届得主](https://www.tiobe.com/tiobe-index/) · [TIOBE 指数计算方法](https://www.tiobe.com/tiobe-index/programminglanguages_definition/)

讲师用培训、金融数据分析和 TensorFlow 开发说明，人们关注同一门语言，可能是为了做不同的事。以 TensorFlow 官方指南为例（整理者补充），已有运算能解决问题，就用 Python 把它们组合起来。要提供已有运算难以表达或效率不足的新运算，才考虑编写 C++ 算子内核，再向 Python 暴露接口。选择要学哪门语言时，先把目标说具体到“调用现成工具”还是“实现工具内部的计算”。[TensorFlow 自定义算子指南](https://www.tensorflow.org/guide/create_op)
