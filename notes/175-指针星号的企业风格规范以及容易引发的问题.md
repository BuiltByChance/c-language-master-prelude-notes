# 175 · 为什么 int* p, q 只声明了一个指针？

`int* p;`、`int *p;` 和 `int * p;` 都声明名为 `p`、类型为 `int *` 的变量。遇到逗号时，先读共同的 `int`，再**逐个读声明符**：`int* p, q;` 中只有 `p` 带星号，等价于分开写 `int *p;` 和 `int q;`。若两者都要指向整数，应写 `int *p, *q;`。[WG14 C11 草案 §6.7.6.1](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=148)

```c
#include <stdio.h>

int main(void)
{
    int value = 100;
    int *p = &value;
    int q = 123;

    printf("%d\n", *p);
    printf("%d\n", q);
    return 0;
}
```

复习版把课堂的一行声明拆开。录屏实跑先通过 `*p` 读到 `value` 的 **100**，再直接读 `q` 得 **123**。讲师口头提到 `*p = 123;`，这行若执行会改写 `value`；实跑时赋值给 123 的是 `q`。

项目可统一星号靠类型或靠名字的排版。若同一行里会混用指针和普通整数，分行声明并在定义时给出初值，读者就能直接看见谁保存地址、谁保存数值。讲师将靠近类型的排版称作“微软风格”；改变空格不会改变 C 的声明规则。
