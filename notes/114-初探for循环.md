# 114 · for 的三段按什么顺序执行，接力计数怎样避免重复一圈？

`for (初始化; 条件; 更新)` 的执行顺序是 **初始化一次 → 检查条件 → 执行循环体 → 更新 → 再检查条件**。第一次检查就为假，循环体一次也不执行。正常走完循环体或执行 `continue` 都会到更新处。执行 `break` 则直接离开循环。[Microsoft Learn《for 语句》](https://learn.microsoft.com/zh-cn/cpp/c-language/for-statement-c?view=msvc-170)

## 先确定圈数，再确定屏幕上的编号

录屏把目标设为 10。`for (uint32_t lap = 0; lap < 10; lap++)` 实跑输出 0～9，共十次。要让跑者看到第 1～10 圈，起点改成 1，条件也要改成 `lap <= 10`。只改起点、仍保留 `< 10`，第 10 圈就不会打印。

用片尾的 `for (uint32_t lap = 1; lap <= 5; lap++)` 手算：进入时 `lap` 是 1，输出 1 后才自增到 2。输出 5 后仍会自增到 6，下一次检查 `6 <= 5` 为假。因此有五次输出、五次自增、六次条件检查。讲师称 `lap++` 为“迭代点”，这里指每轮后的更新动作。走过一轮循环才称为一次迭代。

## 两个跑者共用一个圈号

只在一个循环中使用的计数器可以声明在 `for` 的第一段。出了该循环，这个名字就不再可见。如果第二个循环需要接着使用第一个循环结束时的值，把变量声明在两者所在的外层代码块。

录屏的接力版把变量放到了外层，但第二个循环又写了 `current_lap = 5`。控制台先输出第一人的 1～5，再输出第二人的 5～10，第 5 圈出现两次。要让两人各跑五圈，保留第一段结束时已经得到的 6。下面是整理者的接力写法，在 Visual Studio 的 C 控制台项目中按 `Ctrl+F5` 可核对输出。

```c
#include <stdio.h>

int main(void)
{
    const int total_laps = 10;
    int lap;
    for (lap = 1; lap <= 5; lap++) {
        printf("第一人：第 %d 圈\n", lap);
    }
    for (; lap <= total_laps; lap++) {
        printf("第二人：第 %d 圈\n", lap);
    }
    return 0;
}
```

第二个 `for` 的第一个分号前留空，表示直接检查现有的 `lap`。运行时交接处应连续出现“第一人：第 5 圈”和“第二人：第 6 圈”，最后一行是“第二人：第 10 圈”。
