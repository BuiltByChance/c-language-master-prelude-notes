# 141 · 省略数组长度、只写部分初值，分别会得到多少个元素？

先看方括号是否写了长度，再看大括号给哪些位置赋了初值。录屏中的三个定义都在 `main` 内，实际输出如下。

| 定义 | 实际形状 | 控制台核对结果 |
| --- | --- | --- |
| `int inferred[] = {1, 2, 3};` | 3 个 `int`，下标 0～2 | `inferred count = 3` |
| `int partial[5] = {1};` | 5 个 `int`，下标 0～4 | `partial = 1 0 0 0 0` |
| `int matrix[][3] = {{1}, {2}};` | 2 行，每行 3 个 `int` | 第 0 行 `1 0 0`，第 1 行 `2 0 0` |

第一例用 `sizeof inferred / sizeof inferred[0]` 将整个数组的字节数除以单个元素的字节数，结果为 3。在数组定义所在处使用这个式子。省略长度让编译器根据初值推定容量，之后仍只能改写已有三项。

第二例已经明确指定五项，`{1}` 将第一项初始化为 1，其余四项由 C 的规则补零。如果改为 `int partial[5];`，这组普通局部元素就没有可依赖的初值。补零只适用于容量以内的位置，`partial[5]` 已经越界。

第三例的每组内层大括号初始化一行，因此两组确定两行。`[3]` 规定每行能放几个整数，也决定走到下一行要跨过几个元素，不能再省略。讲师把两个维度都写成 `[]` 后，Visual Studio 构建失败并报告 C2087“缺少下标”。表中的成功输出来自保留 `[3]` 的版本。两行分别只给第一列赋值，同行余下的两列补零。[C11 委员会草案 §6.7.9 第 21、22 段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=159)
