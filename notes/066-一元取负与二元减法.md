# 066 · 同一个减号，怎样分清取负和减法？

读到一个 `-`，先找它直接作用的操作数。`-x` 只对 `x` 取相反数，属于一元运算。`x - y` 用左边的值减去右边的值，属于二元运算。操作数可以是一整个表达式。

课堂在 Visual Studio 中用 `int32_t number_2 = -number_1;` 验证了取负。`number_1` 为 `10` 时，程序依次打印 `10`、`-10`。把初值改成 `-10` 再运行，依次打印 `-10`、`10`。取负产生一个新值，`number_1` 本身没有改变。

沿用第二次运行的值，读 `int32_t total_number = -(number_1 - number_2);` 可以分成两步。

1. 括号内的 `-` 有两个操作数，算出 `-10 - 10`，差为 `-20`。
2. 括号外的 `-` 以整个差为唯一的操作数，对 `-20` 取负，得到 `20`，用它初始化 `total_number`。课堂只写出了这行，`20` 由整理者另行运行核对。

如果写成 `number_1 -;`，减号左边已有 `number_1`，右边却紧跟分号。课堂将鼠标停在标记处，编辑器提示 `expected an expression`。要做减法就补上右侧表达式，例如 `number_1 - number_2`。要给原值取负则写 `-number_1`。[一元算术运算符 §6.5.3.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=107) · [二元减法 §6.5.6](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=111)

## 无符号数前加负号会怎样？

课堂最初把两个变量都声明为 `uint32_t`。对值为 `10` 的 `number_1` 写 `-number_1`，MSVC 报 `C4146`，这一版生成失败。C 允许对无符号整数取负。结果存入 `uint32_t` 时按 2³² 取模。整理者单独运行得到 `4294967286`，即 2³² − 10。微软将 C4146 列为警告，`/sdl` 可将其提升为错误。录屏没有展示该项目的编译选项。[无符号算术 §6.2.5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=58) · [微软 C4146 说明](https://learn.microsoft.com/zh-cn/cpp/error-messages/compiler-warnings/compiler-warning-level-2-c4146?view=msvc-170)

要在本例中保存并显示 `-10`，把两个变量都改为 `<stdint.h>` 的 `int32_t`，并把 `printf` 的十进制格式宏从 `PRIu32` 改为 `PRId32`。两个宏均由 `<inttypes.h>` 提供，例如 `printf("%" PRId32 "\n", number_2);`。[定宽整数的格式宏 §7.8.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=235)
