# 054 · 怎样从变量名看出平均速度公式的单位是否一致？

`s = d / t` 能算出一个数，单看这行却认不出 `d` 是路程还是直径，也看不出 `t` 用秒还是小时。给有单位的量命名时，先写它在计算中代表什么，再写数值采用的单位。课堂里的分母用 `duration_h`，让读者知道存的是经过了多少小时。

```c
#include <stdio.h>

int main(void)
{
    float distance_km = 120.0F;
    float duration_h = 2.0F;
    float average_speed_kmh = distance_km / duration_h;

    printf("average speed = %.1f km/h\n", average_speed_kmh);
    return 0;
}
```

右边用路程（千米）除以耗时（小时），所得单位是千米/小时，与左边的 `_kmh` 相符。变量名里不能写 `/`，所以课堂用 `_kmh` 作后缀，输出字符串里仍写 `km/h`。原版程序在录屏中打印 `average speed = 60.0 km/h`。讲师展示了上面的改名版，整理者独立运行后得到相同输出。[微软 C 标识符语法](https://learn.microsoft.com/zh-cn/cpp/c-language/c-identifiers?view=msvc-170)

## 遇到不同单位的输入，在哪里换算？

**整理者复测。** 同一段路程若由上游提供为 `distance_m = 120000.0F`，直接写 `float distance_km = distance_m;` 也能编译。两边都是 `float`，赋值会把数值 120000 原样传过去。再除以 2 小时，程序便打印 `60000.0 km/h`。在接收处写 `float distance_km = distance_m / 1000.0F;`，再用原公式计算，输出恢复为 `60.0 km/h`。

## 名字写到多具体？

- 一个函数里只有一段路程，`distance_km` 就够了。同时要保存起始距离和剩余距离时，用 `start_distance_km` 和 `remaining_distance_km` 标明角色。课堂只声明了这两个量，计算平均速度仍用 `distance_km`。
- 局部坐标 `x`、`y` 或几行循环中的计数器 `i`，读者从紧邻的代码就能认出含义，可以用短名。若需要翻回定义才知道字母代表哪种业务量，就把那个含义写进名字。
- 同一项目用同一种拼法表示同一个单位。例如统一用 `_s` 表示秒，`_ms` 表示毫秒。这样看到后缀不同，就知道要查单位换算，无须猜 `_s`、`_sec` 和 `_seconds` 是否各有含义。
