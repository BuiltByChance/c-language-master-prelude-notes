# 005 · 本门课注意每节的标题

看播放页右侧的**视频选集**，先读标题里的星号和括号，再决定要练到什么程度。讲师默认学员已会使用 Visual Studio 2022 的基本操作。

| 标记 | 怎样学 |
| --- | --- |
| ⭐ 或“重要” | 重点掌握。例如“int 类型变量的表示范围的计算原理”，复习时应能自己说出计算过程。 |
| “理解即可” | 能解释例子说明了什么就可继续。“基本术语形象单口相声”第一节标了“理解即可”，第二节标了“重要”，两节要求不同。 |
| “选修” | 第一次听不懂可以先跳过。例如浮点数范围原理、标为“难、可忽略、严重超纲”的五子棋练习。若讲师只说“接下来这段是选修”，这个提示只适用于那一段。 |

**按标题找旧课。** 同一节“int 类型变量的表示范围的计算原理”，录屏旧选集是 P24，本套文件是 P25（整理者对照）。回找时用标题关键词，再核对当前集号。录屏时五子棋“规则完善”仍列在选集里，讲师说的是计划覆盖或移到后篇重录，现场只展示了目录。
