# 149 · 怎样把实参交给形参，再把计算结果带回调用处？

在 `greet(18, 1)` 中，`18` 和 `1` 是本次调用的**实参**。在函数定义 `void greet(int age, bool gender)` 中，`age` 和 `gender` 是接收值的**形参**。C 按位置传值，第二次调用 `greet(20, 0)` 会给这两个形参新的值。录屏约定真显示“男”、假显示“女”，用 `%d` 输出年龄，用 `%s` 输出所选字符串。原型与定义的参数类型及次序必须相容，原型中的参数名可以省略。

**要让谁取得结果？** 函数只负责显示时，可以返回 `void`，在函数内 `printf`。若调用者还要使用总和，则返回 `int` 并写 `return num1 + num2;`。单独写 `num1 + num2;` 会丢弃结果，既没有把 15 显示出来，也没有把 15 交给调用者。返回的表达式在交给调用者前会按函数的返回类型转换。[Microsoft 的 C return 说明](https://learn.microsoft.com/en-us/cpp/c-language/return-statement-c?view=msvc-170)

以下复习版保留录屏的两组实参，并把“先存变量”和“直接使用返回值”放在一起比较。

```c
#include <stdbool.h>
#include <stdio.h>

void greet(int, bool);
int add(int, int);

int main(void)
{
    greet(18, 1);
    greet(20, 0);
    int number = add(7, 8);
    printf("%d\n", number);
    printf("%d\n", add(7, 8));
    return 0;
}

void greet(int age, bool gender)
{
    printf("%d %s\n", age, gender ? "男" : "女");
}

int add(int num1, int num2)
{
    return num1 + num2;
}
```

输出应依次为 `18 男`、`20 女`、`15`、`15`。要在后面多次使用同一次计算的结果，就保存 `number`；只需立即打印一次，可直接把 `add(7, 8)` 作为 `printf` 的实参。
