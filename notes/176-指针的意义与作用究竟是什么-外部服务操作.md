# 176 · 为什么把地址交给函数？桌面快捷方式能说明哪一部分？

若只需在当前函数把数组元素从 103 改为 106，直接写 `floors[2] = 106;` 即可。若同一项更新工作要供多个调用者使用，可把“处理哪个对象”作为参数：调用者传该对象的地址，被调用的函数按自己的规则更新原对象。讲师说的“外部服务”，在 C 中可以只是同一程序里的另一个函数。

```c
#include <stdio.h>

static void change_room(int *room, int new_number)
{
    *room = new_number;
}

int main(void)
{
    int floors[] = {101, 102, 103, 104, 105};
    change_room(&floors[2], 106);
    printf("%d\n", floors[2]);
    return 0;
}
```

这是整理者的复习示例。参数 `room` 得到的是指针值的一份副本，`*room` 指代调用者仍然存在、可写的第三个元素。调用后从原数组读出 **106**，说明函数已更新原对象。

### 看清 Windows 快捷方式的三个位置

1. 右键桌面图标 → **属性**。在“常规”中看 **文件类型** 是否为 `Shortcut (.lnk)`，**位置**表示快捷方式文件自身存放在哪。讲师桌面上的原快捷方式只有 **1.65 KB**。
2. 在“快捷方式”选项卡看 **目标（Target）**，这是它要打开的对象；**起始位置（Start in）** 是启动时的工作目录。“打开文件所在的位置”可定位目标。原桌面项指向 Riot 客户端，而讲师机器上的游戏目录位于 Z 盘，属性显示 **23.2 GB、572 个文件、73 个文件夹**。把桌面图标复制给别人只会复制链接文件。
3. 需要新的入口，可在目标上右键 → **显示更多选项 → 发送到 → 桌面快捷方式**。讲师为 `LeagueClient.exe` 和文件夹展示了这种操作；末段删除快捷方式后，资源管理器仍显示原文件夹。直接双击游戏子目录里的 `League of Legends.exe` 则出现启动方式无效提示，经 `LeagueClient.exe` 打开的是 Riot 客户端。

快捷方式可以类比“通过一个独立的东西找到目标”。Windows 的 `.lnk` 保存供 Shell 定位目标的资料；记事本里写的 `char *shortcut_lol` 只是在类比路径字符串。对指向路径首字符的 C 指针做 `*shortcut_lol` 会得到那个字符，启动应用还需相应的系统调用。录屏没有编译这段文字。[Microsoft 对 Shell Links 的说明](https://learn.microsoft.com/en-us/windows/win32/shell/links)
