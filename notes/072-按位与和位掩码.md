# 072 · 怎样用按位与清除一位、检查一位？

把两个整数的二进制数从最低位对齐，逐列做 `&`。同一列的两位都是 `1`，结果位才是 `1`。课堂把 `12` 和 `25` 排成竖式，只有位权为 8 的那一列同时为 `1`。[微软 C 位运算符](https://learn.microsoft.com/zh-cn/cpp/c-language/c-bitwise-operators?view=msvc-170)

```text
  01100    12
& 11001    25
-------
  01000     8
```

讲师写第二行时从右往左填 `1、0、0、1、1`。读完整的二进制数要从左往右，所以 25 写成 `11001`。

课堂运行 `printf("%d\n", 12 & 25);`，控制台显示 `8`。作为对照，整理者用 `12 && 25` 判断两个数是否都非零，结果是 `1`。

## 清除第 2 位，保留其余位

从右往左编号，最低位是第 0 位，第 2 位的位权是 4。**掩码**是用来选择哪些位要保留、哪些位要清除的整数。掩码某位为 `0` 就清除原值的对应位，为 `1` 就保留它。因此，清一位的掩码只在目标位置放 `0`。

课堂画的八位掩码是 `11111011`，用 C17 十六进制写法是 `0xFBu`。如果 `x` 还有第 8 位或更高的位，`x & 0xFBu` 会把这些高位也清掉。下面是整理者复测的 `unsigned int` 写法，能保留目标位以外的每一位。

```c
unsigned int x = 0x10Cu;     // 第 8、3、2 位为 1
x &= ~(1u << 2);             // 结果 0x108，第 8、3 位仍为 1
```

`1u << 2` 只有第 2 位为 `1`，`~` 将各位取反，生成所需掩码。`&=` 把结果写回 `x`。

## 检查第 3 位是否为 1

要从整个运算结果判断一位，掩码只在目标位置放 `1`，其余全放 `0`。第 3 位的掩码是 `1u << 3`，即 `8u`。

```c
int is_set = (x & (1u << 3)) != 0u;
```

沿用上例的 `x = 0x108u`，`x & 8u` 得 `8`，再与零比较才得到 `1`。整理者再用 `x = 4u` 运行同一检查。虽然 `x` 非零，但第 3 位为零，`x & 8u` 和 `is_set` 都是 `0`。课堂只在板书上推导了这两种掩码。[C17 草案 §6.5.10](https://teaching.csse.uwa.edu.au/units/CITS2002/resources/n2176.pdf#page=89)
