# 187 · 同样是给 5 加 10，函数调用后为什么有时还是 5？

C 调用函数时，把实参的值复制给形参。传整数，函数拿到一份独立的整数；传对象的地址，函数拿到一份指针值，仍能通过它访问原对象。课堂把后一种用法称为“地址传递／引用传递”，这里并没有另一套参数传递机制。[WG14 C11 草案 §6.5.2.2 第 4 段及脚注 93](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=99)

| 课堂写法（每次从 5 开始） | 哪个操作写入调用者的变量 | 现场结果 |
| --- | --- | --- |
| `void` 函数接收整数，在函数里 `value += 10` | 只写了形参，调用方没有赋值 | 5 → 5 |
| 函数返回加十后的数，用另一变量 `number` 接收 | `number` 保存新值，保留原来的 `my_value` | 打印原值 5、`number` 为 15 |
| 函数返回加十后的数，调用方写 `my_value = add_ten_by_value(my_value)` | 赋值号左边的 `my_value` 接收返回值 | 5 → 15 |
| `void` 函数接收 `&my_value`，在函数里 `*value += 10` | `*value` 就是调用者的那个整数 | 5 → 15 |

如果希望调用者自行决定保留原值还是接收新值，用返回值；如果函数的任务就是更新指定对象，把该对象的地址传给它。例如下面两种调用的区别在于原值是否也随之改变。

```c
#include <inttypes.h>
#include <stdio.h>

static int32_t plus_ten(int32_t value)
{
    return value + 10;
}

static void add_ten_in_place(int32_t *value)
{
    *value += 10;
}

int main(void)
{
    int32_t original = 5;
    int32_t result = plus_ten(original);
    printf("original=%" PRId32 ", result=%" PRId32 "\n", original, result);
    add_ten_in_place(&original);
    printf("original=%" PRId32 "\n", original);
    return 0;
}
```

复习例的第一行显示原值 5、新值 15，第二行显示原对象已经变为 15。指针版要求传入一个仍存活、可写的整数地址；漏掉 `*` 写成 `value += 10` 会变成指针运算，无法给目标整数加十。
