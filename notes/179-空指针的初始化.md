# 179 · 指针从 NULL 改指向对象，两条分支怎样验证？

课堂在 Visual Studio 的 `teaching.c` 中把楼层指针初始化为 `NULL`。第一次运行只显示“没有指定楼层的地址！”，退出码为 0。讲师随后定义 `uint32_t number = 100;`，在判断之前加入 `ptr_to_floor = &number;`。第二次运行显示一个地址和“楼层号：100”，同样以 0 退出。改变的是指针保存的目标，`number` 本身始终为 100。

下面把课堂两次运行合成一次，便于复查。两次调用都先比较指针，只有指向 `number` 的那次才执行 `*floor`。这里能放心读取，是因为 `number` 在调用期间仍存活，且已经初始化。

```c
#include <inttypes.h>
#include <stdio.h>

static void show_floor(const uint32_t *floor)
{
    if (floor == NULL) {
        puts("No floor selected");
        return;
    }
    printf("address=%p, floor=%" PRIu32 "\n", (void *)floor, *floor);
}

int main(void)
{
    uint32_t number = 100;
    uint32_t *ptr_to_floor = NULL;
    show_floor(ptr_to_floor);
    ptr_to_floor = &number;
    show_floor(ptr_to_floor);
    return 0;
}
```

成功标志是第一行仅给出缺少目标的提示，第二行含 `floor=100`；具体地址及其文本格式可随运行环境变化。课堂把 `%p` 前的类型转换说成可选，标准要求该转换说明对应的参数为 `void *`，所以例程显式转换打印地址，并以 `PRIu32` 打印无符号的楼层值。[WG14 C11 草案 §7.21.6.1](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=333)
