# 107 · 输入 12 或 q，求和程序该读一个字符还是一整项？（选修）

把结束标记从数字 `0` 换成小写字母 `q`，就能让 0 也参与求和。先看输入规则。按键盘上的**每个数字字符**求和，`12` 应贡献 1 + 2。按**空白分隔的十进制整数**求和，`12` 应贡献 12。两条规则需要不同的读法。

## 为什么输入 q 后旧程序一直刷提示？

旧程序直接按整数读取。讲师依次输入 1 到 5，再输入 `q`，控制台就反复打印“请输入一个数字”。整数转换遇到 `q` 时返回 0，没有给 `number` 赋新值，`q` 也留在输入流中。源码没检查返回值，后续判断和加法仍使用旧值 5，下一轮又在同一个 `q` 处失败。要让一个输入既可表示数字又可表示命令，可以先按字符或字符串读走它，再决定用途。[Microsoft Learn《scanf 格式字段》](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/format-specification-fields-scanf-and-wscanf-functions?view=msvc-170)

## 每个数字字符单独相加

1. 声明 `char input;`，在循环中用 `scanf_s(" %c", &input, 1u)`。这里使用微软 C 运行库，最后的 `1u` 表示目标能容纳一个字符。格式串开头的空格会跳过空格、制表符和换行。录屏最初用 `"%c"`，键入 `1` 再按回车，下一轮把换行当成了无效字符。[Microsoft Learn《scanf_s》](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/scanf-s-scanf-s-l-wscanf-s-wscanf-s-l?view=msvc-170)
2. 读取成功（返回 1）后，若 `input == 'q'` 就 `break`。若 `input >= '0' && input <= '9'`，执行 `sum += input - '0';`。数字字符的编码连续，所以在 ASCII 中，`'1' - '0'` 算的是 49 − 48，得到 1。其他字符提示无效。
3. 讲师实测直接输入 `q` 得到 0，逐个输入 `1、2、3、4、5、q` 得到 15。连续键入 `12` 再回车时，画面出现两轮提示。按这段代码，两轮分别加 1、加 2。若要求只有**单独一项** `q` 才能退出，这种读法也区分不了 `q` 和 `q1` 的开头。

## 把多位整数和退出命令读成完整的一项

录屏改用 `char input[50]` 和 `%49s`。`49` 限制一次最多读入的字符数，数组余下的一格存字符串结束符 `'\0'`。读到 `input[0] == 'q' && input[1] == '\0'` 才结算。`0`、`q1` 和大写 `Q` 都不会触发这个分支。超过 49 个字符的连续输入会留下尾部，单靠字段宽度不能拒绝整项。[Microsoft Learn《scanf 宽度规范》](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/scanf-width-specification?view=msvc-170)

| 检查什么 | 怎样判断 |
| --- | --- |
| 整项能否转成十进制整数 | `strtol(input, &end, 10)` 将 `end` 指向第一个没被转换的字符。`end == input` 表示一个数字都没读到，例如 `abc`。`*end != '\0'` 表示后面还有内容，例如 `12x`。两种输入都应整项拒绝。[转换规则](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/strtol-wcstol-strtol-l-wcstol-l?view=msvc-170) |
| 转换函数能否装下这个值 | 转换前将 `errno` 清零，转换后检查 `errno == ERANGE`。在录屏的 Windows/MSVC 环境里，`long` 最大为 2147483647。第一次输入过大的数时，程序漏查 `ERANGE`，把返回的 2147483647 加到已有的 15 上，打印出 **2147483662**。后来把接收变量换成 `uint64_t`，调用的仍是 `strtol`，所以连合法的 `uint32_t` 值 2147483648 也读不进来。[微软整数范围](https://learn.microsoft.com/zh-cn/cpp/c-language/cpp-integer-limits?view=msvc-170) |
| 本项以及总和是否还在业务范围内 | 本题接受 0 到 4294967295。保留有符号的转换结果，先检查上下限，再转成 `uint32_t`。录屏末版的 `number` 是无符号数，`number < 0` 恒为假。加法前还需检查 `本项 > UINT32_MAX - sum`，否则即使每一项都合法，总和仍可能回绕到小数值。 |

录屏中，输入 `123、335123、5311、q` 得到 **340557**。加上范围检查后，讲师混入两个过大的数，两次收到范围提示，剩下的 321321、54352435 和 1312 相加得 **54675068**。

**整理者复习程序。** 在 Visual Studio 的 C 控制台项目中，将下面的代码放进含 `main` 的 `.c` 文件，选择“调试”→“开始执行（不调试）”（`Ctrl+F5`）。它沿用录屏的 50 字节数组，读取时传入首元素地址 `input`（录屏写成了 `&input`），并用 `strtoll` 的有符号 `long long` 接住完整的 32 位无符号数值范围。[Microsoft Learn《strtoll》](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/strtoll-strtoll-l-wcstoll-wcstoll-l?view=msvc-170)

```c
#include <ctype.h>
#include <errno.h>
#include <inttypes.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char input[50];
    uint32_t sum = 0;
    puts("逐项输入非负整数，输入小写 q 结算。");
    while (1) {
        if (scanf_s("%49s", input, (unsigned)sizeof input) != 1) {
            fputs("读取结束，未收到 q。\n", stderr);
            return 1;
        }
        int next = getchar();
        if (next != EOF && !isspace(next)) {
            do {
                next = getchar();
            } while (next != EOF && !isspace(next));
            puts("这一项超过 49 个字符。");
            continue;
        }
        if (input[0] == 'q' && input[1] == '\0') {
            break;
        }

        char *end;
        errno = 0;
        long long n = strtoll(input, &end, 10);
        if (end == input || *end != '\0') {
            puts("无效输入。");
        } else if (errno == ERANGE || n < 0 || n > UINT32_MAX) {
            puts("本项超出 0 到 4294967295 的范围。");
        } else if ((uint32_t)n > UINT32_MAX - sum) {
            puts("加上这一项会使总和超出范围。");
        } else {
            sum += (uint32_t)n;
        }
    }
    printf("和 = %" PRIu32 "\n", sum);
    return 0;
}
```

**复核方法。** 每组重新运行一次。输入 `12 0 q` 应打印 12。输入 `12x q1 7 q` 应报两次无效，最后打印 7。输入 `4294967295 1 q` 应收下第一项，拒绝使总和越界的 1，最后仍打印 4294967295。
