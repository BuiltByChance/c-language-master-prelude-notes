# 129 · 什么时候用数组比给每个变量单独命名更合适？

若一批数据类型相同、含义相同，且需要按编号反复读写，就可以放进数组。`plant_1`、`plant_2` 是两个独立的名字，循环不能通过改变编号来拼出变量名。用一个数组名和下标，就能让循环变量决定本轮读哪个元素。各元素在内存中连续排列。[Microsoft 的 C 数组声明](https://learn.microsoft.com/zh-cn/cpp/c-language/array-declarations?view=msvc-170)

讲师在编辑器里给 `number_1`、`number_2` 等独立变量都赋 100，随后在《植物大战僵尸》界面圈出已选植物、可选植物和僵尸，分别作为三组对象，又用草坪的行、列解释格子位置。这是用游戏界面建模，录屏没有查看游戏源码。

整理者举例，`int plant_id[3] = {17, 5, 23};` 设有三个槽位，第一个的编号用 `plant_id[0]` 取，最后一个用 `plant_id[2]` 取。下标表示槽位，元素值表示植物编号。`plant_id[1] = 31;` 只替换第二个槽位的值。遍历时用 `i < 3`，下标 3 已超出范围。

讲师把槽位比作快递柜。读取数组元素之后原值仍在，同一元素可以再读一次。固定长度数组建好后不能追加槽位。若只用了三个槽中的两个，要另外记录已用数量或空位。讲师用排队举例说明操作成本。保持顺序且要求队列紧密排列时，移走中间一人，后面的人要依次前移。已知下标且只替换该处的值，则无须移动后续元素。
