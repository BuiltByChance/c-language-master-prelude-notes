# 118 · 算阶乘时，累积值为什么必须从 1 开始？

正整数 N 的阶乘是从 1 到 N 的所有整数之积，记作 N!。开始时还没有乘任何因子，`factorial` 设为 1，乘入第一个数时才能保留它。若沿用求和练习的初值 0，后面无论乘什么都只会得到 0。

对 `N = 3`，循环在 `index` 等于 1、2、3 时依次执行 `factorial *= index;`，乘积依次为 1、2、6。随后 `index` 变成 4，`4 <= 3` 为假，才在循环外输出 `3! = 6`。录屏的控制台也显示了这项结果。“倒数开始”是沿用上一题的提示语，计数器在此处实际递增。

## 在控制台计算

将以下整理者复习代码放入 Visual Studio C 控制台项目的 `.c` 文件，按 `Ctrl+F5`。录屏用 `uint32_t` 存积，未限制输入。`12! = 479001600` 仍可表示，`13! = 6227020800` 超过 `UINT32_MAX` 的 `4294967295`，因此复习程序只接受 1～12。

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void)
{
    uint32_t number, factorial = 1;
    puts("请输入 1 到 12 的整数：");
    if (scanf_s("%" SCNu32, &number) != 1 || number < 1 || number > 12) {
        puts("输入超出本题范围或不是整数。");
        return 1;
    }
    for (uint32_t index = 1; index <= number; index++) {
        factorial *= index;
    }
    printf("%" PRIu32 "! = %" PRIu32 "\n", number, factorial);
    return 0;
}
```
