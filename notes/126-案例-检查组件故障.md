# 126 · 怎样用一个循环逐项报告组件故障？

示例系统有五个组件。`for` 的下标从 0 到 4，实际显示和传给检查函数的编号都是 `i + 1`，即 1 到 5。函数返回 `true` 就报告良好，返回 `false` 就报告故障；两个分支报告完都继续检查下一个组件。

下面是整理者按录屏改写的可运行例子。

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

static bool check_component_health(unsigned component_id)
{
    (void)component_id;  /* 模拟结果只取决于随机数 */
    return rand() % 10 >= 2;
}

int main(void)
{
    const unsigned total_components = 5;
    srand((unsigned)time(NULL));
    for (unsigned i = 0; i < total_components; ++i) {
        unsigned id = i + 1;
        if (check_component_health(id))
            printf("组件 %u 状态良好。\n", id);
        else
            printf("组件 %u 出现故障。\n", id);
    }
    puts("健康检查已完成!");
    return 0;
}
```

`rand() % 10` 的余数为 0～9，其中 0、1 被判故障，所以每次检查的模拟故障率约为 20%。五个组件可能全都良好，也可能多个报错。录屏直接把 `time(NULL)` 交给 `srand`，编译器给出 C4244 警告，因为 `time_t` 转为 `unsigned int` 可能缩窄。示例显式转换作为种子，在循环外只做一次。若要在同一实现上重复某次测试，可把时间换为固定种子。[Microsoft 的 srand 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/srand?view=msvc-170)

运行后应有编号 1～5 的五行结果，最后一行是“健康检查已完成!”。录屏先遇到报告挤在一起，给结果加 `\n` 后能分行读出，数次运行分别报过 5、4、3 号故障，也出现过全部良好。出现模拟故障时仍以 0 退出，因为 `main` 固定返回 0。若接入真实组件，应在检查函数里用 `component_id` 查询对应组件状态；网络请求、告警与修复都是讲师举的用途，演示只生成了模拟报告。
