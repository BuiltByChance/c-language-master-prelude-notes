# 057 · 怎样验证终端清屏、光标定位和字符串转义？

## 用看得见的字符验证清屏和定位

在 C 字符串里，`\033` 是八进制转义，产生一个 ESC 字符（十六进制 `1B`）。`printf("\033[2J");` 把 ESC 和后面的 `[2J` 送到终端。支持该指令的终端会擦除当前可见区域，光标仍在原位。若还要从左上角开始写，接着输出 `\033[H`。课堂先连续打印 `A` 再清屏，运行结束后只见 Visual Studio 的退出提示。注释掉清屏语句再运行，`A` 就保留下来。[C 字符串中的 ESC](https://learn.microsoft.com/zh-cn/cpp/c-language/escape-sequences?view=msvc-170) · [微软终端的清屏和定位指令](https://learn.microsoft.com/zh-cn/windows/console/console-virtual-terminal-sequences#text-modification)

`printf("\033[%d;%dH", 行, 列);` 将下一次输出的位置移到指定单元格。左上角是第 1 行第 1 列。课堂两个参数都是 `3`，第三行开头留下两个 `A`，Windows 的暂停提示从第三格写入。**要验证行、列顺序，用两个不同的数。** 在 Visual Studio 控制台项目的 `.c` 文件中运行下面的整理者示例（Ctrl+F5）。

```c
#include <stdio.h>

int main(void)
{
    printf("\033[2J\033[H");
    printf("AAAAA\nAAAAA\nAAAAA");
    printf("\033[%d;%dHX", 2, 3);
    printf("\033[4;1H");
    return 0;
}
```

`H` 结束定位指令，随后的 `X` 是要写入的字符。整理者在启用虚拟终端处理的 Windows 控制台运行示例，读回的三行依次是 `AAAAA`、`AAXAA`、`AAAAA`，只有第 2 行第 3 个 `A` 被覆盖。最后一条指令把光标移到第 4 行第 1 列，退出提示就不会盖住这三行。

若窗口直接显示 `[3;3H`，说明这次输出没有被解释为定位指令。课堂双击 `x64\Release` 下的程序时就出现了这个结果。Windows 控制台主机的输出模式需要启用 `ENABLE_VIRTUAL_TERMINAL_PROCESSING` 才会解释这些指令。课堂没有读取两个窗口的模式值，无法由此归因于 Debug 或 Release。[微软虚拟终端输出模式与坐标规则](https://learn.microsoft.com/zh-cn/windows/console/console-virtual-terminal-sequences#cursor-positioning)

课堂用 `system("pause");` 暂停以便观察。`system` 在 `<stdlib.h>` 中声明，`"pause"` 是交给 Windows 命令解释器的字符串。课堂漏写引号时，编译器把 `pause` 当成标识符，报 `C2065`（未声明）。[微软 C 运行库的 system 说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/system-wsystem?view=msvc-170)

## 从预期输出反推字符串写法

| 想得到的结果 | 写在 `main` 里的语句 | 运行时观察什么 |
| --- | --- | --- |
| 输出三行，缩进逐行增加 | `printf("第一行\n\t第二行\n\t\t第三行");` | `\n` 换行。第二行从下一水平制表位开始，第三行再向右一个制表位。`\t` 的宽度取决于制表位设置。 |
| 在一句话里显示英文双引号 | `printf("她说：\"你好\"");` | 屏幕显示 `她说："你好"`。两处 `\"` 各输出一个引号，字符串最外层的引号只用于界定内容。 |
| 打印 Windows 路径 | `printf("C:\\Users\\frank\\Documents\\GTA5.exe");` | 显示 `C:\Users\frank\Documents\GTA5.exe`。每对 `\\` 输出一个路径分隔符。这条语句只打印路径。 |
| 请求终端提醒 | `printf("\a");` | 课堂录音能听到短提示音。Windows Terminal 的 `bellStyle` 可以设为声音、视觉提醒或关闭，因此静音本身不足以判断语句是否执行。 |

表中缩进和引语用词为整理者简例，路径沿用课堂输入。[C 转义序列](https://learn.microsoft.com/zh-cn/cpp/c-language/escape-sequences?view=msvc-170) · [Windows Terminal 提醒设置](https://learn.microsoft.com/zh-cn/windows/terminal/customize-settings/profile-advanced#bell-notification-style)
