# 122 · 两层循环怎样把星号排成正方形？

边长为 `size` 的字符方阵有 `size` 行，每行 `size` 颗星。外层计数器 `i` 每增加一次就换到下一行。内层计数器 `j` 每增加一次就在当前行多打印一颗星。两个计数器都从 0 开始，条件应写 `< size`，否则边长 5 会被画成 6。

在 Visual Studio 的 C 控制台项目中，把以下复习代码放到 `.c` 文件里，按 `Ctrl+F5`，输入一个小的正整数作为边长。内层的 `printf("* ")` 带一个空格，方便在控制台分辨相邻的星号。

```c
#include <stdio.h>

int main(void)
{
    int size;
    puts("请输入图案边长：");
    if (scanf_s("%d", &size) != 1 || size < 1) {
        return 1;
    }
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            printf("* ");
        }
        putchar('\n');
    }
    return 0;
}
```

**从第一行走到第二行。** 输入 `5` 时，`i = 0`，内层的 `j` 依次取 0、1、2、3、4。到 `j = 5` 时内层结束，执行一次换行，然后 `i` 才增加到 1。再次进入内层时会重新执行 `int j = 0`，所以第二行也从第一颗星画起。

录屏实际得到 5 行、每行 5 颗星，共 25 颗，退出码为 0。若每颗星独占一行，检查换行是否误写在内层。若 25 颗星挤在同一行，检查换行是否误写在两层循环之外。录屏用 `uint32_t` 计数，复习代码改用 `int`，并检查读入成功且边长为正。
