# 039 · 隐式与显式类型转换：int 存进 short，什么时候会变值

`short small = count;` 用 `int` 变量 `count` 的值初始化 `small`。左侧声明了 `short`，C 会自动把右侧的值转换成这个类型，这叫**隐式转换**。写成 `short small = (short)count;`，就把目标类型写在了表达式里，这叫**显式转换**。两种写法遵循同一套数值规则，`count` 自身保持原值。`(short)` 不会检查范围。[C 标准的整数转换规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf#page=60)

## 先看目标类型，再看当前值

下表是课堂用 Visual Studio 的 `Debug ARM64` 配置实际运行**隐式转换**的结果。这里的 `short` 是有符号的，范围为 −32768～32767。打印 `small` 用 `%d` 即可，有符号 `short` 传给 `printf` 时会提升为 `int`。[微软整型范围](https://learn.microsoft.com/zh-cn/cpp/c-language/cpp-integer-limits?view=msvc-170)

| 赋给 `small` 的 `count` | 控制台打印的 `small` | 如何读结果 |
| ---: | ---: | --- |
| 25、260、32767 | 分别为 25、260、32767 | 当前值在目标范围内，包含上限本身。 |
| 32768 | −32768 | 超过上限 1。在该实现里保留低 16 位，位模式 `0x8000` 表示 −32768。 |
| 255555、25666666 | 分别为 −6589、−23446 | 新值已无法还原原数。第二次同时打印了 `count=25666666`，证明源变量仍保存原值。 |

## 超范围时适用哪条规则

- **转成有符号整数。** C 标准规定，目标类型放不下时，结果由实现定义，或产生实现定义的信号。表中的负数是这次 MSVC 的结果，其他平台要查相应实现。[C 标准 §6.3.1.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf#page=60) · [微软整数转换规则](https://learn.microsoft.com/zh-cn/cpp/c-language/conversions-from-signed-integral-types?view=msvc-170)
- **转成无符号整数。** 整数转成 `uint8_t` 时按模 256 取值，因此 `(uint8_t)260` 得到 `4`。这是针对讲师假设的补充计算。课堂的接收变量始终是有符号 `short`，足以容纳 `260`。[C 标准 §6.3.1.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf#page=60)
- **有符号加法溢出。** 把已经能用 `int` 表示的 `32768` 转成 `short`，与先计算 `INT_MAX + 1` 是两件事。后者的加法结果超出 `int` 范围，行为未定义，事后再强转也无济于事。[C 标准的表达式求值规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=94)

## 必须保留原数时，在转换前检查

下面是整理者补充的复习程序。`<limits.h>` 给出当前实现的 `SHRT_MIN` 和 `SHRT_MAX`，检查对象要用还没缩窄的 `count`。

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    int count = 25;
    printf("count=%d\n", count);
    if (count < SHRT_MIN || count > SHRT_MAX) {
        puts("out of short range");
        return 1;
    }

    short small = (short)count;
    printf("small=%d\n", small);
    return 0;
}
```

在 Visual Studio 的 C 控制台项目里按 **Ctrl+F5**。初值为 `25` 时应看到 `count=25` 和 `small=25`。在课堂的 MSVC 范围下，把初值改为 `32768` 再运行，应看到 `count=32768` 和 `out of short range`，程序会在写入 `small` 前退出。
