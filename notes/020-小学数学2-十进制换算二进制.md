# 020 · 小学数学 2：十进制换算二进制与二进制加法

## 十进制整数怎样换成二进制

把正整数除以 2。因为 `原数 = 2 × 商 + 余数`，余数 0 或 1 就是最右一位。继续用整数商除以 2，每次的余数都填在前一位的左边。商变为 0 时，记下这次的余数就结束。起始数为 0 时直接写 `0₂`。[马尔堡大学数制讲义](https://www.mathematik.uni-marburg.de/~thormae/lectures/ti1/ti_2_1_eng_web.html)

| 课堂题 18 | 第一次 | 第二次 | 第三次 | 第四次 | 第五次 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 被除数 | 18 | 9 | 4 | 2 | 1 |
| 整数商 | 9 | 4 | 2 | 1 | 0 |
| 余数 | 0 | 1 | 0 | 0 | 1 |

字幕里连读的 `01001` 是余数的取得顺序。把表中余数从右往左读，就得到板书的 `10010₂`。从最低位起，五个位权依次为 1、2、4、8、16，两个 1 的位权相加正好是 `16 + 2 = 18`。

**速算（整理者补充）**　当 n 为正整数时，`2ⁿ` 在二进制中是 1 后跟 n 个 0，减 1 就得到连续 n 个 1。课堂题 127 等于 `2⁷ − 1`，所以写作 `1111111₂`。

## 二进制整数怎样相加

把两个数的最右位对齐，从右向左逐列加。每列都把上下两位和右边传来的进位相加，缺位和初始进位按 0 算。和为 0 或 1 就直接写下，和为 2 就写 0 进 1，和为 3 就写 1 进 1。最左列若还有进位，就在左边再写一个 1。[威斯康星大学麦迪逊分校加法讲义](https://pages.cs.wisc.edu/~dusseau/Classes/CS202-F11/Lectures/lecture-add.pdf#page=4)

```text
   1011
 + 1101
 ------
  11000
```

课堂竖式从右数，前三列依次算 `1+1`、`1+0+1`、`0+1+1`，每列都得 2，写 0 进 1。第四列 `1+1+1=3`，本列写 1，进位再占一位，结果是 `11000₂`。
