# 078 · 复合赋值怎样写回结果，左侧求值一次有什么用？

`a += b` 用 `a` 原来的值与 `b` 相加，再把结果写回 `a`。对普通 `int` 变量，这和 `a = a + b` 得到相同的值。左边也可以是数组元素或结构体成员，只要它能被修改，而且两边的类型支持相应的运算。[C11 草案 §6.5.16–6.5.16.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120)

## 用同一个数走完十步

课堂把 `base_number` 设为 `8`，后面的每一步都用上一步写回的值。讲师把输出留作练习。下面将右侧变量换成课堂给定的数值，注释是整理者用 C 程序逐行打印的结果。

```c
int base_number = 8;
base_number += 2;     // 10
base_number -= 3;     // 7
base_number *= 4;     // 28
base_number /= 2;     // 14
base_number %= 5;     // 4，14 除以 5 的余数
base_number <<= 1;    // 8
base_number >>= 2;    // 2
base_number &= 0x0A;  // 2，0010 & 1010 = 0010
base_number |= 0x05;  // 7，0010 | 0101 = 0111
base_number ^= 0x0F;  // 8，0111 ^ 1111 = 1000
```

要自己核对，把代码放进 `main`，包含 `<stdio.h>`，在想检查的语句后加 `printf("%d\n", base_number);`。只看最后的 `8` 无法验证中间步骤，因为初值也是 `8`。

## 左侧只求值一次

当目标需要用下标找出时，复合赋值只计算一次下标表达式。整理者用这个例子核对了写入的位置和下标的最终值。

```c
int values[] = {8, 20};
int i = 0;
values[i++] += 2;
```

`i++` 用旧值 `0` 选中 `values[0]`，并把 `i` 增加一次。执行后数组是 `{10, 20}`，`i` 是 `1`。手工展开时若想保留行为，应先把 `i++` 的结果存为下标，再用这个下标读写同一个元素。[C11 草案 §6.5.16.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=121)

## 哪些类型能用

- `+=`、`-=`、`*=`、`/=` 可以用于整数和浮点数。`%=`、`<<=`、`>>=`、`&=`、`|=`、`^=` 要求两边都是整数。
- `+=`、`-=` 还允许左侧是指向完整对象类型的指针，右侧是整数。例如 `int *p = values; p += 1;` 会让 `p` 指向上例的 `values[1]`。[微软《C 复合赋值》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-compound-assignment?view=msvc-170)

课堂末尾在 `.c` 文件里草写了 `void update(BigStruct& bs)`、`bs = bs + temp;` 和 `bs += temp;`，随后删掉了这段。`BigStruct&` 是 C++ 引用语法。标准 C 允许相容的结构体整体赋值，但没有给整个结构体定义加法。要累加一个数值成员，可以写 `item.count += delta;`。讲师把“原地修改”与少复制联系起来。对普通整数，两种写法都能改回同一变量，C 标准并未规定哪种更快，课堂也没有测量。[C11 草案 §6.5.16.1–2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120)
