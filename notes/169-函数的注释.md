# 169 · 怎样写一段调用者拿来就能用的函数注释？

把注释放在调用者会查看的函数声明或定义之前。先用一句话说明函数完成什么，再写参数的实际含义、允许的输入和返回值。遇到会改变调用方式的条件，写出条件与后果。例如课中 `add_two_numbers` 直接返回 `num1 + num2`，签名使用 `int32_t` 能说明位宽，却没有提供超出范围时的处理。

以下是整理者依据课堂接口改写的 Doxygen 注释：

```c
#include <stdint.h>

/**
 * @brief 求两个 32 位有符号整数之和。
 * @param num1 第一个加数。
 * @param num2 第二个加数。
 * @pre 两数的数学和必须落在 INT32_MIN 到 INT32_MAX 之间。
 * @return 两数之和。函数不提供溢出错误码。
 */
int32_t add_two_numbers(int32_t num1, int32_t num2)
{
    return num1 + num2;
}
```

普通文本可以使用录屏中的 `Parameters`、`Returns`、`Notes` 小标题。若项目用 Doxygen 生成接口文档，则用工具认识的命令，`@param` 后的名字与签名逐个对应，`@return` 后写成功或失败时实际返回的值。讲师口头说 *return*，末帧打成了 `@retrun`；正确拼法是 **`@return`**。普通 C 块注释由 `/*` 和 `*/` 定界；文档块常以 `/**` 开头，中间各行的装饰性星号和对齐空格可以省略。[Doxygen 文档块](https://www.doxygen.nl/manual/docblocks.html) · [参数命令](https://www.doxygen.nl/manual/commands.html#cmdparam) · [返回值命令](https://www.doxygen.nl/manual/commands.html#cmdreturn)
