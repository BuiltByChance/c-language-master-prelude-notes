# 124 · 数字金字塔怎样居中，又怎样避免重复打印峰值？

设总层数为 `levels`，行号 `i` 从 1 开始。每一行按以下顺序输出，三个小循环都在同一个行循环里，依次执行。

| 行内部分 | 第 `i` 行的规则 | 5 层金字塔的第 3 行 |
| --- | --- | --- |
| 左侧缩进 | 打印 `levels - i` 个空白单元 | 2 个空白单元 |
| 左半和正中 | 依次打印 1 到 `i` | `1 2 3` |
| 右半 | 从 `i - 1` 倒数到 1，最后换行 | `2 1` |

右半若也从 `i` 开始，中间的 `3` 会出现两次。第一行的右半从 0 开始，条件 `j >= 1` 一开始就为假，因此塔尖只有一个 `1`。三个内层 `for` 都可用变量名 `j`，各自在自己的循环头重新声明并初始化。

## 对齐要按字符列计算

在等宽控制台里，紧凑版的 `12321` 每个数字占一列，每个缩进单元也应是一格空格。若每个数字后加一个空格，`1 2 3 2 1` 就是两列一个单元，缩进也要改成每单元两个空格。录屏第一次拼合三部分时还混入了测试用的行号。讲师注释掉循环开头的行号输出，再统一缩进和数字的单元宽度，才显示出居中的五层金字塔。

在 Visual Studio 的 C 控制台项目中，将下列代码放入 `.c` 文件，按 `Ctrl+F5`。整理者将层数限于 1～9，使所有数字始终只占一列。输入 `5`，塔尖前应有 8 个空格，底行没有前导空格，峰值 `5` 只出现一次。

```c
#include <stdio.h>

int main(void)
{
    int levels;
    puts("请输入层数（1 到 9）：");
    if (scanf_s("%d", &levels) != 1 || levels < 1 || levels > 9) {
        return 1;
    }
    for (int i = 1; i <= levels; i++) {
        int spaces = levels - i;
        for (int j = 0; j < spaces; j++) {
            printf("  ");
        }
        for (int j = 1; j <= i; j++) {
            printf("%d ", j);
        }
        for (int j = i - 1; j >= 1; j--) {
            printf("%d ", j);
        }
        putchar('\n');
    }
    return 0;
}
```

`spaces` 每行计算一次，因为同一行中 `levels` 和 `i` 都不变。保存这个值后，输出空格的循环仍需执行 `spaces` 次。讲师还提出先拼好一行再输出，以减少 `printf` 调用。录屏停在提取 `spaces` 后的源码，没有再运行这次改动，也没有实现字符串拼接或计时。
