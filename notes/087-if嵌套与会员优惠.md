# 087 · 嵌套 if 怎样判断会员优惠？同样买 90 元，为什么减免不同？

课堂用外层 `if` 判断会员身份，由身份决定接下来比较哪个金额门槛。同样买 90 元，会员走的是“不超过 100 元”这一档，减免 5%。非会员走的是“超过 50 元”这一档，反而减免 10%。

| 身份 | 该身份下的金额条件 | 课堂实际运行（总额 → 控制台显示的减免比例） |
| --- | --- | --- |
| 会员 | 超过 100 元 | 120 元 → `20.00%` |
| 会员 | 不超过 100 元 | 90 元 → `5.00%` |
| 非会员 | 超过 50 元 | 90 元 → `10.00%` |
| 非会员 | 不超过 50 元 | 40 元 → `0.00%` |

## 用大括号分清两层判断

下面按课堂逻辑整理成可运行的 C 程序。把代码保存为 `.c` 文件，每次改动 `is_vip` 和 `cart_total` 的初值后重新编译运行，用上表核对输出。

```c
#include <stdbool.h>
#include <stdio.h>

int main(void) {
    bool is_vip = true;
    double cart_total = 120;
    double discount_rate = 0.0;

    if (is_vip) {
        if (cart_total > 100) {
            discount_rate = 0.20;
        } else {
            discount_rate = 0.05;
        }
    } else if (cart_total > 50) {
        discount_rate = 0.10;
    } else {
        discount_rate = 0.0;
    }

    printf("您的折扣为:%.2f%%\n", discount_rate * 100);
    return 0;
}
```

讲师暂时删去测试值时，Visual Studio 在 `if (is_vip)` 上提示 `C6001`，指出 `is_vip` 尚未初始化。用固定值练习时，应在进入判断前给身份和金额都赋值。

`is_vip` 是布尔值，`if (is_vip)` 就能判断它是否为真。第一个 `else` 在会员代码块内，只处理会员金额不超过 100 元的情况。退出会员代码块后才出现外层的 `else if`，所以只有非会员才会检查 `cart_total > 50`。整理者把外层的 `else if` 改为独立的 `if (cart_total > 50)` 后，会员买 120 元也会命中第二次判断，先前算出的 20% 被覆盖成了 10%。[Microsoft Learn · C 的 if 语句与 else 配对](https://learn.microsoft.com/zh-cn/cpp/c-language/if-statement-c?view=msvc-170)

`discount_rate` 存的是减免比例。乘 100 后，`%.2f` 显示两位小数，`%%` 输出一个百分号。以会员买 90 元为例，`5.00%` 表示减 4.50 元，应付 85.50 元。课堂程序只打印比例。[Microsoft Learn · printf 格式说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions?view=msvc-170)

整理者另测了两个严格大于号的边界。会员买 100 元显示 `5.00%`，买 100.01 元显示 `20.00%`。非会员买 50 元显示 `0.00%`，买 50.01 元显示 `10.00%`。把 50 元这组改成会员，结果是 `5.00%`，可见“不超过 50 元没有优惠”只适用于非会员。
