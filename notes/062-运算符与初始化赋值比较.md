# 062 · 读到等号时，怎样分清初始化、赋值和比较？

## 同一个变量，三种读法

- `uint32_t number = 123;` 定义 `number`，并把它**初始化**为 123。课堂手写的是 `uint32`，在提供 32 位无符号定宽类型的 C 环境中，标准写法是包含 `<stdint.h>` 后使用 `uint32_t`。[C 的初始化规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=158) · [定宽类型名](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=308)
- `number = number + 1;` 给已有的 `number` **赋值**。先读取旧值，加 1，再把结果写回。如果原值是 123，执行后就是 124。整行是表达式语句，分号结束这条语句。[C 的赋值规则](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=119)
- `number == 124` **比较**当前值和 124 是否相等。结果是 `int` 类型的 `1`（相等）或 `0`（不等），这次比较不会改写 `number`。[C 的相等运算符](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=114)

**整理者验证。** 先比较一次，把结果保存在 `equal_before` 中，再更新 `number` 并比较第二次。

```c
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint32_t number = 123;
    int equal_before = (number == 124);

    number = number + 1;
    printf("%d %d\n", equal_before, number == 124);
    return 0;
}
```

实测输出 `0 1`。若把条件 `if (number == 124)` 错写为 `if (number = 124)`，程序会把 124 写入 `number`，然后用这个非零值判断条件，因此无论原值是多少都会进入真分支。

## 按表达式要回答的问题选符号

| 要做什么 | 符号 | 整理者示例 |
| --- | --- | --- |
| 求数值或整数余数 | `+ - * / %` | `7 / 2` 得 `3`，`7 % 2` 得 `1`。`%` 两边必须是整数，除数不能为零。 |
| 比大小或判相等 | `< <= > >=` 和 `== !=` | `number >= 124` 包含恰好等于 124 的情况。`number != 124` 在值为 124 时为假。 |
| 取反或组合条件 | `!`、`&&`、<code>&#124;&#124;</code> | `number >= 100 && number < 125` 要求两个条件同时成立。<code>&#124;&#124;</code> 只需一边成立，`!` 将条件的真假颠倒。 |

课堂把算术、比较、逻辑和赋值作为四个入门类别。查 C 标准时，大小比较列在“关系运算符”，`==`、`!=` 另列在“相等运算符”。移位、按位运算等也有各自的条目。[整数除法与余数](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=110) · [关系与相等运算符](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=113) · [逻辑与、逻辑或](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=117)
