# 184 · 查找一个值时，怎样把“找到没有”和“下标是多少”同时交给调用者？

在 `{10, 20, 30, 40, 50}` 里找 30，要依次比较下标 0、1、2，命中时得到 **2**。下标从 0 起，因而 0 本身可能是正确答案。课堂用 `bool` 表示查找是否成功，用单独的 `size_t` 保存下标，调用者只在成功时读取它。

第一版在 `main` 中逐项比较 `*(start_ptr + i)` 与目标值，命中后保存元素地址、记录 `i`、置 `found = true` 并 `break`。下列函数版把查找与打印分开。调用者传入首元素指针、确切项数、目标值，以及一个可写的 `size_t` 对象的地址。用 `const` 表明函数只读数组，通过 `*index = i` 把结果写回调用者。循环从头开始且首次命中便返回，所以重复值取最早出现的下标。

```c
#include <inttypes.h>
#include <stdbool.h>
#include <stdio.h>

static bool find_index_of_value(const int32_t *array, size_t count,
                                int32_t target, size_t *index)
{
    for (size_t i = 0; i < count; ++i) {
        if (*(array + i) == target) {
            *index = i;
            return true;
        }
    }
    return false;
}

int main(void)
{
    int32_t values[] = {10, 20, 30, 40, 50};
    size_t count = sizeof values / sizeof values[0];
    int32_t target = 30;
    size_t index;
    if (find_index_of_value(values, count, target, &index))
        printf("%" PRId32 " -> %zu\n", target, index);
    else
        puts("not found");
    return 0;
}
```

**核对结果。** 录屏中内联版和函数版都显示 30 的下标是 2。未找到分支中，讲师修正了 `printf` 格式与实参数量，现场没有改为不存在的目标来运行它。整理者用同一函数另测：找 10 得下标 0，找 35 返回 `false`，此时函数没有写入下标。
