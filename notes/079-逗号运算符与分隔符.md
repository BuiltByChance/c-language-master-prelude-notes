# 079 · 逗号表达式取哪个值，怎样认出分隔符？

在逗号表达式 `(左式, 右式)` 中，先算左式，等它对变量的修改完成后再算右式。整个表达式取右式的类型和值。多个逗号连用时，从左到右逐项执行，只有最右一项的值作为整体结果。[C11 草案 §6.5.17](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=123)

## 三个变量都变了，为什么 result 等于 4？

```c
#include <inttypes.h>
#include <stdio.h>

int main(void) {
    uint32_t a = 1, b = 1, c = 1;
    uint32_t result = (a += 1, b += 2, c += 3);

    printf("a = %" PRIu32 ", b = %" PRIu32 ", c = %" PRIu32
           ", result = %" PRIu32 "\n", a, b, c, result);
    return 0;
}
```

课堂控制台输出 `a = 2, b = 3, c = 4, result = 4`。前两项分别把 `a` 改为 `2`、`b` 改为 `3`。最后的 `c += 3` 把 `c` 从 `1` 改为 `4`，这项表达式的值也是 `4`，因此 `result` 得 `4`。录屏用四个 `%d` 打印。上面的复现代码保留 `uint32_t`，用 `<inttypes.h>` 的 `PRIu32` 匹配其无符号十进制格式。[C11 草案 §7.8.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=235)

括号决定哪个值写入 `result`。整理者把三个变量重置为 `1`，先单独声明 `uint32_t result;`，再写 `result = (a += 1), (b += 2), (c += 3);`。由于赋值比逗号结合得紧，`result` 先得到 `2`，随后 `b`、`c` 照常变为 `3`、`4`。要保存最后一项的值，应像课堂代码那样用一对括号包住整串表达式。[微软 C 运算符优先级表](https://learn.microsoft.com/zh-cn/cpp/c-language/precedence-and-order-of-evaluation?view=msvc-170)

## for 循环头中两处逗号各做什么？

```c
for (int i = 0, j = 0; i < 10; i++, j++) {
}
```

- `int i = 0, j = 0` 是一条声明。逗号分隔两个变量，二者各自初始化为 `0`。前面 `printf` 调用中分隔实参的逗号也属于分隔符，它不规定实参从左往右求值。
- `i++, j++` 位于更新栏。这里的逗号是运算符，每轮循环体结束后先增加 `i`，再增加 `j`，然后重新判断 `i < 10`。更新栏用的是两个自增产生的效果，整个表达式的值会被丢弃。[C11 草案 §6.8.5.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=169)

讲师只在编辑器中展示了这个空循环，随后将它删除。按他的可读性建议，循环更新栏适合并列相关操作。普通代码若只需要按顺序修改几个变量，拆成几条语句更容易逐项核对。
