# 120 · 判断素数为什么只试到平方根，还得包含等号？

若整数 `n > 1` 是合数，就能写成 `a × b`，其中 `2 ≤ a ≤ b`。于是 `a² ≤ a × b = n`，较小因子一定不超过 `√n`。例如 28 的因子对有 `(2, 14)` 和 `(4, 7)`，继续试 7 或 14 只会找到同一对的另一端。实际检验时遇到 2 就能停止，因为 `28 % 2 == 0` 已经证明它是合数。

从 2 开始逐个试除，候选数包含平方根本身。讲师最初在板书写“小于”，讲源码时纠正为“小于等于”。例如 49 的唯一非平凡因子对是 `(7, 7)`，只试到 6 就会误判。0 和 1 先判为非素数。2 不需要试除，直接保留素数结论。

## 把判断结果显示出来

录屏展示了 `bool is_prime` 和找到因子后执行的 `break`，循环后直接 `return 0;`，未运行或输出判定。讲师将 `i <= sqrt(num)` 改为 `i * i <= num`，并判断这样更快，现场没有计时。数学上这两个条件对正整数等价，但同为 32 位无符号整数时，`i` 等于 65536 时的平方在该类型中会回绕为 0。整理者在乘法**之前**把一个操作数转换成 `uint64_t`，并在循环后打印结果。[C11 委员会草案 §6.2.5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=58)

在 Visual Studio 的 C 控制台项目中，把代码放进 `.c` 文件，按 `Ctrl+F5`。每次输入一个能由 `uint32_t` 表示的十进制非负整数。

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>
#include <stdbool.h>

int main(void)
{
    uint32_t num;
    puts("请输入一个非负整数：");
    if (scanf_s("%" SCNu32, &num) != 1) {
        puts("未读到整数。");
        return 1;
    }
    bool is_prime = num >= 2;
    for (uint32_t i = 2; (uint64_t)i * i <= num; i++) {
        if (num % i == 0) {
            is_prime = false;
            break;
        }
    }
    puts(is_prime ? "是素数" : "不是素数");
    return 0;
}
```

复测 `1` 和 `2` 可检查下界，分别得到“不是素数”“是素数”。再试 `49` 与 `47`，前者在 `i = 7` 时被整除，后者直到超出平方根都没有找到因子。
