# 189 · 批量涨薪、计算奖金和查最高薪资，分别该返回什么？

课堂把五笔薪资 `3000 4000 3500 4500 3200` 各加 10000，控制台显示 `13000 14000 13500 14500 13200`。最高薪资是第四项 14500；只为这一项按 `salary / 10` 算奖金，显示 1450。除法按整数规则舍去余数。这里数组中存的是金额，程序没有员工姓名、工号等记录。

| 操作 | 需要读写的对象 | 合适的接口 |
| --- | --- | --- |
| 批量涨薪 | 修改调用者的整个薪资数组 | 传可写首元素指针、项数、增量，函数逐项加后返回 `void` |
| 计算某人的奖金 | 只用到一笔金额，产生一个新数 | 传 `uint32_t` 数值，返回计算出的 `uint32_t` |
| 找到最高薪资那一项 | 还要在调用者的数组里定位这一项 | 遍历比较金额，返回最高项的地址；调用者用 `*highest` 取金额 |

**为什么能返回函数里的指针？** 函数内的变量 `highest` 结束生命周期时，返回的是它所存地址的副本。该地址指向调用者仍然存活的数组元素。课堂用了 `return (uint32_t *)highest;` 去除只读限定，并把括号解释为“返回指针”的要求。括号实际属于强制类型转换；查找只需读取时，返回类型与形参都保留 `const`，即可直接写 `return highest;`。[WG14 C11 草案 §6.5.4](https://www.open-std.org/JTC1/SC22/WG14/www/docs/n1570.pdf#page=110)

**整理者复习版。** 课堂最后采用固定人数宏 `EMPLOYEES_COUNT`；这里把实际人数交给函数，空数组范围没有最高项，返回 `NULL`。已有最高项时只在严格大于它时更新，因此并列保留先出现者。涨幅和金额取课堂数值，均在 `uint32_t` 可表示范围内。

```c
#include <inttypes.h>
#include <stdio.h>

static void update_salary(uint32_t *salaries, size_t count, uint32_t increment)
{
    for (size_t i = 0; i < count; ++i)
        salaries[i] += increment;
}

static uint32_t calc_bonus(uint32_t salary)
{
    return salary / 10;
}

static const uint32_t *find_highest_salary(const uint32_t *salaries, size_t count)
{
    if (count == 0)
        return NULL;
    const uint32_t *highest = salaries;
    for (size_t i = 1; i < count; ++i) {
        if (salaries[i] > *highest)
            highest = &salaries[i];
    }
    return highest;
}

int main(void)
{
    uint32_t salaries[] = {3000, 4000, 3500, 4500, 3200};
    size_t count = sizeof salaries / sizeof salaries[0];
    update_salary(salaries, count, 10000);
    const uint32_t *highest = find_highest_salary(salaries, count);
    if (highest != NULL)
        printf("highest=%" PRIu32 ", bonus=%" PRIu32 "\n",
               *highest, calc_bonus(*highest));
    return 0;
}
```

复测输出 `highest=14500, bonus=1450`。
