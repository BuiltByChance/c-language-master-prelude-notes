# 058 · 怎样用 bool 表示游戏状态，一个布尔变量占多少空间？

## 用变量名说清真假回答的是哪个问题

课堂先用 `int` 的 `0`、`1` 约定输赢，再用两个布尔变量分别记录“游戏结束了吗”和“玩家赢了吗”。用 C99 到 C17 编译这两行时，先包含 `<stdbool.h>`。

```c
bool is_game_over = false;
bool is_game_won = true;
```

读 `is_game_over = false` 应得到“游戏尚未结束”。录屏早先在整数版旁写的“0 输了”，把“是否结束”和“是否获胜”混在了一起。若游戏规则规定结束时才结算，先看 `is_game_over`，只有它为真时才根据 `is_game_won` 判断输赢。课堂只写了两个初始化声明，没有实现胜负判定。

C99 引入 `_Bool`。在 C99 至 C17 中，`<stdbool.h>` 把 `bool` 定义为 `_Bool` 的宏，把 `true` 和 `false` 分别定义为整数常量 `1` 和 `0`。按 C23 编译时，这三个名字都是关键字，可以直接使用。录屏注释里的 `ture` 是笔误，实际声明写的是 `true`。[C99 草案 §7.16](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1256.pdf#page=265) · [C23 草案 §6.4.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3096.pdf#page=72)

## 用一次运行分清取值和占用空间

整数赋给 `bool` 时，零变成 `0`，任何非零整数都变成 `1`。因此 `-7` 和 `42` 存进去后再也区分不开。要保存分数就用整数，要记录“分数是否达标”才用布尔值。[C99 草案 §6.3.1.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1256.pdf#page=55)

课堂说“`bool` 只占一位”。一位足以区分两种值，但独立 `bool` 对象至少占一个 C 字节。下面是整理者的复测程序。第一行输出用 `%d` 查看布尔值（传给 `printf` 时提升为 `int`），第二行用 `%zu` 查看 `sizeof` 得到的字节数，用 `CHAR_BIT` 查看每字节有几位。[C99 草案 §6.5.3.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1256.pdf#page=92)

```c
#include <limits.h>
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool flags[8] = {0, -7, 42};
    printf("%d %d %d\n", flags[0], flags[1], flags[2]);
    printf("one=%zu, eight=%zu, CHAR_BIT=%d\n",
           sizeof flags[0], sizeof flags, CHAR_BIT);
    return 0;
}
```

在 Windows x64 的 TinyCC 0.9.27 上，第一行是 `0 1 1`，第二行是 `one=1, eight=8, CHAR_BIT=8`。这个实现中，一个元素占 1 字节，8 个布尔元素共占 8 字节。换编译器时，运行同一程序即可核对大小。
