# 025 · int 类型变量的表示范围：为什么上限要减一

两盏灯各有灭（0）、亮（1）两种状态，`00`、`01`、`10`、`11` 依次表示 0、1、2、3。**一共有 4 种状态，其中有 3 个正数，最大值是 3。** 同理，n 位无符号整数有 2ⁿ 种组合，从 0 数起，最大值就是 2ⁿ−1。

## 同样的 32 位，怎样读出两个范围

课堂查的是微软 C 编译器的范围表。`int` 和 `unsigned int` 都占 4 字节，每字节 8 位，区别在于最高位的权重。[微软数据类型范围表](https://learn.microsoft.com/zh-cn/cpp/cpp/data-type-ranges?view=msvc-170)

| 32 位整数类型 | 最高位为 1 时贡献的值 | 最小值 | 最大值 |
| --- | ---: | ---: | ---: |
| `int`（补码） | −2³¹ | −2,147,483,648 | 2³¹−1 = 2,147,483,647 |
| `unsigned int`（无符号） | +2³¹ | 0 | 2³²−1 = 4,294,967,295 |

**用位权推导（整理者补充）。** 低 31 位可以表示 0 到 2³¹−1。对 `int`，最高位为 0 时就读这个值，最高位为 1 时则从这个值减去 2³¹。这样，`100…000`（1 后跟 31 个 0）正好是 −2³¹，`111…111` 是 −1。负数一侧多出的值是 −2³¹，零只出现一次。对 `unsigned int`，32 位全为 1 时各位权相加，正好是 2³²−1。[C 标准委员会工作草案 §6.2.6.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf#page=56)

## 自己核对

- **算无符号上限。** 在 Windows 计算器 → 菜单 → 科学（Scientific）中，按 `2 → xʸ → 32 → =` 得 4,294,967,296，再按 `− 1 =` 得 4,294,967,295。
- **核对二进制。** 从同一菜单切到程序员（Programmer），选 `DEC` 输入十进制数，读 `BIN` 一栏。课堂中的 25 显示为 `0001 1001`，13 显示为 `1101`，后者可用位权验算为 `8 + 4 + 1 = 13`。[微软计算器说明](https://support.microsoft.com/en-us/windows/apps/use-the-calculator-in-windows)
- **换编译目标时查实际范围（整理者补充）。** 在 C 程序中包含 `<limits.h>` 后，`INT_MIN` 和 `INT_MAX` 分别给出 `int` 的下限和上限，`unsigned int` 的范围是 0 到 `UINT_MAX`。[微软 C 整数限制](https://learn.microsoft.com/zh-cn/cpp/c-language/cpp-integer-limits?view=msvc-170)
