# 071 · 怎样用条件运算符选择要输出的值？

`条件 ? 真分支 : 假分支` 先求条件的值。条件非零，只求问号和冒号之间的表达式。条件为零，只求冒号右边的表达式。`?:` 选出一个值，`printf` 决定怎样把它显示出来。[微软 C 条件表达式运算符](https://learn.microsoft.com/zh-cn/cpp/c-language/conditional-expression-operator?view=msvc-170)

## 从分数选出等级

```c
#include <stdio.h>

int main(void)
{
    int score = 99;
    printf("你的成绩等级: %s\n", score >= 90 ? "A" : "不及格");
    return 0;
}
```

课堂分别把 `score` 写成 `99` 和 `89` 运行，得到 `A` 和 `不及格`。整理者复测边界 `90` 得到 `A`，因为条件写的是 `>= 90`。这段代码只设置了两种输出，所有低于 90 的分数都取同一个标签。

分支也可以给出数值。例如 `int larger = a > b ? a : b;` 会把两个整数中较大的值存入 `larger`（整理者示例）。

## 输出由数字改成文字时，为什么只改一处会出错？

| 想显示什么 | `printf` 写法 | 实际传入的值 |
|---|---|---|
| 比较结果 `0` 或 `1` | `printf("%d", a > b);` | 比较表达式产生的 `int` |
| 单个字符 `A` | `printf("%c", 'A');` | 单引号字符常量 `'A'` |
| 单词 `true` 或 `false` | `printf("%s", a > b ? "true" : "false");` | 指向所选字符串首字符的指针。`%s` 打印到结尾的 `\0` 之前 |

课堂取 `a = 10`、`b = 20`，所以 `a <= b` 为真。第一次运行时，最后一行已选出 `"true"`，格式却保留了 `%d`，控制台显示 `a <= b: 82484316`。`%d` 需要 `int`，实际传入字符指针，两者不匹配会导致未定义行为。保留条件表达式，只把格式改成 `%s`，再次运行便显示 `a <= b: true`。[C17 草案 §7.21.6.1](https://teaching.csse.uwa.edu.au/units/CITS2002/resources/n2176.pdf#page=248)
