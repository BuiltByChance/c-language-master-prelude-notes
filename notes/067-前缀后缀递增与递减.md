# 067 · score++ 和 ++score，表达式各取哪个值？

如果只想把 `int` 变量 `score` 加一，单独写 `score++;` 或 `++score;` 都可以。如果还要把表达式的值交给另一个变量，需要旧分数就用后缀 `score++`，需要加一后的分数就用前缀 `++score`。

## 同一轮运行，从 10 到 12

下列代码中的注释是课堂控制台对应的三行输出。

```c
#include <stdio.h>

int main(void)
{
    int score = 10;
    int before = score++;
    printf("score = %d\n", score);                       // score = 11
    printf("before = %d, score = %d\n", before, score);  // before = 10, score = 11

    int after = ++score;
    printf("after = %d, score = %d\n", after, score);    // after = 12, score = 12
    return 0;
}
```

`before` 保存了递增前的 `10`。后面的 `++score` 接着从 `11` 加到 `12`，所以 `after` 是 `12`。讲师开头口算 `after` 为 `11`，因为他假设直接从 `10` 做前缀递增。

讲师用“第六行执行完才加一”帮助理解后缀。准确的规则是 `score++` 先取得旧值，更新 `score` 的副作用在下一个完整表达式开始前已经完成。本例紧接着的 `printf` 因此读到 `11`，即使把前面的声明拆成两行，结果也一样。[后缀运算 §6.5.2.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=103) · [完整表达式 §6.8](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=164)

## 递减时取哪个值？

课堂只运行了 `++`。整理者分别把 `score` 初始化为 `10` 验证了两种写法。`int before = score--;` 让 `before` 得到 `10`，`int after = --score;` 让 `after` 得到 `9`。两种写法执行后，`score` 都是 `9`。[后缀递减 §6.5.2.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=103) · [前缀递减 §6.5.3.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=106)
