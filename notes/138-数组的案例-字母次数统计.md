# 138 · 怎样用 26 个计数器统计文本里的英文字母？

一个数组存文本，另一个数组存各字母的累计次数。这两个数组用不同的条件遍历。读文本时遇到 `\0` 才结束，空格和句号只跳过计数。输出时则逐一检查 26 个计数器，只显示大于 0 的项。

下面是整理者按录屏改写的例子，适用于 ASCII 兼容编码的英文字母。

```c
#include <ctype.h>
#include <stdio.h>

int main(void)
{
    const char text[] = "Example text for frequency analysis.";
    unsigned frequency[26] = {0};

    for (size_t i = 0; text[i] != '\0'; ++i) {
        int ch = tolower((unsigned char)text[i]);
        if (ch >= 'a' && ch <= 'z') {
            ++frequency[ch - 'a'];
        }
    }
    for (int i = 0; i < 26; ++i) {
        if (frequency[i] > 0) printf("%c: %u\n", 'a' + i, frequency[i]);
    }
    return 0;
}
```

`char text[] = "…"` 让编译器按字符串字面量的长度再加一个结束符决定数组大小。`tolower` 返回当前字符的小写形式，不改变原文本。传参前转成 `unsigned char`，能将字节值放在该函数允许的范围内。[Microsoft 的 tolower 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/tolower-tolower-towlower-tolower-l-towlower-l?view=msvc-170)

`ch - 'a'` 把字母换成下标，例如 `E` 转为 `e` 后得到下标 4，每读到一次就给 `frequency[4]` 加 1。输出时用 `'a' + i` 反向换回字符。录屏实际输出 `a: 3`、`c: 1`、`e: 5`，没有出现的 `b` 和 `d` 不输出。“频率”在这个程序中指次数，代码没有除以总字母数求占比。
