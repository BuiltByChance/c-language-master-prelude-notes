# 007 · 基本术语形象单口相声第一节（理解即可）

## 从哪里开始读一个 C 程序

课堂的 `001.c` 里，`main` 定义局部变量 `int number = 123;`，然后调用 `printf("number = %d\n", number);`，最后 `return 0;`。读这段程序要分清三个时刻。

- **翻译源码时**，预处理指令 `#include <stdio.h>` 引入标准输入输出头文件，其中有 `printf` 的声明。编译器由此知道正在调用哪个函数、参数应怎样传。源码开头的另一条指令引入 `<stdlib.h>`，打印这个整数只用到了前一个头文件。
- **运行控制台程序时**，从 `main` 进入，依次初始化变量、调用 `printf`，最后执行 `return 0;`。这段代码预期打印一行 `number = 123`。
- **发生函数调用时**，先执行被调用的函数，正常返回后由调用处继续。门诊请放射科拍片，检查步骤由放射科完成，报告交回门诊。这里门诊是调用方，拍片是被调函数，报告对应返回值。门诊不必把拍片的每一步再写一遍。`return` 结束当前函数，有返回值时把它交回调用方。认函数调用也要看括号前的名字，`if (...)` 和 `while (...)` 是控制语句。[C11 委员会草案 §5.1.2.2.1、§6.5.2.2、§6.8.6.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

## 怎样判断接下来的执行路径

| 读代码时要找的东西 | 课堂例子 | 判断结果 |
| --- | --- | --- |
| 步骤的先后顺序 | 去彩票店、选号、付钱、取票、等开奖 | 在没有跳转或分支的这一段，做完一步才轮到下一步。 |
| `if` 的条件 | 中奖才领奖。不同的录取结果会改变去向 | 条件非零走 `if` 的分支，条件为零时走 `else`（若有）。 |
| `while` 的条件及其变化 | 没考上就继续备考，考上后停止 | 每轮开始前判断一次。课堂草稿 `while (985)` 中的常量始终非零。要表达“考上就停”，须检查会变化的录取状态，或在循环内明确退出。 |
| `switch` 的取值与出口 | 考研、考编、考教师资格证对应不同 `case` | 跳到匹配的 `case` 后往下执行。`break` 退出最近一层循环或 `switch`。`return` 直接结束整个当前函数。 |

讲师在记事本和编辑器里写的是示意草稿，例如备考状态和拍片报告都用占位内容代替。要把这些例子写成能运行的程序，须给出实际条件、对应动作和退出点。[C11 委员会草案 §6.8.4–6.8.6](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=166)

## 删掉头文件后，怎样读生成错误

讲师在 `Debug / x64` 下删掉两条 `#include`，保留 `printf` 调用，选 **Debug → Start Without Debugging**（**Ctrl+F5**）。这次生成 **0 个成功、1 个失败**。诊断按发生顺序读，就能知道先改什么。

1. **C4013** 出现在编译阶段。这次编译器在调用处看不到 `printf` 的声明，按返回 `int` 的外部函数暂时处理。先核对函数名与声明它的头文件。[微软对 C4013 的说明](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-warnings/compiler-warning-level-3-c4013?view=msvc-170)
2. **LNK2019** 出现在链接阶段，点名 `main` 引用的 `printf` 没有解析成功。**LNK1120** 只汇总尚未解析的符号数，本例为 1。[微软对 LNK2019 的说明](https://learn.microsoft.com/zh-cn/cpp/error-messages/tool-errors/linker-tools-error-lnk2019?view=msvc-170)
3. 讲师在“运行上次成功的版本”提示中选 **No**，恢复两条包含指令，悬停在 `printf` 上已经能看到函数签名。录像到此只验证了编辑器能看到声明。自己复现时，还要再次生成并查看控制台是否出现 `number = 123`。

用错误列表中的行号找源码时，Visual Studio 2022 可在 **工具 → 选项 → 文本编辑器 → 所有语言 → 常规 → 行号** 勾选显示（2026-11-19 核实）。课上行号原本已显示，讲师只打开了选项搜索框。[Visual Studio 行号设置](https://learn.microsoft.com/zh-cn/visualstudio/ide/reference/how-to-display-line-numbers-in-the-editor?view=vs-2022)
