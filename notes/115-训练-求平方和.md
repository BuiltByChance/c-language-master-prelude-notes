# 115 · 求 1 到 N 的平方和，循环里哪两个量要变？

`number` 保存只读一次的终点 N，`index` 从 1 走到 N，`sum_of_squares` 从 0 开始保存已经走过的各项之和。循环体写 `sum_of_squares += index * index;`。如果写成 `=`，每一轮都会覆盖前面的和，最后只剩 N²。

**用 N = 5 走一遍。** `index` 取 1、2、3、4、5，依次加上 1、4、9、16、25，累计值为 1、5、14、30、55。加完 25 才执行 `index++`，下一次判断是 `6 <= 5`，此时退出。上界要写 `<=`，写成 `<` 会漏掉 25。计数器只在循环里用，可以直接在 `for` 的第一栏声明。[Microsoft Learn《for 语句》](https://learn.microsoft.com/zh-cn/cpp/c-language/for-statement-c?view=msvc-170)

## 在控制台复算

在 Visual Studio 的 C 控制台项目中把代码放进 `.c` 文件，按 `Ctrl+F5`。录屏实际输入 `3`，显示 `14`，退出码为 0。`5` 是讲师随后在编辑器中推演的例子。

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void)
{
    uint32_t number;
    uint32_t sum_of_squares = 0;
    puts("请输入 0 到 2343 之间的整数：");
    if (scanf_s("%" SCNu32, &number) != 1 || number > 2343) {
        puts("请输入规定范围内的整数。");
        return 1;
    }
    for (uint32_t index = 1; index <= number; index++) {
        sum_of_squares += index * index;
    }
    printf("平方和 = %" PRIu32 "\n", sum_of_squares);
    return 0;
}
```

录屏第二次输入 `qwewqe`，控制台却显示上界 `3435973836`、结果 `1305670058`，退出码为 0。`scanf_s` 这次没有读到整数，原程序仍使用了未赋值的 `number`。这些数字只记录了此次运行，不能据此预测下一次。[Microsoft Learn《scanf_s 的返回值》](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/scanf-s-scanf-s-l-wscanf-s-wscanf-s-l?view=msvc-170)

整理者补上了读取检查和上限。练习时每次输入一个能用 `uint32_t` 表示的十进制非负整数。输入 `0` 时，第一次判断 `1 <= 0` 就为假，结果保留初值 0。输入 `2343` 得到 `4290161084`，再加 `2344²` 就是 `4295655420`，超过 `uint32_t` 最大值 `4294967295`。录屏没有限制 N，不能把它推广到任意大小的整数。
