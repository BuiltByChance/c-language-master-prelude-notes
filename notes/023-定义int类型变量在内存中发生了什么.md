# 023 · 定义 int 类型变量时，内存中发生了什么

在 `int sun_flower = 9673;` 中，9673 是初值。`printf("%d", sun_flower)` 打印当前值，`sizeof sun_flower` 给出这个变量占的字节数。讲师现场观察的是整台虚拟机的内存用量。

## 用任务管理器看运行内存

课堂虚拟机有 70.0 GB 磁盘和 8.0 GB RAM。保存在磁盘上的文件断电后仍可读取，浏览器运行时使用的普通 RAM 断电后会丢失内容。要比较关闭网页前后的整机读数，按 `Ctrl+Shift+Esc` 打开任务管理器，在简洁视图先点 **详细信息**，再选 **性能 → 内存**。[微软的任务管理器说明](https://support.microsoft.com/en-us/windows/experience/system-configuration-tools-in-windows)

| 课堂操作 | 正在使用（其中已压缩） | 可用 | 占用率 |
| --- | --- | --- | --- |
| Firefox 打开网页时 | 5.0 GB（416 MB） | 2.9 GB | 64% |
| 关闭窗口后 | 4.8 GB（420 MB） | 3.2 GB | 60% |

括号内的压缩量已经计入“正在使用”。“可用”是还能供程序使用的内存。两次读数覆盖整台机器，其他程序也在运行，因此无法从 0.2 GB 的差额算出这一个网页占了多少。

**容量换算。** 一位（bit）可取 0 或 1，课堂电脑上每 8 位组成 1 字节（B）。板书中的“1 KB = 1024 字节”用了二进制进位。按标准写法，**1 KiB = 1024 B**，**1 kB = 1000 B**。[NIST 容量前缀对照](https://physics.nist.gov/cuu/Units/binary.html)

## 自测当前环境的 int 大小（整理者补充）

`sizeof` 按 C 字节计数，其结果用 `%zu` 打印。`<limits.h>` 中的 `CHAR_BIT` 给出每个 C 字节的位数。[WG14 C11 草案 §6.5.3.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=108) · [§5.2.4.2.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=45)

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    int sun_flower = 9673;
    printf("%zu bytes, %d bits per byte\n", sizeof sun_flower, CHAR_BIT);
    return 0;
}
```

在 Windows x64 的 TinyCC 上实测输出 `4 bytes, 8 bits per byte`，所以该环境中的 `int` 占 4 × 8 = 32 位。换编译目标后可用同一程序核对。
