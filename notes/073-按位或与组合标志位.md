# 073 · 怎样用按位或打开多个开关，同时保留原设置？

两个整数做按位或 `|` 时，从最低位对齐，逐列计算。同一列只要有一个 `1` 就得 `1`，两位都是 `0` 才得 `0`。课堂例子中，`2` 在位权为 2 的一列有 `1`，`5` 在位权为 4 和 1 的两列有 `1`，所以结果是 `4 + 2 + 1 = 7`。

```text
  0010    2
| 0101    5
------
  0111    7
```

讲师在 Visual Studio 中令 `int a = 2;`、`int b = 5;`，运行 `printf("%d\n", a | b);`，控制台输出 `7`。录屏里的计算器同时显示 `DEC 7` 和 `BIN 0111`。自行复核时，在 Windows 计算器的「程序员」模式选 `DEC` 并输入 `7`，再读 `BIN` 行。

双竖线 `||` 判断两个数中是否至少有一个非零，结果只有 `0` 或 `1`，所以 `2 || 5` 得 `1`。异或 `^` 也逐位计算，但两位都是 `1` 时，`1 ^ 1` 得 `0`，`1 | 1` 得 `1`。课堂的 `2` 和 `5` 没有重合的 `1`，单用这组数看不出或与异或的差别。[微软《C 位运算符》](https://learn.microsoft.com/zh-cn/cpp/c-language/c-bitwise-operators?view=msvc-170) · [C11 草案 §6.5.14](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=117)

## 打开选定的位，保留已有设置

把每一位当作一个独立开关。用一个整数（掩码）标记要打开的位置。目标位填 `1`，其余位填 `0`。对任意一位 `b`，`b | 1` 总是 `1`，`b | 0` 保留 `b`。因此同一个开关打开两次仍然是开着的。

讲师在板书上用箭头标出三个开关，口头说明多个选项可以合成一个设置。下面是整理者补写并运行的例子，位号从最右边的第 0 位算起。

```c
const unsigned int sound = 1u << 0;   // 声音占第 0 位，掩码为 0001
const unsigned int light = 1u << 2;   // 灯光占第 2 位，掩码为 0100
unsigned int flags = 2u;              // 已有设置占第 1 位，当前为 0010
flags |= sound | light;
```

`sound | light` 合出掩码 `0101`。`|=` 将结果写回 `flags`，得到 `0111`，新选的两位都打开，原有的第 1 位仍在。如果写成 `flags = sound | light;`，赋值后只剩 `0101`，原有设置会丢失。[C11 草案 §6.5.16.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=121)
